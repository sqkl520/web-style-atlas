互斥清单

一枚锁的切口角度由它的互斥对数决定，所以清单是可核对的：数出几条，就能拿尺子量出切口该有多陡。

  • 9信号 A与 3 号锁争用同一条进路交叉点

  • 13信号 G侧向进路经 5 号道岔，与 3 号锁的路由交叠
  • 14信号 H与 3 号锁共用同一段钢轨电路区段
