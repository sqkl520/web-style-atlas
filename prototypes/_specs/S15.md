**结构类型**：F（FLOORPLAN） ｜ **认知门槛**：高 ｜ **调性**：温暖手作 / 人味

**1. 一句话视觉定义**
一本 1930 年代挪威渔场的硫酸纸平面簿：三层半透明描图纸叠在同一张网具舱平面图上，最上层是 0.8px 的铅笔硬线标注与橡皮擦过留下的白痕，页脚钉着一根 1:200 的手绘比例尺，图例挂在平面图右侧只占六成高度。

**2. 美学家族与参考**
北欧渔业档案（1930 年代挪威）。参考三个真实对象：挪威渔业博物馆保存的鳕鱼场与网具舱平面测绘图、1930 年代工程师用的硫酸纸（tracing paper）三层透叠制图法、以及同期手绘比例尺与图例的排布习惯。偷的机制是「透叠是把不同年代的信息压在同一张图上，所以三层必须错开才能读出各自属于哪一年」，以及「铅笔标注是会被擦掉的，擦痕本身是修订史」。我们拿的是透叠层数与擦痕，不是泛黄纸感。

**3. 配色系统**
主色 `#3A3F45` 石墨（色相 213°，饱和 15.9%，明度 24.9%，同时构成脏色，情绪：朴拙）46%；背景色 `#E7EBE9` 硫酸纸透光色（冷白半透明描图纸，色相 150°、饱和 1.7%、明度 91.4%，情绪：透叠）34%；深色 `#22282B` 铅笔重压处与图例底（L 15%，脏色）15%；铅笔灰 `#7A7466`（普通标注线，饱和 8%，脏色）5%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「深蓝底加白色线稿」的蓝图套路，也反纯白底：石墨是铅笔与晒图两者的交集色，饱和只有 15.9%，而多数 AI 生成的「档案风」是给泛黄纸加一个暖滤镜，本方案整体偏中性，暖只出现在纸色一个值上。

**4. 字体策略**
标题用 `Newsreader`（OFL 1.1，为屏幕重绘的报纸衬线，带光学尺寸轴）；中文用思源宋体（OFL 1.1，横细竖粗，长文宽排）；读数与坐标用 `Reddit Mono`（OFL 1.1，窄等宽，纵向字面紧凑）。分工：平面图标题与档案标题 = Newsreader 加思源宋体宽排（字距 0.04em）；说明文与档案条目 = 思源宋体 15px / 行高 1.9（长宋宽排的行长放到 38 个汉字）；深度读数、坐标、登记号 = Reddit MonoMono。为什么不像 AI 选的：AI 默认装配线里没有一款报纸衬线，也没有把中文宋体的行高放到 1.9 的做法；这里展示与正文的对比靠字面宽度与行距节奏，而不是靠换一款几何无衬线。

**5. 布局与网格**
12 栏，基线 8px，栏间距 20px。不对称方式：平面图占 1–8 栏并向左侧满幅出血 40px，图例悬挂在 9–12 栏，高度只到平面图的 62% 且顶部对齐平面图的 1/3 处；比例尺贴在版心右下角，宽度固定 240px。留白节奏：平面图外围留 4 个基线单位的空白（这是测绘纸的图廓留边），档案条目之间只留 1 个基线单位，形成「图幅大留白、条目小间距」的两级节奏。滚动行为：平面图随滚动整体缩小到 68% 并向上让位，图例保持原位不缩放，比例尺始终贴住视口下沿内 24px。

**三层硫酸纸的透叠规则**
固定三层，层间错位量分别为 0 / 3 / 7px，透明度 100% / 78% / 56%；第一层是 1934 年原始平面，第二层是 1936 年的网具区修订，第三层是 1938 年的水深补测。切换年份时只有对应层的不透明度升到 100%，其余两层降到 30%，避免三层同时全亮导致读不清。图例中每一层用不同线型区分（实线 / 长虚线 / 点划线），不靠颜色区分，因为真实硫酸纸上三层都是同一支铅笔。

**断点具体行为**
≥1440px 保留 12 栏、平面图满幅左出血 40px、比例尺 240px；1024–1439px 折为 9 栏，图例移到平面图下方并横向排成 2 列，比例尺缩到 180px；<1024px 单栏，三层硫酸纸改为按层折叠成三个可展开的板块（点击层标题展开该层标注），比例尺固定在页脚不随滚动，热区点击面积一律不小于 44×44px 以保证触屏可用。

**6. 关键视觉元素（≥3 个）**
一是硫酸纸透叠，三层错位 0 / 3 / 7px，边缘有 1px 的纸张毛口，层与层交叠处亮度自动降低 6%（用混合模式实现而非降低不透明度）；二是铅笔标注，线宽固定 0.8px 硬线，端点方头，末端带 2–6px 的橡皮擦除残迹（表现为线条中断后留下 12% 不透明度的浅灰底），修订编号写在擦痕旁；三是图标逻辑，自绘测绘符号，32 单位网格、1px 单线，三角点用「等边三角加中心点」、等深线用「三级粗细递变曲线」、锚位用「带横杆的十字」，绝不用任何 Emoji，符号线宽只有 0.8px 与 1.2px 两级；四是图像处理，所有照片先扫描成灰度，再压到石墨与纸色两个色阶，保留原始铅笔压痕的侧向阴影，禁止暖色滤镜与纸张纹理贴图。

**7. 动效与交互**
滚动：平面图缩放触发阈值为滚动 200px，缩到 68%，时长 600ms，缓动性格为阻尼无过冲；悬停：热区边界由 0.8px 变 1.2px 并显示该区登记号，140ms，无位移；加载：三层硫酸纸按 1934 / 1936 / 1938 顺序依次叠上，每层 220ms，缓动为线性（模拟手动落纸）；转场：年份切换用 260ms 交叉叠化，且只有两层参与，第三层保持不动；光标：24px 十字加 0.5px 细圈，进入热区后细圈变为虚线；微交互：点击热区时该区在图例中的对应线型同步加粗一次（160ms）。降级：`prefers-reduced-motion: reduce` 时取消平面图缩放与逐层叠上，三层改为静态全部可见，年份切换用 100ms 不透明度瞬切，比例尺不再贴视口下沿而固定在图幅内。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.6「白 / 灰交替分区」：全站只用 `#E7EBE9` 与三层硫酸纸的交叠亮度变化分区，没有任何 section 换底色；跳脱之处在于分区的明暗是层数造成的，不是设计者挑的两块灰。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部面板直角，层与层之间没有投影，深度由 0 / 3 / 7px 的错位与交叠亮度差承担。第三，反 C-2.14「3 / 6 / 9 等量图标网格」：热区共 14 个且面积按舱室真实面积等比，不等量、不等距。第四，反 `01-research-brief.md` F 节 P14「没有真实图片、用渐变块顶替」：主视觉是三层测绘纸的实拍扫描与铅笔压痕，页面内不存在任何抽象色块。

**9. 反 AI 味风险与规避**
最易滑向「复古档案做成泛黄滤镜」：一旦把整站调成褐黄、再加一层纸纹贴图，就与 7 号方案和大量「档案风」模板撞车。规避动作三条：一是纸色只允许 `#E7EBE9` 一个值，主色石墨占 46%，整体观感偏中性；二是记忆点必须落在三层透叠与 0.8px 铅笔硬线上，纸感本身不承担识别；三是禁止任何纸张纹理贴图与暖色调整层，纹理只能来自程序化噪声且不透明度上限 4%。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是地图、GIS、空间数据类产品的官网与产品页，平面热区天然对应真实功能区域；二是档案馆、博物馆、研究机构的专题数据库，尤其是需要对照不同年份版本的项目。不适合：需要快速转化的电商与消费品牌页，本方案的认知门槛偏高且缺少单一动作入口；也不适合以短视频或大图为主的品牌页，页面的视觉主角是图纸而不是照片。

**可直接上线的文案**：主张句「网具舱 B-3 区，1936 年 4 月登记 11 张拖网，水深重测过两次」；按钮「放大到 1:200 的 B-3 区」；空状态「这个区域还没有测绘记录。第一份平面图登记于 1934 年冬」；错误状态「第 2 层（1936 年）硫酸纸扫描缺页（错误码 TRACE-36）：该层以 30% 不透明度占位，其余两层可正常读，重扫后自动补上」。

**11. 可落地要点**
CSS 思路：三层透叠用三个绝对定位图层配 `mix-blend-mode: multiply`，交叠亮度差靠混合模式自然产生，不需要额外的手工调色；铅笔线一律用 SVG `stroke-width: 0.8` 与 `shape-rendering: geometricPrecision`，擦痕用同一路径上加一段 `stroke-dasharray` 的浅色副本；全站不引入任何 CSS 色彩插值写法。栅格单位：12 栏、8px 基线、20px 栏间距、图廓留边 32px。字体加载：Newsreader 只取光学尺寸轴的两端取值并子集化，思源宋体按 GB2312 一级字库子集，`font-display: swap`。图片处理：平面图导出为 SVG 以保证 0.8px 线宽在任意缩放下成立，扫描图走灰度加双色阶后输出 AVIF；纹理只用 4% 不透明度的程序化噪声。性能预算：首屏 JS ≤ 55KB（gzip），字体 ≤ 500KB，SVG 平面图 ≤ 180KB（开启 gzip 与路径简化），缩放只改 `transform`，LCP ≤ 2.2s。本方案最难被复用到别的品牌的地方，是三层错位量与图例线型表：任何没有「多版本信息」的项目套上去，三层就变成无意义的装饰。

**12. 设计师签名式怪癖**
页脚那根 1:200 的手绘比例尺上，第 7 格比其余格窄 0.5px，第 13 格又宽 0.5px，因为原件是 1930 年代的人用尺子一格一格手画的。它不影响任何测量，存在的理由是把「这支比例尺是人画的」这件事留在页面底部，让愿意量一下的人发现它并不准。
