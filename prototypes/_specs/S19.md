**结构类型**：F（CARD-CATALOG） ｜ **认知门槛**：高 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一只 1880 年代邱园的标本柜：柜面是 20 个宽度不等的抽屉，抽屉标签上的检索号由柜号、抽屉号、卡号三段组成，抽开抽屉露出铜版蚀刻的植物标本卡，细线只有 0.4px 与 0.8px 两级，褪色的墨绿压在米色卡纸上。

**2. 美学家族与参考**
植物学标本馆（1880 年代英国邱园）。参考三个真实对象：邱园标本馆的索引卡与抽屉标签体系、铜版蚀刻（copperplate engraving）用平行影线表现体积的制版方法、以及 19 世纪植物志里标本签上的手写采集地与时日。偷的机制是「抽屉标签、索引卡、检索号三者构成一条可检索的路径，缺一段就翻不到东西」，以及「蚀刻的深浅由线的疏密决定，不由颜色决定」。我们拿的是三级检索与平行影线，不是拿植物插画与藤蔓花纹。

**3. 配色系统**
背景色 `#E4DECD` 标本卡纸（棉麻浆手工纸，色相 44.3°、饱和 10.1%、明度 84.9%，情绪：陈雅）44%；主色 `#4A5C3A` 蚀刻墨绿（色相 91.8°，明度 29.4%，脏色，情绪：静肃）27%；抽屉与柜架 `#2A241C` 深木褐（明度 13%，脏色，情绪：旧木）24%；标签褪色墨 `#7C7460`（索引标签的褪色字迹，饱和 13%，脏色）5%，面积和 100。这套配色反的是 `#6366F1` 靛蓝与纯白底，也反「深绿加金色」的常见复古配方：绿色是带灰的墨绿而不是饱和绿，柜架色只有 24% 且不参与正文，页面没有金色，唯一的暖色来自卡纸本身。

**4. 字体策略**
中文主字体用京华老宋体（免费商用，发布页须复核：须保留原始授权声明、不得二次转售字体文件，老宋宽排刻版，横竖对比明确）；拉丁标题用 `Spectral`（OFL 1.1，低对比屏幕衬线，与 0.4px 蚀刻细线并置时不抢戏）；检索号与采集数据用 `IBM Plex Mono`（OFL 1.1，等宽，用于三段检索号与经纬度）。分工：柜门标题与卡面标题 = Spectral 加京华老宋体宽排（字距 0.05em，行长 40 个汉字）；采集说明与批注 = 京华老宋体 15px / 行高 1.9；检索号、采集年月、经纬度 = IBM Plex Mono。为什么不像 AI 选的：AI 默认字体栈不会选一款刻版老宋，也不会把行高放到 1.9 来承担宽排节奏；这里的中文是字面宽、行距松的刻版宋，拉丁是同为低对比的屏幕衬线，两者对比靠线宽而不是靠字族风格。

**5. 布局与网格**
12 栏，基线 8px，抽屉面板高 24px（3 个基线单位）。不对称方式：20 个抽屉分 5 行，每行 4 个，宽度分别取 4 / 3 / 3 / 2 栏，行与行之间不重复同一顺序，因此没有两个抽屉等宽；检索号悬挂在抽屉标签右侧 12px 处，比标签基线低 2px。留白节奏：抽屉内边距 8px，抽开后卡面留 16px 内边距，卡与卡之间空 1 个基线单位，行与行之间空 2 个基线单位。滚动行为：滚动经过某一抽屉行时，该行抽屉抽出 24px 并露出卡面首行，离开视口后自动推回；整柜不吸顶，滚动到第 3 行时柜体上沿才进入视口。断点：≥1440px 保留 20 个抽屉与不等宽分配；1024–1439px 合并为 12 个抽屉（每行 3 个），宽度取 4 / 4 / 4 栏但靠抽拉深度 24 / 32px 制造差异；<1024px 单列，抽屉改为可点击展开的索引卡列表，检索号提到行首用等宽字显示，键盘 Tab 顺序按检索号升序排列。

**6. 关键视觉元素（≥3 个）**
一是抽屉抽拉，抽屉面板高 24px、抽出 24px，抽出后开口内侧有 1px 单向下阴影表示柜内的暗，推回时阴影消失；二是索引卡，卡面用 0.4px 蚀刻细线画外框，卡内有 0.8px 的横线与手写批注层，批注用 12% 不透明度的褪色墨以区别于印刷文字；三是三级检索号，格式固定为「柜号-抽屉号-卡号」（如 K-07-112），三段之间用短横连接，检索号在抽屉标签、卡面右上角、页脚检索栏三处同时出现且完全一致；四是图标逻辑，自绘植物学符号，24 单位网格、只用 0.4px 与 0.8px 两级线宽，针叶用「双列斜短线」、蒴果用「椭圆加中轴」，叶脉用「主脉加三级分支」，绝不用任何 Emoji 也不使用彩色字形；五是图像处理，所有照片先做铜版线稿化（灰度后按 45° 平行影线密度重建），线宽 0.4px、影线间距 2px，再压到墨绿与卡纸两个色阶。

**7. 动效与交互**
滚动：抽屉抽拉触发阈值为该行进入视口 25%，抽出 24px，时长 260ms，缓动性格为阻尼无过冲；悬停：抽屉标签的褪色墨从 12% 加深到 24%，120ms，不位移；加载：柜体先出，再按行从上到下依次抽出抽屉又推回一次，每行 160ms，总时长 800ms，缓动为阶跃式；转场：从检索号跳转到某张卡时，该抽屉保持抽出并把卡面推到最前，其余抽屉回到闭合，300ms；光标：12px 十字加 1px 方框，进入抽屉标签区后变为「卡面外框」形；微交互：点击检索号会把它复制到页脚检索栏并高亮 200ms。降级：`prefers-reduced-motion: reduce` 时取消自动抽拉与加载动画，抽屉默认闭合、点击才抽出且无过渡，复制高亮改为 100ms 不透明度变化。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.14 与 R-13「3 / 6 / 9 等量图标网格主体化」：抽屉共 20 个，宽度取 4 / 3 / 3 / 2 栏四种值，且刻意留 2 个空抽屉并在标签上写明「1889 年迁库时借出，位置照留」；跳脱之处在于不等宽与空位是档案被翻动过的证据，而不是版式游戏。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部容器直角，抽屉的立体感来自面板厚度与开口内侧的单向下阴影，页面没有浮起卡片。第三，反 C-1.6「白 / 灰交替分区」：全站只用 `#E4DECD` 一种底，分区靠抽屉行、柜架色与检索号。第四，反 C-1.5 与 C-2.13「抽象球体与 3D 主视觉」：主视觉是蚀刻线稿与卡片目录，页面内不存在渲染图形。

**9. 反 AI 味风险与规避**
最易滑向「复古博物插画墙」：一旦把植物插画铺满、再加烫金花纹与做旧边缘，就变成常见的复古品牌页。规避动作三条：一是所有插画必须是 0.4px 与 0.8px 两级线宽的线稿，禁止水彩填充与彩色植物图；二是记忆点必须落在三级检索号的贯通与抽屉抽拉上，插画不承担识别；三是禁止烫金、金边与暗角，柜架色只占 24%。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是生物、医药、农业与标本馆类数据库的检索界面与官网，三级检索号直接对应真实编号规则；二是需要「先检索再阅读」的学术档案库与法规条文库。不适合：以浏览与推荐为主的内容社区，检索式结构会让无意向的访客无从下手；也不适合强调转化与促销的商业站点，抽屉式的展开节奏偏慢。

**可直接上线的文案**：主张句「检索号 K-07-112：欧洲赤松，1884 年采自邱园 3 号温室」；按钮「抽出第 7 抽屉，查看 112 号卡」；空状态「这个抽屉是空的。1889 年迁库时标本被借走，位置照留」；错误状态「检索号 K-07-113 不在本柜（错误码 CAT-404）：该卡 1889 年迁至 K-12 柜，页脚检索栏已给出跳转」。

**11. 可落地要点**
CSS 思路：抽屉用容器加 `translateY` 抽出，开口内侧的单向下阴影用一条 `inset` 阴影随抽出状态切换；蚀刻线稿一律用 SVG 路径加 `stroke-width: 0.4` 与 `0.8` 两级，禁止用位图放大近似；不使用任何 CSS 色彩插值写法。栅格单位：12 栏、8px 基线、24px 抽屉面板高、16px 卡面内边距。字体加载：京华老宋体按 GB2312 一级字库子集并保留标点全集，Spectral 只取 Regular 与 Italic，`font-display: swap`。图片处理：照片先灰度、再按 45° 影线密度重建为单色 SVG 或高压缩 AVIF，影线间距 2px 需与屏幕像素对齐以免摩尔纹。性能预算：首屏 JS ≤ 45KB（gzip），字体 ≤ 430KB，线稿 SVG 总量 ≤ 220KB，抽拉只改 `transform` 与一条阴影值，LCP ≤ 2.1s。本方案最难被复用到别的品牌的地方，是三级检索号与四档抽屉宽度的对应关系：没有真实编号体系的品牌套上去，检索号会立刻变成看不懂的装饰。

**12. 设计师签名式怪癖**
每张索引卡的右下角都有一处 1px 的指甲压痕，位置随卡号从 001 到 240 每 20 张向右下偏移 1px，因此第 240 张的压痕比第 001 张低了 12px。它不参与检索，存在的理由是把「翻卡片的人手指会越翻越靠下」这件事留在卡上。
