# S34 单案规格

> 源：`deliverables/75-q2/05-N32-N35-DESIGN.md`（Q2 新增）
> 原标题：方案 34｜石墨零图索引（Graphite Zero-Photo Index）
> 本案是**全库第一个零位图页**（`realPictures = 0`，`minPics = 0`），补 `very-quiet` 缺口（4→5）。

---


**结构类型**：R（ZERO-G） ｜ **认知门槛**：低 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一页通体石墨灰（`#2C3034`）的课程说明：七块文字各不共享基线，左缩进分 0/3/5.5/2/7/4/1% 七档，按每块的文字重量分配——字少的浮得远、字多的沉得近；**全页零位图**，没有 `img`、没有背景图、没有 SVG，分区与记忆点全部由字号、留白与漂移承担。

**2. 美学家族与参考**
书信体的**分栏笔记**与「零重力」排版实验。参考三个真实对象：马蒂斯晚年的《爵士》剪纸书里那些字与字之间故意不对齐的版面、瑞士排版师 Emil Ruder 讲义里「以空白而非线来分隔」的练习、以及日本「原稿用纸」上手写批注在页边浮动的位置感。偷的机制是「**不共享基线**」：七块文字之间没有任何水平线把它们串起来，位置关系只由各自的"重量"决定。这与「所有区块对齐到同一个网格」相反——后者是秩序，前者是"每句话说的时候都不一样重"。

**3. 配色系统**
背景色 `#2C3034` 石墨灰（HSL 210°/8%/19%，Lab L\* 19.6，情绪：砚）72%；正文 `#EBEEF0`（对底 **11.41:1**，情绪：纸）18%；次级 `#C2C8CD`（对底 **7.2:1**）7%；更弱 `#A8AFB5`（对底 **4.9:1**）2%；结构线 `#6E767C`（对底 **3.1:1**，非文本满足 3:1）1%，面积和 100。

⚠️ **这个暗度是全库最浅的一档暗色**：现有 8 个暗底案的明度是 5%–15%（S02 5、S03 9、S05 6、S08 5、S12 15、S14 9、S18 5、S28 6），本案是 **19%**。差这一档的意义是它不再是"黑底"，而是"石墨"——接近纸但更冷。这是补 `very-quiet` 缺口时顺手避开同质化的做法：很安静的四案（S15 冷白、S22 灰白、S31 中性灰、S33 冷青）里，本案是唯一偏暗的一案。

**4. 字体策略**
中文正文 `Noto Serif SC` 400/700（OFL 1.1）；拉丁标题 `Jost` 500（OFL 1.1）；编号与错误码 `Sometype Mono` 400/600（OFL 1.1）。分工：H1 与节标题 = Jost；正文与八周清单 = 思源宋 400；块序号（由 CSS counter 生成）与 `QUILL-34` = Sometype Mono。为什么不像 AI 选的：AI 做暗色页会给一个"深蓝黑 + 青色强调 + 圆角卡片"的组合；本页没有任何强调色，全部是同一色的四档明度，靠**明度差与留白**组织层级。

**5. 布局与网格**
基线 6px，正文 17.5px／行高 1.78（比其余案都大一号——零图页要让文字本身更有份量），外距 44px。**七档左缩进** `0 / 3 / 5.5 / 2 / 7 / 4 / 1%`：这个序列不是随机的，它跟着每块的文字长度走——最长的第 4 块（不承诺你发表）缩进 2%，最短的第 5 块（价格）缩进 7%。块间间距 34px。留白节奏：块内段落 10px、块间 34px、区段间 32–52px。滚动行为：七块按序号 × 26ms 再加一个由文本长度决定的 0–40ms 偏移依次淡入——**时间上的不对齐与空间上的不对齐是同一个意思**。断点具体行为：≥1024px 七档缩进全生效；768–1023px 缩进减半；<768px 缩进**全部归零**，改由块间距 98/58/72px 三档承担悬浮感（这是机制的再发明形式——小屏上"浮"会变成"错位"，那是缺陷）。

**断点具体行为**
≥1024px 七档缩进 + 34px 块距；768–1023px 缩进减半、块距不变；<768px 缩进归零、块距改 98/58/72px 三档循环、按钮满宽、错误块纵排。

**6. 关键视觉元素（≥3 个）**
一是**七档左缩进** 0/3/5.5/2/7/4/1%，按文字重量分配（这是本页唯一的记忆点，也是"零重力"的具体化）；二是**零位图**——`realPictures = 0`，全页没有 `img` / `background-image: url()` / SVG，这是元素而不是缺失；三是**八周清单**，八行 `第一周 / 第二周 …`，用 CSS 而非表格排，每行一条具体任务；四是图标逻辑——**不用任何图标**，替代它的是序号与加粗的周次；五是图像处理——无图像可处理，这一栏在本案里是空的（这是刻意的）。

**7. 动效与交互**
入场：七块按序号 × 26ms + 文本长度决定的 0–40ms 偏移依次淡入，300ms 线性，**只变 opacity**（不用 transform：位移会把缩进与窄档溢出的风险带进来）。悬停：按钮边框转 `#6E767C`，180ms。加载：无整块淡入。转场：无。光标：默认。微交互：无。降级：`prefers-reduced-motion: reduce` 时取消逐块淡入，改成**七块一次性到位 + 块间距各差 8px**（104/96/112/88/120/92）——"不齐"这件事从空间缩进转到间距差上，缩进数值 0/3/5.5/2/7/4/1% 一字不改。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.15「纯黑底 + 纯白字」：底色 `#2C3034` 而非 `#000000`，正文 `#EBEEF0` 而非 `#FFFFFF`。第二，反 C-1.6「白 / 灰交替分区」：一个底色，分区靠留白与漂移，不存在交替。第三，反 C-2.11「圆角卡片 + 柔和投影」：零圆角、零 `box-shadow`、零渐变。第四，反「暗色页必配强调色」这条默认：本页**没有任何强调色**，全部由同一色的四档明度构成。第五，反 C-2.14「图标网格」：全页零图标。

**9. 反 AI 味风险与规避**
最易滑向「暗色 SaaS 落地页」：一旦加上荧光强调色、圆角、卡片、网格背景，就与大量开发者工具模板撞车。规避动作三条：一是**不加任何强调色**（连按钮都是同一色的反相）；二是记忆点必须落在七档缩进与零位图上；三是零圆角零投影零渐变零网格背景。另有一条反向风险：**「零重力」容易被做成"元素散落各处"**——那会读成排版事故而不是设计。本页的漂移幅度只有 7%，且**每一档都对应一个可解释的重量**（字少的浮得远），这让它读起来是"有意"而不是"失控"。

**10. 适用场景（≥2 类，并附「不适合」）**
适合三类项目：一是**文字本身就是产品**的项目（写作课、编辑服务、翻译、出版），这些项目的页面上放图反而分散注意力；二是**没有照片可用、也不该凑**的场景（如本案：学员不同意露脸、教室是线上会议室）；三是需要**高阅读密度**的长文页（政策说明、研究摘要、长篇声明），零图让读者不停顿。不适合：电商与任何以图为决策依据的页面；需要强视觉冲击的活动页；面向低龄用户的页面（纯文字对儿童不友好）。

**可直接上线的文案**：主张句「这一页一张图都没有」；按钮「看看报名表还剩几个位置」；空状态「本期报满了。下一期十一月开，到时候这一页的数字会变，位置也会重新空出来」；错误状态「这周三的课要推迟一天：我住的这栋楼临时停电检修，晚上七点到十一点。提前说是因为有人可能要调时间——如果周四来不了，告诉我，我把你那一篇的批注改成书面的，不占你上课的时间（错误码 QUILL-34）」。

**11. 可落地要点**
CSS 思路：七档缩进用七个子类 `.d1`–`.d7` 而不是内联 `style`，因为档位是内容属性；块序号用 `counter-reset` / `counter-increment` + `::before` 的 `counter(d, decimal-leading-zero)`，**不用 `span` 手写 `01`**（那会被 `numbering` 规则判为装饰性编号，且屏读器读不到顺序）；零图页要提高密度，所以块距压到 34px、`max-width` 放到 62ch——这两个数是被 `empty-screens` 逼出来的，不是审美选择。栅格单位：6px 基线 / 44px 外距 / 34px 块距 / 七档缩进 0·3·5.5·2·7·4·1%。字体加载：三族各取实际字重，`font-display: swap`。图片：零张。性能预算：首屏 ≤ 170KB（全部是字体，无图），LCP ≤ 1.2s——这是全库 LCP 最低的一案。最难被复用到别的品牌之处：**七档缩进与文字重量的绑定**——没有一个"每块重量不同"的叙事，七档缩进就成了随机的错位。

**12. 设计师签名式怪癖**
第七块（下一期什么时候）的右边距，永远比其余六块窄 12px。它来自手写稿上最后一段总是挤在页脚附近、写到边上就写不下去了的实况。不影响阅读，存在的理由是让这一页承认"最后那点空间总是不够"。

**自评：8.3/10**
依据一：字段 3 五色面积和为 100，底色 Lab L\* 19.6 是全库最浅的一档暗色（其余 8 个暗底在 5–15%），补 `very-quiet` 缺口（4→5）。依据二：字段 6 的元素里「零位图」本身就是可测的（`realPictures = 0` 是机械读数），与 S31 的刻度、S33 的镜像在机制上互不重复：三者都少图，但一个靠刻度、一个靠对照、这一案靠**不对齐的留白**。依据三：`minPics = 0`，全库第一个。⚠️ 已知短板：为了满足 `empty-screens`，块距从设计意图的 96px 压到 34px、缩进从 14% 压到 7%——**漂移幅度被密度要求压掉一半**，机制还在但比设计意图弱。这是零图与"每屏不空"之间的真实张力。
