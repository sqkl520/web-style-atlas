**结构类型**：R（MASK） ｜ **认知门槛**：低 ｜ **调性**：荒诞幽默 / 玩心

**1. 一句话视觉定义**
一整面青柠色层压塑料墙被 45° 与 135° 硬边斜切出七个洞口，洞口内侧有 0.5px 米白翻边，透过洞口露出深墨绿的机房底色，墙面上浮动着一层 8px 宽的斜纹边框。

**2. 美学家族与参考**
孟菲斯集团（Memphis，1980 年代米兰）。参考三个真实对象：Ettore Sottsass 1981 年首展的层压塑料家具（Carlton 书架）、Nathalie Du Pasquier 的斜纹图案布样、1980 年代街机框体的丝印面板。偷的机制是「层压板把图案压进塑料里，所以边缘必然被压出一条白线」，以及「斜纹是印刷方向而不是装饰花纹」。我们拿的是压印翻边与斜纹方向这两件事，不是拿一组孟菲斯色卡。

**3. 配色系统**
主色 `#B5D626` 青柠（色相 72°，情绪：顽皮）34%；背景色 `#1E2A2E` 深墨绿（L 15%，脏色，情绪：机房底）48%；强调色 `#E23E57` 洋红（情绪：塑料贴纸）12%；贴面色 `#F2E9D8` 米白（层压板芯纸，情绪：切口）6%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「深底加霓虹紫青」的仪表盘套路：青柠是被压进塑料的实色，不带光晕也没有发光边；底色是带绿的墨色，既不是纯黑也不是 `#0F172A` 那种蓝黑。按钮与色块约束：主色 `#B5D626` 作填充时白字只有 1.67:1，一律改用深色文字 `#111111`（实测 11.34:1），或把主色退到只有 45° 斜切的描边与图标位、不承担文字底。

**4. 字体策略**
标题用 `Bricolage Grotesque`（OFL 1.1，宽度轴 75–100 与字重 200–800 双向极端，「圆钝粗笨」由宽度轴的后段给出）；关卡号与洞口编号用 `JetBrains Mono`（OFL 1.1，等宽，只用于 14px 以下的编号与分数，不承担标题）；正文用未来荧黑 Glow Sans（OFL 1.1，硬骨架几何黑体）。分工：标题层级 = Bricolage Grotesque 极宽档；正文与规则说明 = 未来荧黑；关卡号 / 分数 / 计时 = JetBrains Mono。为什么不像 AI 选的：不用被组件库写死的默认无衬线栈；Bricolage 的宽度轴能让同一个字既是方块又是长条，这正是孟菲斯层压板的冲切逻辑，AI 默认的单一字重无衬线做不出这种尺度差。落地：三款均 OFL 1.1，未来荧黑按 GB2312 一级字库子集，`font-display: swap` 配 `size-adjust` 抑制跳版；授权复核：`Bricolage Grotesque` 的 OFL 1.1 原文须在落地前逐页复核发布页。

**5. 布局与网格**
8 栏，基线 6px（对齐街机像素栅格），栏间距 0。不对称方式：七个洞口按 3 / 2 / 1 / 1 的行数递减错位堆叠，最大洞口跨 4 栏，最小洞口只占 1 栏并故意留空，整体重心压在版面左侧 38% 处。留白节奏：洞口之间不留均匀间隙，间隙按 12px / 28px / 44px 三级跳变，形成冲切落料的不规则边角。滚动行为：主体是一屏高的墙面，滚动到 60% 时墙面向右平移 40px 露出第二层，第二层仍是挖空墙但斜纹方向翻转。断点：≥1440px 保持 8 栏与满屏墙面；900–1439px 折为 6 栏，最大洞口降到 3 栏，平移量减到 24px；<900px 挖空机制完整保留并换一种不对称方式，墙面变为「双列错位咬合」，两列斜边洞口以 16px 互相压叠交替排列（左列洞口上沿为 45° 斜切、右列下沿为 135° 斜切），两列宽分别为 42% 与 50%，斜纹边框收窄到 4px 但角度仍只允许 45° 与 135°，翻边高光保持 0.5px，Tab 顺序仍按洞口编号 01–07 硬性排列，触屏点击热区不小于 44×44px；<768px 两列咬合改为上下咬合，列宽改为 50% 与 46%，互压量由 16px 增到 20px，斜纹角度与 0.5px 翻边高光参数不变。

**6. 关键视觉元素（≥3 个）**
一是挖空边缘全部为 45° 或 135° 硬切，任何位置不允许圆角，切边内侧压 0.5px `#F2E9D8` 硬高光，模拟层压板冲切后的翻边；二是 45° 斜纹，条纹宽 8px、间距 8px，只出现在洞口边框与按钮底，角度按层级在 45° 与 135° 之间翻转；三是图标逻辑，全部为自绘硬边几何符号，16 单位网格、2px 方头线宽、只用直线与 45° 折线，绝不用任何 Emoji 或曲线图标，颜色继承文字色；四是图像处理，所有照片先做 `#1E2A2E` 与 `#B5D626` 双色分色，再用同一套斜切遮罩冲切，边缘保留 1px 套色错位，禁止羽化。

**7. 动效与交互**
滚动：墙面平移触发阈值为滚动 60%，位移 40px，时长 480ms，缓动性格为一次性过冲（`cubic-bezier(0.2,1.5,0.4,1)`），落位时回弹 6px；悬停：洞口斜纹相位错开 8px（即条纹接缝跳一格），时长 120ms，不位移不缩放；加载：七个洞口按 01–07 顺序做冲切落下，每洞 90ms，缓动为 `steps(3)`；转场：关卡切换用 200ms 硬切配 1px 轮廓闪一次；光标：20px 方形空心框、2px 边框，进入洞口后框内转为斜纹；微交互：按钮沿 135° 下沉 2px 并露出 2px 底层洋红。降级：`prefers-reduced-motion: reduce` 时取消墙面平移与回弹，洞口直接切换，闪烁改为 100ms 不透明度变化。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全站圆角为 0，容器由 45° / 135° 斜切定义，页面不存在柔和投影；跳脱之处在于「可通行区域」是被硬边挖出来的，不靠卡片浮起暗示层级。第二，反 C-2.14「3 / 6 / 9 等量重复的图标网格」：七个洞口不等宽不等高，其中一个留空并在角上标「未开」；跳脱之处在于不平衡是孟菲斯式的版面态度，不是功能缺项。第三，反 C-1.6「白 / 灰交替分区」：全站只有 `#1E2A2E` 一种底，分区靠挖空层级与斜纹方向完成。第四，反 C-1.5「抽象 3D 球体代表科技」：主视觉是层压板冲切墙面，页面内无球体、无流体金属。

**9. 反 AI 味风险与规避**
最易滑向「孟菲斯多色贴纸堆砌」：把青柠、洋红、黄、蓝一次摆满，就退回成样式堆砌。规避动作三条：一是只允许三个实色加一个米白，禁止引入第四个彩色；二是所有图形边界必须能追溯到 45° 或 135°，禁止曲线与自由形状；三是斜纹角度只允许 45° 与 135°，禁止 30°、60° 这类中间值。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是独立游戏与休闲游戏的官网、活动页，用户期待 3 秒内被逗笑；二是面向 18–30 岁人群的潮流品牌快闪页与音乐节分场页。不适合：金融、政务、医疗等依赖可信感的站点；也不适合长文阅读类内容站，斜切遮罩会切断行首，破坏连续阅读。

**可直接上线的文案**：主张句「这面墙有七个洞，凿开三个就算通关」；按钮「切到第 3 关：青柠管道」；空状态「这一格还没开。凑齐三条斜线就凿得动」；错误状态「洞口 05 的斜纹贴图加载失败（错误码 MASK-05），已用 45° 单色斜纹兜底，热区仍可点击」。

**11. 可落地要点**
CSS 思路：挖空用 `clip-path: polygon()` 的 45° / 135° 折线顶点定义，翻边高光用同顶点的内缩 0.5px 副本垫底，斜纹用 SVG `<pattern>` 绘制，全站不引入任何 CSS 色彩插值写法。栅格单位：8 栏、6px 基线、12 / 28 / 44px 三级间隙。字体加载：Unbounded 只取两档宽度轴并子集化，未来荧黑按 GB2312 一级字库子集，`font-display: swap`。图片处理：双色分色后导出 AVIF，色阶压到每通道 4 bit 配合硬边风格。性能预算：首屏 JS ≤ 60KB（gzip），字体 ≤ 380KB，`clip-path` 不做逐帧动画，位移一律走 `transform`，LCP ≤ 2.0s。本方案最难被复用到别的品牌的地方，是那组 45° / 135° 的洞口顶点坐标与三级跳变间隙：换了文案之后，这组坐标仍然只适用于「一块被冲切的塑料板」。

**12. 设计师签名式怪癖**
页面右下的洞口编号 01–07 是手写数字压在 45° 斜纹上，其中 04 与 05 之间的间距比其它编号窄 3px，因为街机面板丝印常常为躲开螺丝孔而挤掉一点间距。它不影响点击热区，存在的理由是把「编号是印在实物面板上的」这件事留在成品里。
