**结构类型**：F（RECEIPT） ｜ **认知门槛**：中 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一张 1900 年代奥斯曼印花税票式的对账联：右侧是右对齐小数点的等宽明细行，左侧三成宽是带 1.2px 齿孔的存根联，一枚暗红骑缝章横跨两联并固定偏移 2mm，撕开就知道账目归属。

**2. 美学家族与参考**
奥斯曼印花税票（1900 年代）。参考三个真实对象：奥斯曼帝国时期的印花税票与骑缝章制度、凹版印刷（intaglio）在纸面上压出的 0.2mm 墨线凹槽、以及同时期欧洲票据的「主联加存根联」二联式单据。偷的机制是「存根联不是为了留档而存在，它是被撕下来才生效的」，以及「凹版印的线是压进纸里的，摸得到」。我们拿的是撕口与压线，不是拿异域花纹与货币符号。

**3. 配色系统**
背景色 `#E1D6BD` 税票纸（未涂布证券纸，色相 41.7°、饱和 16%、明度 81.2%，情绪：矜持）52%；主色 `#5A2A50` 凹版紫墨（色相 312.5°、明度 25.9%，脏色，情绪：沉静）30%；强调色 `#7A2E2E` 印花红（色相 0°、明度 32.9%，脏色，情绪：印信）10%；次级纸色 `#C9BFA6`（存根联专用压纸色，本方案唯一的背景色是 `#E1D6BD`，此色不作背景，情绪：留档）8%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色、`#3B82F6` 那一类默认蓝与纯白底：证券纸的纸色比纯白低 9 级亮度，主墨改成含铁紫墨（色相 312.5°），距 `#3B82F6` 的 217° 有 95°、距 `#8B5CF6` 的 258° 有 54°，印花红只用在印章与合计两处，不做按钮底色。对比度实测（脚本计算）：主色 `#5A2A50` 对背景 `#E1D6BD` 为 7.73:1，强调色 `#7A2E2E` 对背景 6.45:1，两者都在 AA 正文线以上；主色块上的文字用纸色 `#E1D6BD`（7.73:1），`#111111` 压在紫墨上只有 1.69:1，不采用。

**4. 字体策略**
中文主字体用文津宋体（免费商用，发布页须复核，老宋窄排刻版，字距压到 0.02em）；拉丁标题用 `Literata`（OFL 1.1，电子书原生衬线，字腔开阔、小字号稳定）；数字与金额用 `Sometype Mono`（OFL 1.1，等宽，字面比同类等宽更窄更硬，小数点可对齐）。分工：单据抬头与条款标题 = Literata 加文津宋体窄排；明细行文字 = 文津宋体 14px / 行高 1.6（票据行距比正文紧）；金额、税率、编号 = Sometype Mono 并启用表格数字特性以保证小数点垂直对齐。为什么不像 AI 选的：AI 默认字体栈里没有窄排刻版宋，也没有一款等宽体被指定承担「小数点对齐」这种具体任务；这里展示与正文都属于有刻版来源的衬线体系，靠窄排与行距把票据的紧凑感做出来，而不是靠一款几何无衬线。

**5. 布局与网格**
12 栏，基线 8px，明细行的行高固定 24px（3 个基线单位），金额列宽固定 96px 且右对齐。不对称方式：主联占 4–12 栏，存根联占 1–3 栏，两联之间是齿孔线而不是边框；骑缝章横跨两联，盖章中心固定偏离齿孔线 2mm，且只盖在合计行所在的水平位置。留白节奏：明细行之间不留额外间隙（靠 1px 浅色行线分隔），小计与合计之间空 2 个基线单位并加一条 2px 的凹版压线。滚动行为：明细行随滚动增量加载，每批 20 行，新行从下方 12px 处落位；齿孔线与合计行固定在视口底部上方 64px，始终可见。

**断点具体行为**
≥1440px 主联与存根联左右并排（存根 25%，主联 75%），金额列固定 96px；1024–1439px 存根联折到主联下方并保留齿孔线，金额列压到 80px；<1024px 转为单联竖排，齿孔线改为顶部的横向撕口，明细行改为两行一组（上行项目、下行金额），金额不再右对齐而改为行末紧跟，合计固定在页脚。所有触屏断点下，撕存根的点击热区不小于 44px 高。

**6. 关键视觉元素（≥3 个）**
一是齿孔撕边，孔径 1.2px、孔距 6px，只出现在存根联一侧，孔的边缘有 0.5px 的纸纤维毛口，撕开后毛口加宽到 1px；二是骑缝章，暗红实印，跨越两联且固定偏移 2mm，章面有明显的双色套印错位（错位 0.8px），边缘保留印泥外溢的 4% 不透明度晕边；三是凹版印花税票，票面细线固定 0.4px 与 0.8px 两级线宽，花瓣与数字处用平行影线表现深浅，线是压进纸里的因而在 45° 侧光下可见凹槽；四是图标逻辑，自绘税票几何符号，24 单位网格、0.8px 方头单线，税票用「齿孔外框加中心星」、骑缝用「跨栏方框加斜线」、已销账用「双横杠缺口圈」，绝不用任何 Emoji；五是图像处理，所有扫描图先灰度化再压到主墨与纸色两个色阶，保留印泥的边缘晕散，禁止套用纸张纹理贴图。

**7. 动效与交互**
滚动：明细行每批 20 行从下方 12px 落位，单批 200ms，缓动性格为阻尼无过冲；悬停：明细行底色转为 `#DFD6BF` 并显示该行税票编号，120ms，无位移；加载：先出纸色与齿孔线，再逐行压出明细，合计最后落位，总时长 900ms，缓动为阶跃式；转场：账期切换用 180ms 硬切并伴随骑缝章盖章一次（缩放从 1.08 到 1.0）；光标：14px 十字加 1px 方框，进入金额列时方框变为票据外框形；微交互：点击「撕下存根」时存根联沿齿孔线向右位移 6px 并露出纸纤维毛口，之后回位，320ms。降级：`prefers-reduced-motion: reduce` 时取消逐行落位与盖章，行直接出现，撕存根改为 100ms 不透明度变化，齿孔线与合计仍保持固定可见。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.6「白 / 灰交替分区」：全站只用 `#E1D6BD` 一种底，分区靠齿孔线、压线与行线完成；跳脱之处在于分区物是可以被撕开的物理结构。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部容器直角，页面唯一的高度差来自凹版压进的 0.2mm 墨线凹槽与骑缝章的印泥厚度，没有投影。第三，反 C-2.14「3 / 6 / 9 等量图标网格」：明细行数量随账期变化（示例为 27 行），金额不等量、行高统一但内容长短不一。第四，反 R-28 与 C-4：本方案不写「严谨」「专业」这类形容，票据的可信度由 0.4px 与 0.8px 两级线宽、2mm 盖章偏移与小数点对齐三个数承担。

**9. 反 AI 味风险与规避**
最易滑向「复古票据风贴图」：一旦把整页调成褐黄并叠一张做旧纸张贴图，就与大量复古模板撞车。规避动作三条：一是纸色只允许 `#E1D6BD` 一个值，整体偏中性而非褐黄，主墨占 30% 且已换成含铁紫墨（色相 312.5°），与褐黄不落在同一个色相里；二是记忆点必须落在齿孔 1.2px 孔径、6px 孔距与 2mm 盖章偏移这三个可测值上；三是禁止纸张纹理贴图与暗角，任何做旧只能来自线宽与压线。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是财务对账、税务与票据类 B 端系统，用户需要逐行核对并留档；二是档案馆与出版机构的票据专题数据库、钱币与印花收藏展示页。不适合：需要情绪化叙事的品牌首页，本方案的视觉主角是行与线而不是画面；也不适合面向大众泛用户的移动端消费产品，密集明细行在小屏上阅读成本偏高。

**可直接上线的文案**：主张句「本期应缴 12,480.00 元，其中 3 笔跨月未销账」；按钮「撕下存根联，导出 CSV」；空状态「这个账期还没有税票登记。导入 3 月的对账文件即可开始」；错误状态「存根联与主联编号不一致（错误码 STUB-17，两联相差 1 号）：合计行已锁定，导出前须先完成骑缝章校验」。

**11. 可落地要点**
CSS 思路：齿孔用 SVG `<pattern>` 画圆孔并配合纸纤维毛口位图，不使用任何 CSS 色彩插值写法；小数点对齐用等宽字体加 `font-variant-numeric: tabular-nums` 并把金额列设为 `text-align: end`；骑缝章用一张带透明通道的 PNG 覆盖两联，偏移量由 CSS 变量控制以复用同一张章面。栅格单位：12 栏、8px 基线、24px 行高、96px 金额列。字体加载：文津宋体按 GB2312 一级字库子集，Literata 只取 Regular 与 Italic，`font-display: swap`。图片处理：税票纹样做成单色 SVG，扫描件灰度加双色阶后输出 AVIF，印泥晕边用 4% 不透明度的独立图层。性能预算：首屏 JS ≤ 48KB（gzip），字体 ≤ 420KB，明细行虚拟滚动只渲染视口内 40 行，LCP ≤ 2.0s。本方案最难被复用到别的品牌的地方，是两联的宽度比与 2mm 盖章偏移：没有存根联需求的品牌套上去，齿孔线就成了多余装饰。

**12. 设计师签名式怪癖**
存根联顶部的单据编号旁，永远多出一枚倒置的 1.2px 齿孔，位置在第 3 孔与第 4 孔之间。它来自连张印刷被裁切机多打一孔的实况，不影响撕口对齐，存在的理由是把「这张票是从一整版上裁下来的」这件事留在单张上。
