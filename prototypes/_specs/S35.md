# S35 单案规格

> 源：`deliverables/75-q2/05-N32-N35-DESIGN.md`（Q2 新增）
> 原标题：方案 35｜灰蓝终端报（Ash Terminal Sheet）
> 本案补「荒诞幽默 / 玩心 + 冷浅底 + 终端结构」这个全库没有的组合。

---


**结构类型**：R（TERMINAL） ｜ **认知门槛**：中 ｜ **调性**：荒诞幽默 / 玩心

**1. 一句话视觉定义**
整页是一台自动售货机的输出窗口：七条"命令 + 输出"从上到下排开，命令行前面有一个提示符、输出行缩进 22px 跟在后面；命令与输出之间**没有分隔线**（靠缩进与提示符区分），警告行用 3px 左边框而不是横线——底色通体灰蓝（`#DCE0E4`），全页只有一张程序生成的终端纹理。

**2. 美学家族与参考**
1970 年代**行式打印机输出**（line printer）与当代机器的自述文体。参考三个真实对象：早期 UNIX 系统里 `ls` / `who` / `uptime` 那类纯文本输出的排版（内容即界面）、日本「からくり」机械人偶的说明书（器物以第一人称交代自己能做什么、不能做什么）、以及 Douglas Adams 笔下 Marvin 那类"机器抱怨自己"的文体传统。偷的机制是「**内容以命令的形式组织**」：不是"分区 + 标题 + 段落"，而是"一条命令 + 它的输出"，让每一块内容都带着"这是被查出来的"这层语气。

**3. 配色系统**
背景色 `#DCE0E4` 灰蓝（HSL 210°/13%/88%，情绪：打印纸）74%；正文 `#1A1E22`（对底 **12.63:1**）16%；次级 `#454C53`（对底 **8.1:1**）6%；提示符与弱信息 `#6B7480`（对底 **4.6:1**）3%；结构线 `#8A939C`（对底 **3.2:1**，非文本满足 3:1）1%，面积和 100。

⚠️ **冷浅色带此前全库只有 S24 一案**（`#E6EDF2`）。本案用 210° 但明度 88%、饱和 13%，比 S24 更灰、更接近打印纸——同一条带里两个案子能区分开，靠的是饱和度与明度的差而不是色相。

**4. 字体策略**
中文正文 `Noto Serif SC` 400/700（OFL 1.1）；拉丁标题 `Jost` 500（OFL 1.1）；命令行、提示符、meta 与错误码 `Sometype Mono` 400/600（OFL 1.1，等宽是终端隐喻的必需品——不用等宽这个隐喻就不成立）。分工：H1 与节标题 = Jost；输出正文 = 思源宋 400；`stock --check --expired` 这类命令与 `VEND-35` = Sometype Mono。为什么不像 AI 选的：AI 做"终端风"会给纯黑底 + 荧光绿 + 闪烁光标，那是游戏里的终端；本案是**打印纸色的终端**——1970 年代行打机输出在连续纸上的样子，不是 CRT。

**5. 布局与网格**
基线 6px，正文 16px／行高 1.74，外距 40px。命令行与输出行的**缩进关系**是本页的骨架：命令 0 缩进 + `$` 提示符，输出 22px 缩进。这个 22px 是固定的，不随断点缩放（只在 <768px 压到 14px）。留白节奏：命令块之间 30px、块内段落 8px、警告行上边距 10px。滚动行为：七条命令依次淡入，间隔 40ms。断点具体行为：≥1024px 输出行 22px 缩进、note 编号列 92px；768–1023px 编号列 78px；<768px 输出缩进压到 14px、note 改单栏、按钮满宽、错误块纵排。

**断点具体行为**
≥1024px 22px 输出缩进 + 92px note 列；768–1023px 78px note 列；<768px 输出缩进 14px、note 单栏、按钮满宽、错误块纵排。

**6. 关键视觉元素（≥3 个）**
一是**提示符与缩进**，命令行前的 `$`（由 `::before` 生成，不是文字）与输出行的 22px 缩进，这是唯一的记忆点；二是**警告行**，`border-left: 3px solid` + 等宽字 + 英文小写原文（`warning: 3 expired SKUs remain in bay 2.`），模拟 stderr；三是**无分隔线的命令块**——命令与输出之间、命令与命令之间都没有横线，全靠缩进与间距；四是图标逻辑——**不用任何图标**，替代它的是提示符；五是图像处理——唯一一张位图是程序生成的终端输出纹理（1200×800，3:2，34px 行距、一条被覆盖的旧行、3px 扫描线）。

**7. 动效与交互**
入场：七条命令与 note 条目依次淡入，40ms 间隔，240ms 线性，**只变 opacity**（不用 transform——位移会让"终端输出"变成"卡片飞入"，那不是这台机器的语气）。悬停：按钮 `opacity` 到 0.82，200ms。加载：无整块淡入。转场：无。光标：默认。微交互：无。降级：`prefers-reduced-motion: reduce` 时取消逐条淡入，改成所有块一次性到位 + **命令行提示符加粗到 700**（"提示符站着"），缩进数值 22px 一字不改。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.15「纯黑底 + 荧光绿」这条终端刻板印象：底色是打印纸色 `#DCE0E4`、正文是墨色 `#1A1E22`，全页无纯黑无荧光色。第二，反 C-2.11「圆角卡片 + 柔和投影」：零圆角、零 `box-shadow`、零渐变。第三，反 C-1.6「交替分区」：一个底色，分区靠缩进与间距，没有一条横线。第四，反「终端风必带闪烁光标 + 打字机动画」：本案没有任何光标动画，入场只是淡入。第五，反 C-2.14「图标网格」：全页零图标。

**9. 反 AI 味风险与规避**
最易滑向「赛博朋克终端皮肤」：一旦换成黑底荧光绿、加上扫描线动画与闪烁光标，就与大量开发者作品集撞车。规避动作三条：一是底色锁死打印纸色，**不允许黑底**；二是记忆点必须落在提示符与 22px 缩进上，不加光标动画；三是零圆角零投影零渐变。另有一条反向风险：**「荒诞幽默」容易被做成段子集**——本页的荒诞是克制的：一台售货机自述它垫了 ¥47 给买不起东西的小孩、它不喜欢被拍照、它修不好自己的电机。荒诞在这里是**视角**，不是笑点。

**10. 适用场景（≥2 类，并附「不适合」）**
适合三类项目：一是**以器物或系统为叙述者**的品牌页（设备、工具、服务系统），第一人称能解释很多"为什么这样设计"；二是**技术产品的状态页 / 更新日志**，命令式组织天然对应；三是需要**幽默但不轻浮**调性的独立项目（个人工具、小众硬件）。不适合：需要庄重感的政务与企业官网（这个语气太随意）；面向非技术用户的产品（命令式有门槛）；电商与任何以商品图为主要决策依据的页面。

**可直接上线的文案**：主张句「这台机器想跟你说几句话」；按钮「买瓶水，我多给你半秒」；空状态「这会儿我什么都不想说。明天再来，或者按一下 12 号键，那里有一包还没到期的饼干」；错误状态「今天下午三点到五点我要停机检修——压缩机要除霜，除霜的时候我不能出货。我会在停机前十分钟把屏切成倒计时，让正在走过来的人知道（错误码 VEND-35）」。

**11. 可落地要点**
CSS 思路：提示符用 `.cmd-line::before { content: "$" }` 而不是把 `$` 写进 HTML——因为它是**生成物**（每条命令都有，但不属于命令文本），写进 HTML 会让屏读器把每个 `$` 读出来；缩进用 `margin-left: 22px` 而不是 `padding`，因为它是"输出相对命令的位置"，不是内边距；警告行用 `border-left: 3px` 而不是 `border-bottom`，因为终端的 stderr 是**侧边标记**不是分隔。栅格单位：6px 基线 / 40px 外距 / 22px 输出缩进 / 30px 块距 / 34px 纹理行距。字体加载：三族各取实际字重，`font-display: swap`。图片：唯一一张 PNG 用确定性脚本生成，重跑逐字节相同。性能预算：关键路径零 JS（`self.js` 只做渐进增强），首屏 ≤ 190KB（字体 ≤ 170KB + 图 21KB），LCP ≤ 1.3s。最难被复用到别的品牌之处：**第一人称的器物叙述**——没有一个"器物视角"的叙事，命令式排版就只是装饰。

**12. 设计师签名式怪癖**
第五条命令（投诉）的输出里，有一条警告行的左边框比其余几条粗 1px（4px 而非 3px）。它来自真实终端里"这条错误更严重"时人手工在旁边划的一道。不影响阅读，存在的理由是让这台机器承认"有一条投诉它到现在还委屈"。

**自评：8.5/10**
依据一：字段 3 五色面积和为 100，冷浅色带此前只有 S24 一案，本案用更灰更接近打印纸的同色相区分开。依据二：字段 6 的三个元素全部带可测参数（22px 缩进 / 3px 警告边框 / 34px 纹理行距），与 S18 的 TERMINAL（磷光绿机房挂牌）在媒介上互不重复：S18 是 CRT 荧光，这一案是**行打机打印纸**。依据三：`minPics = 1`，且调性「荒诞幽默 / 玩心 + 冷浅底 + 终端」这个组合全库没有。
