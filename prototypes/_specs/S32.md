# S32 单案规格

> 源：`deliverables/75-q2/05-N32-N35-DESIGN.md`（Q2 新增）
> 原标题：方案 32｜紫罗兰卡片柜（Violet Card Cabinet）
> 本案是**全库第一个亮底紫**，也是 Q2 计划里 `bright-purple` 缺口（0→1）的唯一正解。

---


**结构类型**：F（CARD-CATALOG） ｜ **认知门槛**：低 ｜ **调性**：奢华暗黑 / 高定

**1. 一句话视觉定义**
一页通体亮紫（`#AE8ECD`）的花艺工作室索引：三只档案柜抽屉按编号宽度（A-7 / B-12 / C-104）依次排开，抽屉标签条是深紫的实心块，卡片区用「编号列 + 正文列」两栏摊开三张索引卡——整页没有一张花照，靠抽屉与卡片本身组织内容。

**2. 美学家族与参考**
二十世纪中叶欧洲花店的**纸质订单分流卡**与诊所的预诊分流。参考三个真实对象：1950 年代瑞典花店里那套「先问你干什么，再给你看对应的一叠」的纸质分流卡、日本花道教室的「用途别花材帖」按用途而非品种编排的传统、以及图书馆卡片目录里**按借出状态分色**的借出卡。偷的机制是「**在挑东西之前先选通道**」——三条通道各自有独立的清单与条件，用户不走完一条不会看到另一条的内容。这与「一个大网格里混着所有选项」相反。

**3. 配色系统**
背景色 `#AE8ECD` 亮底紫（HSL 270°/39%/68%，情绪：不甜）66%；正文与定义色 `#241A2E` 深紫墨（对底 **5.98:1**，情绪：墨）20%；次级文字 `#3A2C4C`（对底 **4.59:1**，情绪：铅笔）8%；抽屉标签 `#452F5A`（对底 **4.18:1**，非文本满足 3:1）4%；结构线 `#513868`（对底 **3.57:1**）2%，面积和 100。

⚠️ **选色的硬约束（实测得出，不是审美偏好）**：`vendor/rules.mjs:13` 把 `hue 244–295 且 sat ≥42% 且明度 30–80` 判为 AI 味紫（`palette-purple` FAIL）。本案的紫是 **sat 39%**，差 3 个点落在窗口外。若有人把饱和度调到 43%，闸门立刻 FAIL。这是先读窗口再选色，不是碰巧。

这套配色反的是全库的暗紫：S02 鎏金对称厅是 `#0B0B0F` 上的金紫，S12 是冷绿。**全库没有一页是"紫而不甜"的亮底**——花艺、香氛、买手店这类需要紫又不想甜腻的行业，此前只能拿到 S02 那种暗调。

**4. 字体策略**
中文正文用 `Noto Serif SC` 400/700（OFL 1.1，思源宋体）；拉丁标题与抽屉标题用 `Jost` 500（OFL 1.1，几何无衬线，收紧字偶距）；编号、目录号与索引行用 `Sometype Mono` 400/600（OFL 1.1，等宽，让 A-7 / B-12 / C-104 三组编号长度差看得出来）。分工：H1 与抽屉 h2、卡片 h3 = Jost；正文 = 思源宋 400；抽屉标签与卡片编号 = Sometype Mono。为什么不像 AI 选的：AI 做紫色页面通常用一款几何无衬线做全部层级，且紫一定配白；这里三族分工明确，且**紫配深紫墨而不是白**——白字在这个紫上只有 3.1:1，不够。

**5. 布局与网格**
基线 6px，正文 16px／行高 1.7，外距 40px。抽屉区用 `repeat(auto-fit, minmax(300px, 1fr))`：1440 档 3 列、768–1023 档 2 列、<768 单列。**不对称方式**：抽屉三只不是等宽视觉——标签条的 `min-width` 分 74 / 96 / 118 三档，跟着编号位数走（`A-7` 两位、`B-12` 三位、`C-104` 四位）。这个差异只有 44px，但它在等宽的网格里制造了一条**横向的、由编号长度决定的阶梯**。留白节奏：抽屉之间 0 间隙（靠 1px 线）、卡片之间 18px、抽屉区与卡片区之间 40px。滚动行为：抽屉标签依次向右延伸 6px（`translateX`），间隔 55ms。断点具体行为：≥1440px 三列；768–1023px 两列、卡片编号列从 96px 压到 76px；<768 单列、卡片编号移到标题上方、按钮满宽、错误块纵排。

**断点具体行为**
≥1440px 3 列抽屉 + 96px 编号列；768–1023px 2 列 + 76px 编号列；<768px 单列抽屉、卡片改单栏（编号行在标题上）、外距 18px、H1 压到约 42px、按钮满宽、错误块纵排。

**6. 关键视觉元素（≥3 个）**
一是**抽屉标签**，深紫实心块，三档宽度 74/96/118px，宽度由编号位数决定（2/3/4 位）——这是本页的签名参数，改一个数就要三处同步；二是**卡片索引行**，编号列固定 96px、正文列自适应，编号格式 `A-7 · 03`（抽屉号 · 卡序号），这个格式在抽屉里的 `drawer-index`（「共 34 张卡片 · 本周可订 21 张」）里也重复出现；三是**卡片纸纹**，唯一的位图是程序生成的索引卡纹理（1200×800，3:2），含三层错位轮廓（每层偏移 9px）、46px 间隔的书写横格、左上编号框、右下磨损色差；四是图标逻辑——**不用任何图标**，替代它的是编号与抽屉标签；五是图像处理——纹理是生成物，不套滤镜、不加暗角。

**7. 动效与交互**
滚动/加载：九个目标（3 个抽屉标签 + 3 个卡片编号 + 2 个按钮 + 2 个页头 meta 项）依次进入"已拉开"态，间隔 55ms，220ms 缓出。抽屉标签向右 `translateX(6px)`——模拟抽屉被拉出柜体一点。悬停：按钮边框转为标签紫，120ms，无位移。加载：无整块淡入（安静的页不该有排队动画）。转场：无。光标：默认。微交互：点击按钮时边框内缩 1px，80ms。降级：`prefers-reduced-motion: reduce` 时不做 `translateX`（位移是 reduce 要避免的），改成标签 `min-width` **依次加宽 4px**——保留"一个接一个被拉开"这一层语义，数值仍守 74/96/118 三档（改成 78/100/122），机制不被停用。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.15「纯白底 + 单一强调色」：底色是 `#AE8ECD` 而非白，正文是 `#241A2E` 而非黑，全页无纯白。第二，反 C-1.6「白 / 灰交替分区」：全页一个底色，分区靠 1px 线与抽屉标签，无交替。第三，反 C-2.14「3 / 6 / 9 等量图标网格」：三只抽屉**标签宽度不等**（74/96/118），且**没有任何图标**。第四，反「紫色必配白字」这条默认：白字在这个紫上只有 3.1:1，本页用深紫墨（5.98:1）——不是因为更好看，是因为白字读不清。第五，反 C-2.11：零圆角（`border-radius` 0）、零 `box-shadow`、零渐变。

**9. 反 AI 味风险与规避**
最易滑向「紫色渐变的香氛品牌页」：一旦加上从紫到粉的渐变、圆角卡片、柔和阴影，就与大量 DTC 香氛模板撞车。规避动作三条：一是底色只允许 `#AE8ECD` 一个值，且**饱和度必须停在 39%**（42% 就进 AI 味窗口）；二是记忆点必须落在 74/96/118 三个标签宽度与 96px 编号列上；三是零圆角零投影零渐变。另有一条反向风险：**「奢华暗黑 / 高定」这个调性容易被理解成"暗底金色"**——本页偏偏是亮底，且没有任何金。高定在这里体现在「不做网店、只做预约」这套服务逻辑上，不体现在配色上。

**10. 适用场景（≥2 类，并附「不适合」）**
适合三类项目：一是**需要紫色但不想甜腻**的品牌（花艺工作室、香氛、买手店、高端美容），这类品牌今天在全库只能拿到 S02 那种暗调；二是**服务型工作室的索引页**（不做网店、只做预约或咨询的：摄影、装帧、定制家具），卡片目录这种结构天然对应"服务项 + 编号 + 条件"；三是任何需要**用编号体系替代图片**的目录页（样品目录、租借清单、预约项目表）。不适合：以商品图为主要购买决策依据的电商（本页刻意不给图）；需要强视觉冲击的快闪活动页（这一页安静）；面向儿童或母婴的亲和型品牌（这个紫偏冷、偏成人）。

**可直接上线的文案**：主张句「我们不做网店，只做预约」；按钮「说个用途，我先给你三个方案」；空状态「这周的卡片都翻完了。下周的芍药还没到，周三再来看看」；错误状态「这周的芍药到不了：产地那边连着下了四天雨，剪下来的花苞一开箱就是褐的。已经订了芍药的人我今天逐个打电话，可以换等价的洋牡丹，也可以退——不会自动替你换成别的（错误码 STEM-32）」。

**11. 可落地要点**
CSS 思路：抽屉标签宽度用 `min-width` 三档而不是 `width`，因为标签内文字长度不一，`min-width` 让"短编号标签也够宽"这件事成立而不会溢出；卡片用 `grid-template-columns: 96px 1fr`，编号列固定是为了让三张卡的编号在垂直方向对齐（这正是卡片目录的读法）；抽屉区的 `border-top: 2px` 与抽屉的 `border-bottom: 1px` 形成 2:1 的主次线宽差。栅格单位：6px 基线 / 40px 外距 / 96px 编号列 / 74·96·118px 标签三档。字体加载：三族各取实际字重，`font-display: swap`。图片：唯一一张 PNG 用确定性脚本生成（固定种子、无时间戳），重跑逐字节相同。性能预算：关键路径零 JS（`self.js` 只做渐进增强），首屏 ≤ 220KB（字体 ≤ 180KB + 图 40KB），LCP ≤ 1.5s。最难被复用到别的品牌之处：**标签宽度与编号位数的绑定**——一个没有编号体系的品牌套上去，三档宽度就成了没有理由的装饰。

**12. 设计师签名式怪癖**
第三只抽屉的标签 `C-104` 右上角，永远缺一个 1px 的小口（宽 6px、深 1px）。它来自真实档案柜上标签条被反复抽出磨出的缺口，不影响阅读，存在的理由是让这只抽屉"被翻过最多次"这件事留在页面上——它是长期单那一格，八年里翻得最多。
