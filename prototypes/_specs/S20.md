**结构类型**：R（GENERATIVE） ｜ **认知门槛**：高 ｜ **调性**：冷静克制 / 工程感

**1. 一句话视觉定义**
一张 1:1 的白色图纸贴在墙上，一支 0.35px 的针笔用单线把声音走成一层层不交叉的等高线，右侧挂着参数面板，滚动页面等于拧参数旋钮，图形随每一次滚动重绘。

**2. 美学家族与参考**
参数化生成印刷（2020 年代荷兰数据驱动设计）。参考三个真实对象：荷兰数据驱动设计工作室的绘图仪（pen plotter）作品、工程图纸上的声压级等高线与等值线标注法、以及早期示波器记录纸上的单线走位。偷的机制是「针笔是一次成线的，它不能回头也不能填色，所以图形的密度只能靠走线间距表达」，以及「参数变一次，图就整体重排一次，图与参数是同一个对象的两面」。我们拿的是单线走位与滚动即调参，不是拿波形的装饰曲线。

**3. 配色系统**
背景色 `#FAF3E1` 图纸白（针笔绘图纸的高亮微暖白，色相 43.2°、饱和 10%、明度 93.1%，情绪：精密）52%；主色 `#26485C` 针笔墨蓝（色相 202.2°，明度 25.5%，脏色，情绪：测量）30%；坐标与暗部 `#0F1418`（明度 5%，脏色）12%；辅助针笔墨 `#55606B`（明度 37.6%，脏色）6%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「深色底加青色发光」的科技页套路，也反纯白底：图纸白比纯白低 5 级亮度且偏暖 2 级，主色是带灰的墨蓝而不是饱和蓝，全部图形只有线没有发光与填充。

**4. 字体策略**
标题与参数标签用 `Space Grotesk`（OFL 1.1，几何骨架加工程图纸式的窄字腔）；中文用思源黑体（OFL 1.1，字重齐全，作中文主字体）；坐标与参数读数用 `Martian Mono`（OFL 1.1，可调宽度等宽）。分工：标题与参数分组名 = Space Grotesk 加思源黑体 Medium（字距 -0.01em）；说明文字 = 思源黑体 Regular 15px / 行高 1.8；坐标、段数、频率 = Martian Mono 窄档。为什么不像 AI 选的：我们不用 Inter 这一类默认栈，也不用「几何无衬线加圆润无衬线」的搭配程序，那三款都宽字腔且都偏友好；这里拉丁标题用窄字腔的工程骨架，中文用字重可调的思源黑体，读数用等宽，三类的任务边界清晰，字面宽度从窄到宽形成一条可解释的梯度。

**5. 布局与网格**
12 栏，基线 8px。绘制区是一张严格 1:1 的正方形画布，边长跟随视口高度减 96px；参数面板占右侧 3 栏，低于画布顶边 32px，因此画布与面板的上边缘不对齐。不对称方式：画布整体左偏 8%，画布内图形的重心再由参数决定，通常偏离几何中心 4% 至 12%，页面任何时刻都不对称。留白节奏：画布四周留 24px 白边（绘图仪的走纸安全区），参数分组之间空 4 个基线单位，组内参数行间距只有 1 个基线单位。滚动行为：滚动量映射为参数值而不是位移，每滚 100px 相当于频率档位走一格，图形在 60fps 内实时重排；画布本身不移动、不缩放、不视差。

**断点具体行为**
≥1440px 保持 1:1 画布与右挂 3 栏参数面板，重绘 60fps；1024–1439px 参数面板折到画布下方并横向排成 3 列，画布边长改为视口宽减 120px 但仍保持 1:1，重绘降到 45fps；<1024px 画布缩到视口宽减 24px，参数仍由滚动驱动（每滚 90px 走一格，滚动量到参数的映射关系完整保留），底部另加三个滑杆（频率 / 振幅 / 走线间距）供触屏精调，滑杆与滚动作用于同一组参数、互不覆盖，重绘降到 30fps 并对走线段数设 4000 段上限，键盘左右键可逐格微调滑杆；<768px 画布缩到视口宽减 16px，三个滑杆改为纵向两行排列，滚动驱动与 4000 段上限不变。

**6. 关键视觉元素（≥3 个）**
一是绘图仪针笔单线走位，线宽 0.35px 单线，走线不回头、不交叉复位，线端方头，禁止任何填充色块与粗描边；二是坐标网格，0.2px 浅线、间距 8px，只在画布白边内出现且不透明度 18%，网格与走线之间不允许叠加第三种线；三是声场图例，量级用走线间距表达（间距 0.6px / 1.2px / 2.4px 三级分别对应三个量级），不使用颜色区分，图例本身也由三小段真实走线构成；四是图标逻辑，自绘绘图仪符号，20 单位网格、0.5px 单线，笔架用「倒梯形加竖针」、走纸轮用「圆加八个齿」、原点用「两个同心方框」，绝不用任何 Emoji；五是图像处理，本方案不引入任何位图纹理与颗粒，所有图形一律矢量化输出，以此与全批其它方案的颗粒材质拉开距离。

**7. 动效与交互**
滚动：滚动量映射为参数，参数变化触发图形重排，重排时长 420ms，缓动性格为阻尼无过冲（重绘过程中旧线淡出 30% 而新线逐段画出）；悬停：把指针移到某条等高线上，该线加粗到 0.5px 并显示该线的声压级读数，140ms；加载：画布先出网格，再让针笔从原点起笔按走线顺序画完，总时长 1400ms，缓动为线性（模拟笔的恒速）；转场：切换音频样本时整张图在 240ms 内被「擦除」为空白再重绘；光标：16px 细十字加 0.35px 单圈，与图上的线宽一致；微交互：拖动参数滑杆时，画布右下角的段数读数实时跳动但不做补间。降级：`prefers-reduced-motion: reduce` 时取消实时重排与逐段画出，参数变化改为 120ms 直接替换整图，滚动不再调参只做正常滚动，滑杆仍可用。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.10 与 C-1.5「弥散渐变与抽象球体代表科技」：主视觉是单线走位的矢量化声场图，页面既没有色彩插值写法，也没有渲染图形，图的形状完全由输入音频与参数决定。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部容器直角，面板与画布之间靠 1px 线与留白分隔，不存在投影。第三，反 `01-research-brief.md` F 节 P11「网格背景加虚线边框加玻璃卡片三层叠加」：本方案的网格只有 0.2px 且不透明度 18%，且网格在画布内被真实走线覆盖，不构成背景装饰层。第四，与 24 号、29 号的机制隔离：24 号靠叶脉分叉与孢子节点做路径选择，29 号靠爆炸图与 45° 警示斜纹，本方案的图形语言是单线不交叉走位且禁止填充与斜纹，三者的图形语法互斥。

**9. 反 AI 味风险与规避**
最易滑向「深色数据可视化大屏」：一旦把画布换成深底、加上发光描边与图例卡片，就退回成常见的数据看板。规避动作三条：一是底必须是图纸白且只允许一个值，禁止深色模式切换；二是图形只允许 0.35px 单线，禁止发光、禁止填充、禁止色彩插值；三是图例必须由真实走线段构成，不允许做成带圆角的图例卡片。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是音频、声学、传感器与测量仪器类产品的官网与产品页，图与参数是同一个对象，能直接呈现设备在做什么；二是数据可视化工具与生成艺术工作室的作品集，参数驱动的重绘本身就是展品。不适合：需要情绪化叙事的品牌首页，本方案没有图像与色彩冲击；也不适合移动端为主要入口的消费产品，参数调参与密集细线在小屏上都难以成立。

**可直接上线的文案**：主张句「当前参数：频率 220Hz，振幅 0.62，走线 1840 段」；按钮「按这组参数重绘，保持 3 秒」；空状态「还没有输入音频。把一段 20 秒的录音拖到画布左侧，针笔会走完它」；错误状态「走线段数超出上限（错误码 PLOT-4000）：本次只绘制前 4000 段，把走线间距提到 1.2px 后可完整重绘」。

**11. 可落地要点**
CSS 思路：走线全部用 SVG 路径，`stroke-width: 0.35`、`shape-rendering: geometricPrecision`、`vector-effect: non-scaling-stroke` 以保证缩放下线宽恒定；参数变化时用 `requestAnimationFrame` 每帧只更新路径的 `d` 属性，避免重建节点；不使用任何 CSS 色彩插值写法。栅格单位：12 栏、8px 基线、8px 坐标格、画布 1:1。字体加载：Space Grotesk 只取 Medium 与 Regular，思源黑体按 GB2312 一级字库子集，Martian Mono 只取窄档，`font-display: swap`。图片处理：本方案不引入位图，所有图形矢量输出，导出分享图时再栅格化到 2 倍图。性能预算：首屏 JS ≤ 75KB（gzip），字体 ≤ 450KB，单次重排路径总长设上限（4000 段以内），移动端降到 30fps 并限制每帧重算的路径数，LCP ≤ 2.2s。本方案最难被复用到别的品牌的地方，是参数与走线间距的三级图例映射：换掉音频来源之后，这套映射仍然只对应声压级的量级关系。

**12. 设计师签名式怪癖**
每张图的左下角有一枚 0.35px 的起笔点，它永远比理论原点向左下偏 0.6px，因为绘图仪的针架存在物理回差，设计师把这个误差保留下来而不是校正掉。它不影响读图，存在的理由是把「这条线是机械臂拖着笔走出来的」这件事留在图上。
