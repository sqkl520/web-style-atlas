# 当前有效值（authoritative）— 建原型前必读

> **这份文件是 30 个方案"现在到底什么颜色、什么字体"的唯一权威来源。**
>
> 依据：`04-schemes-01-10.md` §六（L458–476）、`05-schemes-11-20.md` 终局修正记录（L599–664）、`06-schemes-21-30.md` 终局修正记录（L449–467），以及 `06` §F 与 L447 的补充。
>
> **为什么必须有这份文件**：`_specs/Sxx.md` 里的 12 字段是**修正前**的原文。跨文件终局修正轮改掉了大量背景色、主色、字体。**若照 `_specs/Sxx.md` 的字段 3／4 直接建原型，会建成废弃版本。** 已发生实例：S04 的主色在终局轮由 `#E8871E` 改为 `#96550F`。
>
> **冲突时以本文件为准。** 本文件也没写到的，才回 `_specs/Sxx.md`。

## 0 全局硬规则（30 案通用）

| 项 | 值 |
| --- | --- |
| 禁用字体栈 | `Inter` / `Roboto` / `Arial` / `Helvetica` / `system-ui` / `-apple-system` / `BlinkMacSystemFont` / `Segoe UI` **进入 `font-family` 声明的次数必须为 0** |
| 按钮字色 | 各案按实测写死，**见下表最后一列**；不得自行默认白或黑 |
| 装饰色 | 被降级为"装饰性实色块"的颜色**不承载文字与图标**（S29 `#E4B400`、S30 `#00E676`） |
| 错误状态 | 每案必须有一个具体的错误态，**并带下表给出的错误码** |
| 降级路径 | 每案必须有 `prefers-reduced-motion` 降级 |
| Emoji | 功能图标一律不得用 Emoji |
