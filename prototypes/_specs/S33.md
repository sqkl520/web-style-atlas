# S33 单案规格

> 源：`deliverables/75-q2/05-N32-N35-DESIGN.md`（Q2 新增）
> 原标题：方案 33｜青灰对账簿（Teal Mirror Ledger）
> 本案补 Q2 的 `mid-lightness` 缺口（1→2），且刻意用**冷调**而不是暖调。

---


**结构类型**：R（MIRROR） ｜ **认知门槛**：中 ｜ **调性**：温暖手作 / 人味

**1. 一句话视觉定义**
一张通体青灰（`#4A6763`）的对账页：左边一列是客户的原话（带引号），右边一列是落进合同的数，中间一条 1px 竖线从上到下对穿；左栏宽度随原话长短分三档（0.8 / 1 / 1.3），右栏永远等宽——整页没有一张工地照，靠左右对照本身组织内容。

**2. 美学家族与参考**
工程队的**纸质对账单**与日本「見積書」的左右对照传统。参考三个真实对象：日本工务店报价单里「お客様のご要望 / 施工内容」两列并排的排版（左列是客户口述、右列是书面化条款）、民国营造厂的手写工料单（左边业主说的、右边账房记的，中缝用红笔拉一条线对穿）、以及装帧里的「对校」（collation）传统——两栏并置、逐行核。偷的机制是「**原话与数字并置**」：不是"我们承诺了什么"，而是"你说了什么、我们把它变成了什么数"，中间那条线是这两者之间的转换声明。

**3. 配色系统**
背景色 `#4A6763` 冷青灰（HSL 172°/16%/35%，Lab L\* 35.4，情绪：砚台）70%；正文与定义 `#F2F6F5`（对底 **5.65:1**，情绪：纸白）18%；次级 `#D8E4E2`（对底 **4.72:1**）8%；结构线 `#A8C0BD`（对底 **3.21:1**，非文本满足 3:1）3%；深色块 `#2F4744`（对浅字 **9.15:1**，承载文字，非分隔线）1%，面积和 100。

⚠️ **为什么必须是冷调**：全库 18/30 落在暖浅色带，S31 已经占了中性灰。中间明度这一档如果再用暖色，等于把同质化从"暖浅"挪到"暖中"——数字好看，问题没解决。选 172° 的青，是因为全库色相桶里 150–179 只有 S15 一案（那条是冷白描图纸，不是青）。

对比度实测（脚本计算）：正文 5.65:1、次级 4.72:1 均过 AA；结构线 3.21:1 满足非文本 3:1。**深色块 `#2F4744` 对底只有 1.62:1，但它承载的是文字不是分隔线**，判据是它上面的字色 9.15:1，而不是它与底色的比。

**4. 字体策略**
中文正文 `Noto Serif SC` 400/700（OFL 1.1，思源宋体，小字号稳）；拉丁标题与节题 `Jost` 500（OFL 1.1）；数字与条款号 `Sometype Mono` 400/600（OFL 1.1，等宽，让右侧那些 `840mm` / `¥118,400` / `≤5%` 的数值对齐）。分工：H1、节标题 = Jost；客户原话与记账正文 = 思源宋 400；所有数值与 `PLUMB-33` 这类错误码 = Sometype Mono。为什么不像 AI 选的：AI 会把两列都排成同款无衬线，左右对照就失去了"两种声音"的区分；这里的区分靠**字体分工 + 引号 + 字号差（16 / 15）**三层，而不是靠颜色。

**5. 布局与网格**
基线 6px，正文 16px／行高 1.72，外距 40px。每一行是 `grid-template-columns: <左> 1px <右>`，中缝那 1px 是 `.row-tick` 的实色块。**三档左栏比例**：`w1` = 0.8fr / 1.2fr（原话短）、`w2` = 1fr / 1fr（中等）、`w3` = 1.3fr / 0.7fr（原话长）。这个档位不是随机的：它跟着原话的字数走，短的给窄、长的给宽——而**右栏永远等宽的意思**是"记账的格式不变，说话的人每次不一样"。留白节奏：行间 0 间隙（靠 1px 线）、行内 padding 18px、中缝两侧各 22px。滚动行为：每行左栏先到位、右栏稍后，间隔 26ms。断点具体行为：≥1024px 三档比例全生效；768–1023px 三档统一成 1:1（空间不够）；<768 镜像**失效并再发明**——变成上下对照（原话在上、记账在下），中缝 1px 竖线转成 1px 横线，对照关系保留。

**断点具体行为**
≥1024px 三档左栏比例；768–1023px 统一 1:1、note 编号列 74px；<768px 单列上下对照、竖线转横线、note 改单栏、按钮满宽、错误块纵排。

**6. 关键视觉元素（≥3 个）**
一是**中缝竖线**，1px 实色 `#A8C0BD`，贯穿每一行，行与行之间不断开（视觉上是一条连续的线穿过所有行）；二是**三档左栏比例** 0.8 / 1 / 1.3，与本页八行原话的长短对应；三是**原话的引号**，用 `quotes: "「" "」"` 的中文直角引号而不是西文弯引号——这是"原话"这一层的标识物；四是图标逻辑——**不用任何图标**，替代它的是数值本身；五是图像处理——唯一一张位图是程序生成的对账簿纹理（1200×800，3:2，中缝竖线在 x=600、横格 38px、左侧一块擦写痕），不是照片。

**7. 动效与交互**
入场：每行的左栏（原话）先到位，右栏（记账）紧随，间隔 26ms，260ms 线性**只变 opacity**（不变形、不位移——位移会让左右栏对不齐，那是破坏机制）。悬停：按钮边框转 `#A8C0BD`，160ms。加载：无整块淡入。转场：无。光标：默认。微交互：无。降级：`prefers-reduced-motion: reduce` 时不动逐行淡入，改成**整列一次性到位 + 中缝竖线加粗到 2px**——"这条对照线立起来"是机制的再发明形式，数值保留（三档比例 0.8/1/1.3 一字不改）。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.15「纯白底 + 黑字」：底色 `#4A6763`、正文 `#F2F6F5`，全页无纯白无纯黑。第二，反 C-1.6「白 / 灰交替分区」：一个底色，分区靠 1px 线与中缝。第三，反 C-2.11「圆角卡片 + 柔和投影」：零圆角、零 `box-shadow`、零渐变。第四，反「把客户评价做成星级 + 头像」这条默认：客户的声音在这里是**逐条原话 + 逐条数字**，不是一段好评。第五，反 C-2.14「图标网格」：全页零图标。

**9. 反 AI 味风险与规避**
最易滑向「工程感深绿仪表盘」：一旦加上网格背景、等宽大字、荧光强调色，就与大量 SaaS 后台模板撞车。规避动作三条：一是底色只允许 `#4A6763` 一个值，**不允许加网格背景**（那会把"纸"变成"屏"）；二是记忆点必须落在三档左栏比例与中缝竖线上；三是零图标零投影零渐变。另有一条反向风险：**「温暖手作 / 人味」这个调性容易被做成暖色**——本页偏偏是冷青。人味在这里体现在"把你说的原话留着"这个做法上，不体现在配色上。

**10. 适用场景（≥2 类，并附「不适合」）**
适合三类项目：一是**装修 / 施工 / 定制家具**这类"口头承诺多、事后容易扯皮"的服务业——对账表是它们最需要但最少有的东西；二是**咨询 / 设计 / 法务**等按项目计费的专业服务，同样需要"客户说的"与"合同写的"并置；三是任何需要**并列两组相关信息**的页面（改前 / 改后、报价 / 实付、需求 / 实现）。不适合：以商品图为主要决策依据的电商（本页刻意不给图）；需要轻松调性的消费品牌（这个青偏严肃）；单页只有三五行内容的极简站点（对照表要有足够的行才成立）。

**可直接上线的文案**：主张句「你说的话，和我们记的数」；按钮「约个时间，我上门量一次」；空状态「这套房的账还没开始记。量完房我会先给你一张空表，左边留白，等你说话」；错误状态「下个月那户的水电师傅住院了，胆囊手术，休四周。这一户的开工日期要往后挪，具体挪多久我今晚逐个电话说，不在这一页上改——日期这种东西写在网页上，你看的时候可能已经变了（错误码 PLUMB-33）」。

**11. 可落地要点**
CSS 思路：中缝用 `grid-template-columns` 里的 `1px` 轨道 + 一个实色 `div`，而不是 `border-left` —— 因为 border 会跟着行的 padding 走，而这条线要在视觉上**贯穿所有行**，用独立轨道才能做到连续；三档比例用修饰类 `.w1/.w2/.w3` 而不是内联 style，因为档位是内容属性不是表现属性。栅格单位：6px 基线 / 40px 外距 / 三档 0.8·1·1.3 / 中缝 1px / 中缝两侧 22px。字体加载：三族各取实际字重，`font-display: swap`。图片：唯一一张 PNG 用确定性脚本生成，重跑逐字节相同。性能预算：关键路径零 JS（`self.js` 只做渐进增强），首屏 ≤ 200KB（字体 ≤ 170KB + 图 26KB），LCP ≤ 1.4s。最难被复用到别的品牌之处：**"左栏宽度随原话长短变化、右栏等宽"这个不对称**——换一个没有"用户声音"这一层的品牌，三档比例就成了没有理由的装饰。

**12. 设计师签名式怪癖**
第八行（预算那一行）的左栏下方，永远多出 3px 的空白，比其余七行高一点。它来自手写对账单上"这一条被反复算过"的位置——纸被笔尖压出了凹。不影响阅读，存在的理由是让这张表承认"有一行是最难谈的"。

**自评：8.6/10**
依据一：字段 3 五色面积和为 100，底色 Lab L\* 35.4 落在中间明度带，且**刻意选冷调**（172°）以免把同质化从暖浅挪到暖中。依据二：字段 6 的三个元素全部带可测参数（1px 中缝 / 0.8·1·1.3 三档 / 1200×800 + 38px 格距），与 S31 的 SIGNAL-BOARD（尺规刻度）在机制上互不重复：S31 靠刻度替代图，这一案靠左右对照替代图。依据三：`minPics = 1`，同时补 `mid-lightness`（1→2）与 `low-photo`（2→3）。
