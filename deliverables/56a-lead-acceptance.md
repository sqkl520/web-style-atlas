## 二、但它 §4「名不副实」D 档三条，我复算推翻两条半（本席唯一的大面积失守处）

| 它的 D 档指控 | 我的复算 | 裁定 |
|---|---|---|
| **S06**「0.62 递减，CSS+HTML 全搜命中 0 ⇒ 名不副实」 | `0.62` 命中 **5 处**；且 `style.css` 的 `.card:nth-of-type(2/3/4)` 定义 `--off: 59px / 37px / 23px`，比值 0.615 / 0.627 / 0.622 **≈ 0.62** | **假指控**，机制真落地 |
| **S08**「12 列栅格 CSS 里没有对应物」 | `grid-template-columns` 最大轨道确是 3（列数这条对），**但等距核心机制在**：`--step-x:24px; --step-y:12px` 配 `translate3d(calc(var(--l)*var(--step-x)), calc(var(--l)*var(--step-y)*-1))`——正是字段 5 的「每层 (24px 横, 12px 纵)」 | **判错重心**，机制落地 |
| **S25**「10 栏栏距 18px 无对应物」 | `column-count` 0 处、`repeat(10` 0 处；但 `18px`/`44px`/`56px` 均在 CSS 出现 | **部分成立**（10 栏确实没实现） |

**失守机制**：三条都犯「搜不到就判不存在」。它在 `index.html` 搜 `--off`，值其实在 `style.css`。

**坦白**：我第一轮复算也**差点顺着它走**——同样只搜 `index.html`，得 `--off` 命中 0，正要接受它的结论；补搜 CSS 才见真相。**我自己也在同一个坑里，只是多走了一步。**

本项目的教训登记到此已第 4 次同型（S19 改名漏引用 / S24 只搬两行 / tools 蒸发被旧报告掩盖 / 本席"搜不到=不存在"）：**判「某物不存在」之前，先证明「我搜全了每一层」。**

**处理：D 档作废，不据它改判任何案；§1/§2 作为有效交付采纳。**

## 三、据它已实测数据的定稿合成（非代作审美判断）

**§5 它没填完的裁定，据其 §1/§2 实测可下这几条**（引的都是它自己的数字）：

- **全批构成层最实的两案**：**S15（CONS 第 1）与 S28（CONS 第 2）**——共同硬指标是留白档 35–36（全批最富）、机制 7/7 落地、每屏词 81–85。这两案是「如果只能拿两个出去」的答案。
- **全批最严重的构成缺陷 = 字重坍塌**（18/30 ≤2 档、5 案单档）。它与 52 席的「主张层 30/30 同型句式」是**同一个病的两个轴**：
  **说同一句话 × 只用一根对比轴（字号）撑层级。**
- **离「每案拿得出手」差四步**（据 §2 七条归并）：
  ① 字重补档——多数是**字没下载**、不是不想重（S06/S08/S16/S22/S30 只引 400 一档），可一次构建修复；
  ② 长页补「我在哪、还剩多少」反馈（8/30 撞 report 的 12 屏上限，另 12 案 10–11 屏）；
  ③ 暖纸同族散开（22 浅底案里 15 案挤在色相 36°–47°）；
  ④ 栏线共享率提上来（批内中位 17%，21/30 <30%——「栅格感是画出来的，不是排出来的」）。

- **它替被审者说话再判回来的公道做法，我保留**：圆角全 0（29/30）判**无罪、而且是对的**；无导航判**最贵的一条错误**（理由是可感知反馈缺失，不是 `<nav>` 这个标签）；「左对齐大标题」判**一半风格、一半错误，错的那半是分贝**（中位 hero 80.6px）。这三条比多数角色的"发现即缺陷"更成熟。
