# 74 · 供给策略：基准、楔子与 30 案的目标分布

> 角色：OFFERING STRATEGIST（基准 + 差异化）。
> 前提（业主固定，不再讨论）：店主在 GitHub Pages 上浏览 → 选一个方案 → **复制一段 AI 提示词** → 粘进 ChatGPT / Claude / v0 → 得到自己那个站。**陌生人不克隆仓库**。方案可以按季度增删归档。
> 基线：`0432753`（2026-11-04 侦察口径），`data.js` 30 案 / `prompts.js` 30 条。本文所有「实测」为本机脚本现算或文件读数，敌手数字引自 `deliverables/74-recon/` 与 `53-critique-demand-reality.md`。
> 纪律：**不把「别人更好」写成「我们没价值」，也不把「我们有机制句」写成「店主会为此付一次点击」。** 两条都要给出可核的边界。

## 0. 先给结论（六句，后面全部是账）

1. **真实差事不是「挑风格」，是「把『我这家店』说成一段 AI 真能照做的施工说明，而且换 3 次生成都不塌」。** 店主不是缺灵感，是缺**可被验证的约束**；他想问的从来不是「好看吗」，是「AI 会不会又一次给我一个暖米色 + 大衬线标题 + 三张等宽卡」。
2. **替代品全部免费且更快**：一句「帮我做个高级感的咖啡店网站」0 秒、0 学习成本；Minick Studio 20 个 live demo 能输入店名；HTML5 UP 44 模板单模板 **29.4 万–77.4 万**下载（`53` §1.1 实测区间 293,898–774,259）、站底 22,174,547；ThemeForest Corporate 7,941 / Retail 3,707；Coolors / Huemint / Fontjoy 把配色与字体搭配做成了交互产品。**「30 个能跑的风格，不是 30 张配色图」这句在 2026 年已经被 Minick 用同一句话说过，且它免克隆。**
3. **候选楔子（机制句 + 逐行 CSS 出处）不成立为「产品楔子」，只成立为「资产楔子」**：`mechanisms.mjs` 确实有 20 条带 `source:` 的机制句，`prompts.js` 里 30/30 有机制句（均值 88.1 字），这是**别人没有的**。但：① 用户复制到的提示词里**只有 1 句机制句、0 条 `source:`、0 个出处行号**（实测 `dna` 无 `source` 键）；② 那一句在 3 案（S03 焦距/9 栏、S07 5 栏/7 栏、S17 96px）与实现硬冲突；③ 30/30 原型有约 2,844 行内联 JS，提示词 0/30 提 JS，`check-prompts.mjs` 对 `.mechanism` 引用数为 **0**；④ 提示词 37.7% 是全库共用样板，789 个带单位数字里只有 269（34.1%）进提示词。**一个用户看不到、闸门不读、有错的机制层，不能拿去当封面。**
4. **能站住的唯一楔子要换一层**：不是「我们解释为什么它这样读」，是「**我们提供一段已被 CSS 逐行对过账、且带着『做错会是什么样』的风格约束，让第二个 AI 复现时不会退化成通用 AI 味；并且给你三个视口的真截图去当场对答案**」。别人给「结果」或「生成能力」，本库给**可复核的约束 + 对照组**。它是**窄的**、只对「已经打算让 AI 生成、且被 AI 味坑过一次」的人有效；诚实的人数上限因此远小于「所有店主」。
5. **差异化赤字是真的、且是分布问题不是造假问题**：底色 L 分布实测 `8 案 ≤15 / 1 案 61 / 21 案 ≥78`，**L 16–60 为 0**；暖浅带（H28–72 ∧ L≥78 ∧ S>8）**18/30**；紫→品红 H250–350 的底色 **0/30**；全直角 **26/30 `radiusBare=true`**（另 4 案只是 50% 圆点）；`axes.loud`「很安静」**2/30**；结构标签 22 种却 **8 对撞车**，其中 S05/S21（`CONSOLE`+机能冷峻）、S10/S26（`VERSUS`+冷静克制）连调性都撞；`minItems≤4` **0/30**、`minPics≤2` **0/30**。**「我只有 4 个商品、没有照片」这个最典型的店主处境，30 案里没有一案的版式规模是为它设计的。**
6. **所以季度路线图的第一个动作不是加 5 案，是换 5 案**：按 §4 的评分，归档 `S10 / S21 / S26 / S11 / S23`（五案，逐案给分与理由），新增 5 案专门占「中间调、紫品红、真圆角、安静、少内容少图」五个空格。目标分布见 §3 的逐格数字。

### 1.1 为什么不用「直接问 ChatGPT」（诚实版）

| 场景 | 直接问 ChatGPT | 本库 | 谁赢 |
| --- | --- | --- | --- |
| 只想要一个能看的落地页，今天上线 | 一句话 → 一版完整 HTML，0 秒 | 打开 Pages、看 30 张图、点开、复制 1988 字、粘进去 | **ChatGPT 完胜**。本文不劝这类人 |

## 2. 楔子：把候选主张拿去和五个替代品对撞

### 2.1 候选主张的原文与实测边界

候选是：**「唯一一家交付『为什么它读成这样』的供给 —— 20 条机制句，每条带逐行 CSS 出处；别人只给『它长什么样』」**。

**先给它记功（这部分是真的）**：
- `prototypes/_prompts/mechanisms.mjs` 有 **20 个 `source:` 字段**，例如 `S11` 的 `"style.css:18 --hang:56px / :21 --measure:34em / :24-26 --ghost-1/2/3"`，`S15` 的 `"style.css:155 12栏 / :158 grid-column 1/9 / :160 margin-left:-40px"`。
- `prompts.js` 里 `dna.mechanism` **30/30 有值、均值 88.1 字**；红队 `_mech.mjs` 复算：162 个带单位 token，**151 个（93.2%）能在该案 CSS/HTML 逐字找到**；`redteam.md` §11 报 29/30 案全对。
- 我在核过的替代品里**确实找不到第二家**做「风格 → 可执行数值 + 逐行出处」。Minick 给「适合哪类生意」的定位散文，Empire UI 给「签名 CSS + GPU 成本分层」，Refactoring UI 给规则但没绑 30 个成品——**没有一家给「这一案的第 155 行」**。

### 2.2 但它作为「产品楔子」塌在四处（逐条可核）

| 攻击 | 实测 | 对楔子的后果 |
| --- | --- | --- |
| **用户看不到出处** | `prompts.js` 的 `dna` 键并集 = `palette,fonts,radius,radiusBare,shadow,lineWidths,h1Size,bodySize,h1SizeAt1440,mechanism,degrades,risk,reuse` —— **无 `source`**；`prompt-copy.js:308-309` 只输出「这个风格的签名动作：+ 机制句」；我渲染的 S07 提示词 1811 字里，**0 个行号、0 个 CSS 出处** | 「逐行出处」是**仓库资产**，不是**用户拿到的东西**。楔子把内部质检术语当成了交付物（`60-diagnosis` 的 C 结论在此再次命中） |
| **唯一那句没有闸门，且有硬错** | 8 个 `check-*.mjs` 对 `.mechanism` 引用数全为 **0**（`redteam2.md` §3）；硬错 3 案：S03「9 栏 / 游标随焦距比移动」实际是 2 列 + `pointermove` 1:1 跟随；S07「正面 5 栏对背面 7 栏」实际 `5fr 1px 7fr` 是**两页宽度比**，真实 `column-count: 2/3`；S17「金额列 96px」实际 `td.num` 是 88px | 「带出处」的价值是**可复核**，而复核结果恰是「这一案错了」。**S03/S07/S17 的出处反而是自证其伪的证据** |
| **结构性缺口：JS** | 30/30 原型有 `<script>`（约 2,844 行内联 JS），提示词 DNA **0/30** 提 `script`/`JavaScript`；S07 的镜像偏移在纯 CSS 下物理做不到 | 机制句描述的「为什么这样读」有一类**根本没被传输**。AI 要么忽略，要么糊一个假的 |
| **同质那一层被完整传输** | 789 个带单位数字进提示词 269 个（34.1%）；13 个人写散文字段 0 次；30 条提示词 37.7% 共用样板；S03↔S10 最长公共子串 470 字 | 用户真正带走的是**配色 + 字体 + 8 条通用防退化**，也就是 Coolors / Fontjoy / 通用模型最擅长的那一层 |

### 2.3 逐家对撞（「唯一」这个词能否成立）

| 替代品 | 它给「为什么这样读」吗 | 它能复制本库的机制层吗 | 判定 |
| --- | --- | --- | --- |
| **直接问 ChatGPT / Claude** | 能：你追问「为什么这版显得高级」，它会给一段解释，还会给 CSS | 能：把 `mechanisms.mjs` 粘给它，它当场就能复述并改写 | **「唯一能解释」不成立**。且它免费、0 步 |
| **v0 / shadcn / Tailwind UI** | shadcn/ui 与 Tailwind UI 给的是**组件 + token + 可访问性 + 源码**：「为什么」以设计系统文档的形式存在，比 20 条机制句更系统、更可维护 | 结构上能：它们本来就是代码 | **不成立**，且在「可复用」这一轴明显更强（`README.md:444` 自陈「不是设计系统」） |
| **HTML5 UP / ThemeForest** | 模板源码里每一行 CSS 都是「怎么做」，注释与文档给「为什么」；7,941 + 3,707 条的供给量让「逐案出处」不再是稀缺品 | 能，且是现成可下载的 | **不成立**：逐行 CSS 出处是模板市场的默认状态，不是本库专利 |
| **Minick Studio StyleCatalog** | 给「为哪类生意最出力」的定位语 + 20 个 live demo + 输入店名即时预览 + 比较视图 / style board | 结构上不需要：它的价值在「你的名字落在里面」 | **≈100% 重叠**（`53` §1.1），且在 J4「当场对答案」上比本库强 |
| **Coolors / Huemint / Fontjoy** | Huemint 在真实 UI 预览上看配色**面积比**——这本身就是「为什么这个比例读得对」的可视化解释 | 不需要 | **配色/字体这一子层被完全覆盖**（90–100%） |

**裁定：候选楔子按字面不成立。** 它成立的部分是「语料资产」（对 agent 工作流搭建者，规模代理 `UI-Prompt` 419★），但业主已固定客户是**店主、在 Pages 上、只复制提示词**，所以不能拿一个「别人看不见、且客户不是他」的资产当封面。红队两次独立给出同一收窄（`redteam.md` §11「正确客户不是店主」、`redteam2.md` §5「唯一真实的客户是 agent 工作流搭建者」）——**我接受这个事实，但拒绝把定位改掉**：业主的决定不可谈判，所以要在**店主能拿到**的东西里找楔子。

### 2.4 站得住的那一根（替换主张）

> **别人给「一个结果」或「一次生成能力」；本库给「一组可被逐行核对的约束 + 一组三档真截图的对照组」。**
> 更短：**「不是替你做站，是给 AI 一份你能对答案的施工图。」**

四项的合取才构成结构性不可复制（**单独任何一项都被覆盖**）：

1. **约束与实现同源**：色值/字体链/线宽/字号是 `style.css` 实测抽取，不是形容词（`check-prompts.mjs` 对 hex/线宽/字号有断言）——Minick 的 live demo 不给 DNA，Coolors 给色但不给整套版式。
2. **带「做错的样子」**：每案附 `risk`（作者原话「最容易滑向复古报纸风海报」）+ 30 案共用 8 条正面防退化 + 验收三问——模板市场给的是「正确成品」，不给「错版识别器」。
3. **三档真状态对照组**：272 张真截图含 1440/768/390、真长文、真空态/错态（`MIRROR_BUDGET=46` 真会第 47 行报错）——Awwwards/HTML5 UP/Minick 都不给「塌法与缺图态」。
