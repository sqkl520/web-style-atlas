## 二、`.md` 下载：不是"多一个功能"，是一条物理出路

### 为什么要它

复制走剪贴板，而剪贴板在三种情况下失效：
1. 浏览器策略（无用户手势、文档失焦）
2. 目标应用不接受富文本粘贴（有些编辑器会截断长文本）
3. **用户想把这份提示词存起来，下次接着改** —— 剪贴板做不到这件事

前两种已有 `showManual()` 兜底（弹 textarea 让用户手选），但那个兜底仍然是
**内存里的字符串**，关掉页面就没了。下载给的是一个文件，它在磁盘上。

### 下载的内容与复制的**不完全一样**

剪贴板内容要直接粘进 AI，所以必须干净。`.md` 文件是给人存档的，多一层元信息有用：

```markdown
# 税票存根联 · AI 施工提示词

| 项 | 值 |
| --- | --- |
| 案号 | S17 |
| 中文名 | 税票存根联 |
| 英文名 | Revenue Stamp Stub |
| 结构类型 | RECEIPT |
| 生成日期 | 2026-11-11 |
| 正文字数 | 2060 |

> 下面 `---` 之后是提示词正文，直接全选粘进 ChatGPT / Claude / v0 / Cursor 即可。

---
（提示词正文）
（出处附录）
```

判据：**剪贴板求最短路径，文件求可追溯。**

文件名 `S17-税票存根联-提示词.md` —— 带中文名，因为用户下载十几个文件后
光看 S17 认不出是哪个案子。

### 一个必须处理的细节

`URL.createObjectURL(blob)` 之后**必须** `revokeObjectURL`，否则每下载一次泄漏一份
blob。但不能立刻 revoke —— 部分浏览器在下载真正开始前就失效。实测取 4000ms 后撤销。

## 三、按工具改首部：不是换称呼，是换约束

### 为什么四个工具真的需要不同的首部

`deliverables/74-plan/PROMPT-SYSTEM.md:78` 的实测结论：

> ChatGPT/Claude 输出单文件 HTML 没问题；**v0 是 React 组件工作流，
> `<script>` 常常被忽略或改写**，且它已有自己的状态模型。

同一段提示词粘进四个工具，坏掉的方式完全不同：

| 工具 | 坏法 | 首部要做什么 |
|---|---|---|
| ChatGPT / Claude | 基本不坏 | 只要求「直接输出、不要先解释」 |
| **v0** | **`<script>` 被剥 → 机制静默消失，用户看不出哪里坏了** | ① 掰开它的 React 默认路径；② 若本案依赖 JS，**如实警告** |
| Cursor | 一段两千字的对话式提示词，它不知道该写到哪个文件 | 改成文件级指令（写到 `index.html`） |

### 只改首部，不改正文

正文（视觉硬约束、结构约束、输出要求）是风格本体，四个工具都需要它一字不差。
**为什么不给 v0 单独写一份提示词**：那会立刻产生两份正文、两个真相来源，
而本仓库反复吃过这个亏（五份行业答案互相矛盾，见 `01-Q2-FACTS.md` §四）。
首部是"环境说明"，正文是"风格规格"，两者正交，所以可以叠加而不分裂。

### v0 + 依赖 JS 的案子：必须当场说清代价

```
【这条提示词是给 v0 用的，先说清楚一件事】
v0 默认产出 React 组件，而这个版式要的是**一个单文件 HTML**……
⚠️ 这一案的签名机制需要 JavaScript（用它量几何 / 读实时状态）。
**v0 会把 <script> 剥掉或改写**，所以你在 v0 里拿到的版本机制会消失，
而且看起来不容易发现哪里坏了。如果你只能用 v0，建议换一个不依赖脚本的案子；
或者接受一个「少了签名动作」的静态版本。
```

这段是这一项最重要的产出：**在用户粘之前就告诉他"这个组合会坏"**，
而不是让他粘完、生成、看到结果才发现机制没了。

### 默认「不限」，不猜

猜错比不猜更糟：用户拿到的是一份带错误环境说明的提示词，而他不会知道那几句
是为别的工具写的。默认 `generic` 时 `toolHead()` 返回空数组，
**输出与改前一模一样** —— 这一点有断言守着（`tool-head-applied` 比较字数）。

## 五、过程中修的两个真缺陷

### ① .md 文件头三行全是「—」，文件名退化成 `S17-prompt-提示词.md`

第一版用 `pick(id)` 取中文名，而 `pick()` 返回的是 **prompts.js** 的记录。
那份只有 `id / dir / plain / scenes / minItems / minPics / hard / capacity / dna`，
**没有中文名** —— 中文名在 `data.js` 的 `window.SCHEMES` 里。

两条数据链本来就分工不同（README 里写着、`check-twolines` 也在守），
这里只是各取所需，**不合并**。加了 `meta(id)` 从 data.js 取展示信息。

### ② 断言太松，抓不住它本该抓的东西

修好 ① 之后我给它配了变异用例（把 `meta(id)` 换成 `{}`），
结果**变异没红** —— 因为我的判据是「文件名以 `.md` 结尾」，
而退化的 `S17-prompt-提示词.md` **也以 `.md` 结尾**。

判据改成「文件名必须含中文名，不能出现 `-prompt-` 这个兜底词」之后才红。
这条同时守两件事：数据链取对了、用户下载十几个文件后还能认出来。
