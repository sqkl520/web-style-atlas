# 裁决 2 已解决：`role="none"` 能消掉 AX 语义且零几何影响

- 测量时刻：2026-10-29 17:00 (Asia/Shanghai)
- 背景：执行 Agent 诚实提出「`<code>` 是独立 AX 角色，屏幕阅读器会念成『代码 118』，CSS 消不掉」

## 一、解法：给 `<code>` 加 `role="none"`

### 原理
- `role="none"` 把元素从无障碍树的语义中移除（但内容仍会被读）
- `probe.mjs` 的 `inCode` 判据用的是 `el.closest('code,pre,kbd,samp')`——**匹配的是原生标签名，不受 role 影响**

所以两者可以同时成立。

### 实测（S07，103 个 `<code>`）
```
基线：                AX role="code" = 97
加 role="none" 后：   AX role="code" = 0   （97 → 0，语义完全消掉）
closest('code,...')   仍命中 103 / 103（inCode 判据不受影响）
```

## 三、S21 的抖动是真问题（但不是本次改动引起的）

### 实测
```
同一状态连测 5 次：
  第 1 次 hash=-703443318
  第 2 次 hash=-1240965543
  第 3 次 hash=-2024150392
  第 4 次 hash=-2024150392   ← 从这次起稳定
  第 5 次 hash=-2024150392

加载后不同等待时间：
  1000ms → hash=-466359809
  2000ms → hash=397281266
  3000ms → hash=1582711079
  5000ms → hash=-2024150392   ← 只有等到 5 秒才稳定

反复切换 role="none" 5 轮（在稳定后）：
  轮 1 不同（因为还在稳定过程中）
  轮 2-5 全部相同

逐元素对比（471 个元素）：差异 0 个
```

**结论：S21 需要约 5 秒才达到布局稳态。** 稳定后 `role="none"` 零影响。

### 这是 S21 的既有缺陷，与本次改动无关
之前的执行 Agent 也报告过同类现象：「S07 `buildGhost()` 有两个自洽态，取决于量矩形时 webfont 是否就绪」。

S21 的原因待查，但**它不是本轮引入的**。而且它有一个更严重的含义：

> **闸门 `inspect.mjs` 的等待时间如果是 2 秒，那么它对 S21 的测量结果可能不稳定。**
> 同一份 CSS，测 3 次可能得到 3 个不同的几何签名。

这值得单独记录——`inspect.mjs` 目前用 `settleMs`（默认看起来是 2 秒左右），而 S21 要 5 秒。

## 四、裁决 2 的最终结论

**采用 `role="none"`。** 三个目标同时达成：
1. ✓ 消除屏幕阅读器的「代码」语义（AX 归零）
2. ✓ 保持 `mono` 闸门通过（inCode 判据不受影响）
3. ✓ 零几何影响（S07/S13 逐元素完全相同；S21 稳定后也相同）

这比执行 Agent 提出的三个选项都好——它原本担心的是「接受 vs 用 span 退回 FAIL」的二选一，实际有第三条路。
