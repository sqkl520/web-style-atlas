## §0 测试设计（成本算法，不拍脑袋）

**问题**：一个外部设计师把某案的"风格"搬进自己的 Next.js 站，要付多少小时？分五项计价，全部输入用 `grep -c` 级机械计数（脚本存 `deliverables/50-scratch/analyze.mjs` / `pass2.mjs` / `pass4-cost.mjs`，原始表 `table-30.tsv` / `cost.json`），30 案全量跑一遍，不是只测 3 案。

**计量口径**：
- 体积/文件事实 = `git cat-file blob HEAD:<path>`（cmd 重定向保字节序，绕开 PowerShell `>` 的 UTF-16 坑）。工作树里 S04/S15/S22/S23/S24/S27 的 css 正被别人改——**本报告一切 css/html 计数只用 HEAD 版**，下表不再逐行重复此注。
- 字体归属 = 解析 HEAD 版 `index.html` 里 `../_fonts/css/*.css` 链接 → 解析该 css 的 `url(…woff2)` → 按 `git ls-tree -r -l HEAD` 求和。`_fonts` 全目录 925 文件 / 31.2 MB（871 个 woff2 / ≈30.3 MB）在 HEAD 里可全量核。
- 引用完整性 = HEAD 树索引逐条解析 css `url()` + html `src`；`_cand/`（未用素材池）不计入。

**费率（工时 = 计数 × 费率）**：

| 项 | 费率 | 依据 |
| --- | --- | --- |
| 拆组件（markup） | 0.4 min / 元素（含把中文占位文案换成你的） | 一个元素≈一次 JSX/模板迁移+类名核对 |

## §3 取用动线断在哪

README L237–242（阶段 4）自述路径：「每个 `prototypes/<方案目录>/` 是**自包含**的（index.html + style.css + assets/）。要让它独立跑起来，需**一并带上 `prototypes/_fonts/`**。把这两部分放进同一个父目录即可。」我按一个 Next.js 用户的实际动线走：

1. **选型台里选中 S07** → `#S07` 深链 ✓、三档截图 ✓、"打开原型"链接 → `../S07-…/index.html` ✓（`_selection/app.js` L321 真有这个出口）。**不断。**
2. **复制目录**：README 说"两部分放进同一个父目录即可"。① 先要懂 `../_fonts` 相对路径 → 在 Next.js 里 `public/` 布局下路径完全不同，README 没说搬进去之后要改 `index.html` 头部 1–4 行 `href="../_fonts/…"`（均摊 2.9 张表）——**第一步就靠读者自行推断**。② 字面照做会缺东西：S07 的 `style.css` 里有 4 个 `@font-face` 指向 `assets/fonts/*.woff2`（Libre Franklin/Newsreader/IBM Plex Mono 私有拷贝，HEAD 实测），S21 有 `fonts/` 目录 71 个 woff2，S04 4 片、S08 1 片——README 的"自包含"定义漏了案目录内的私有字体层，**而这四案的 CREDITS.md 反而写着"页面字体全部自托管在 `prototypes/_fonts/`"**，取用人连"要补什么"都会被文档带错。③ `assets/` 全量 2.84 MB / 17 文件（S07），页面实际只引用 7 张——没给引用清单，谁敢删？
3. **改成组件**：无 token 表、无组件边界、148 条选择器、51 个结构码语义要靠读 `_specs/S07.md`（47 行）+ `_CURRENT-VALUES.md`（95 行表）+ `_CONTRACT.md`（31.5 KB）三份文档拼图。**README 承诺"能拆到字段"，拆的是文档，不是代码。**
4. **核许可**：MIT 只覆盖代码；3 张字体表文件头**没写许可**（44/48 如此，LICENSE L14 的指引落空）；S07 照片在"不得对外复用"五案名单里（LICENSE L28）——README L95 恰恰拿 S14 当招牌举例、L298 拿 S07 当选型台样例，**样例案自己就是素材雷区**。
5. **重出纹理/字体子集**：`build/` 在 `.gitignore:7`，克隆者 texture-job **0/30**、手切子集的字符集清单也在被忽略的 build/ 里——"参数落盘可逐字节复算"对贡献者是 12/30、对克隆者是 0/30，README L403 只承认了前者。

**断点判定：第 2 步（复制）和第 3 步（组件化）之间**。第 2 步断的是"自包含"的字面不真（私有 fonts/、路径改写、引用清单三项缺失）；第 3 步断得最死——README 从头到尾没有一行描述"原型 → 自己框架的组件"这条路，成本中位 10.9h。"放进同一个父目录即可"对**托管**成立（当静态站跑），对**取用**不成立（当资产拆）。

## §4 裁定

**30 案是"30 件手工艺品 + 3 件可复用资产"，而且手工艺品里有 5 件（S04/S07/S08/S13/S17）的素材部分被自家 LICENSE 判了死刑。** 每一案平均 11.5 个工时的取用成本、无组件边界、黑话规格、0/30 可复算的纹理参数、44/48 不可核的字体许可——这是标本，不是素材库。标本的价值（看得懂、测得了、照着悟）README 已经兑现了；它没兑现的是"取用"。

**README 承诺句有没有骗人**——分三句判：
- L7 「30 个能跑的风格」：**不骗**。30/30 真能跑（HTTP 下），我连 `prefers-reduced-motion` 都数了：30/30 有。"能跑"的主语是原型自己，不是你的站。
- L25 「每个案子都能打开、能跑、**能拆到字段**」：**不骗但偷换**。"拆到字段"拆的是 12 字段文档，README 全文没承诺"拆成组件"；但"能拆"两个字出现在卖点里，普通读者（和 L239 的"取用某一个原型"连读）会读成代码可拆。**这是误导，不是谎言。**
- L239 「每个 `prototypes/<方案目录>/` 是**自包含**的」：**这句是错的**，不是修辞问题——S04/S07/S08/S21 四案带私有字体、S07 带 app.js、S03/S08/S13 带构建脚本、全部 30 案需要路径改写。README 已把"带 `_fonts`"的补丁打上，但"自包含"三个字仍然挂着一处不实。
- L140 「模板层：改 12 个变量就是一个站」：**基本真**，M03 最干净；M01/M02 的"别的数字不用动"各有一小撮未披露常量（§2），属"该修的字"，不属"骗人"。

**该改成什么**（可直接替换 L239 首句 + L25 尾句的最小改写）：
