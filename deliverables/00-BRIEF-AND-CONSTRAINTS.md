## B. 最高优先级组织原则：F / R 对半结构轴（来自用户自定义答案「一半模板一半反模板」）

用户要的不是"30 个都很疯"，也不是"30 个都很乖"，而是**一条从"低认知门槛"到"结构激进"的完整光谱**，让他能按项目风险承受度挑选。

因此引入贯穿全案的第六根唯一性轴：**结构熟悉度 Structure Familiarity**

- **F 型（Familiar Skeleton / 熟悉骨架）— 恰好 15 个**
  信息层级必须做到"任何人 3 秒内知道先看哪、点哪、下一步做什么"。但**禁止**使用用户明令封杀的默认骨架（Hero + 三卡 + Testimonials + Pricing + FAQ + Footer）。
  F 型必须从下列**"非默认熟悉骨架池"**中指定 1 个，且 30 个方案中同一骨架最多出现 **3 次**：
  1. `NEWS-FRONT` 报纸头版式（报头 + 多栏正文 + 折角导读 + 续表）
  2. `MAG-TOC` 杂志目录/跨页式（目录页 + 左右跨页不对称版心 + 页码系统）
  3. `RECEIPT` 票据 / 清单 / 表单式（等宽打字机明细行 + 合计 + 存根联）
  4. `CONSOLE` 仪表盘 / 控制台式（面板分区 + 读数 + 状态灯 + 拨杆）
  5. `CARD-CATALOG` 档案馆索引 / 卡片目录式（抽屉标签 + 索引卡 + 检索号）
  6. `DOSSIER` 书信 / 公文体式（抬头 + 编号 + 正文条款 + 签发栏）
  7. `MANUAL` 说明书 / 技术手册式（章节编号 + 爆炸图 + 规格表 + 警示框）
  8. `PRICE-BOARD` 价目表 / 菜单板式（手写板 + 灯箱 + 分量标注）
  9. `CHRONO` 年表 / 时间轴驱动式（纵向年代轴 + 事件卡 + 时代色带）
  10. `FLOORPLAN` 地图 / 楼层平面驱动式（平面图热区 + 图例 + 比例尺）

- **R 型（Radical Structure / 结构激进）— 恰好 15 个**
  明确放弃常规导航与线性阅读，用结构本身作为记忆点。可选（不限于）：
  `ZERO-G` 零重力布局、`SPLIT` 分裂屏对峙、`SCROLLY` 滚动叙事、`TERMINAL` 命令行驱动、`COLLAGE` 拼贴墙、`RIVER` 非线性卡片河流、`ISOMETRIC` 空间透视/等距、`GENERATIVE` 参数化生成式、`BRANCH` 路径选择分支、`MASK` 非矩形挖空/遮罩、`VERSUS` 多栏对撞、`MIRROR` 镜像折叠。
  同一 R 结构最多出现 **3 次**。

- **分布要求（强制）**：3 个生成 Agent 各负责 10 个方案，**每个 Agent 的 10 个里必须恰好 5 个 F 型 + 5 个 R 型**，并在自己区间内交错排列（如 F,R,F,R…），禁止前 5 个全 F、后 5 个全 R。
- 交付时必须对每个方案标注：`结构类型：F（骨架名）/ R（结构名）`。

## C. 绝对禁令（用户第 3 节 + Lead 追加的硬规则，逐条机械校验）

### C-1 用户原始禁令（违反即整案作废）
1. 禁止紫蓝渐变、粉紫渐变、任何"AI 味渐变"作为背景或主视觉。
2. 禁止 Inter、Roboto、Arial、system-ui 作为主字体。
3. 禁止居中大标题 + 三张等宽卡片 + 底部 CTA 的默认 SaaS 布局。
4. 禁止 Emoji 作为功能图标。
5. 禁止抽象 3D 球体、发光渐变球体"代表 AI / 科技"。
6. 禁止每个 section 背景白 / 灰交替。
7. 禁止"赋能""解锁""一站式""无缝体验"等空洞营销词。
8. 禁止 30 个方案采用相同页面结构骨架。
9. 禁止用"极简""现代""高级感"这类空泛形容词**替代**具体设计决策。

### C-2 Lead 追加禁令（同等效力，用于堵住"擦边球"）
10. 禁止任何 `mesh gradient / aurora blob / 发光噪点球` 作为 hero 背景；也禁止 `紫→青`、`蓝→紫`、`粉→橙` 的二元插值渐变。
11. 禁止 `24px 圆角 + 柔和 drop-shadow` 的"卡片浮起"默认范式（除非该方案的核心命题就是**批判并击碎**它，且在"去 AI 味审查点"中明说）。
12. 禁止在任何 font stack 里出现 `Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI"` 作为主/正文字体。可以出现在"我们拒绝什么"的批判文字里。
13. 禁止 3D 渲染的机器人 / 宇航员 / 抽象人头 / 流体金属作为 hero 主视觉。
14. 禁止"Icon + 短标题 + 两行说明"重复 3 / 6 / 9 次的 feature grid 作为页面主体。
15. 禁止纯 `#FFFFFF` 背景 + 纯 `#000000` 文字 + 单一强调色这种偷懒三色。允许接近白/黑，但必须给出**有印刷/材质理由**的具体暖冷偏移值并论证。
16. 禁止用 Lorem ipsum 或"示例文案""此处填写"占位；每个方案的关键文案必须写出**真实可用的中文示例**（≥2 处，例如真实主张句、真实按钮文字、真实空状态文字）。
17. 禁止"渐变描边文字（gradient text）"与"毛玻璃吸顶导航 + 背景模糊"的默认堆叠。
18. 禁止 30 个方案出现任何一对"同骨架换色"（判定标准见 F 节近似度规则）。
19. 每个方案必须至少有 **1 处"设计师签名式怪癖"（signature quirk）**——一个不为了效率、只为作者表达而存在的细节，必须显式写出。
20. 空洞营销词黑名单（正文与示例文案均不得出现，论述时可用引号批判性提及）：
    `赋能 / 解锁 / 一站式 / 无缝 / 颠覆 / 革命性 / 极致 / 助力 / 闭环 / 生态 / 抓手 / 颗粒度 / 心智 / 种草 / 吊打 / 碾压 / 数智化 / 全链路 / 沉浸式体验 / 未来已来`

### C-3 高危家族的强制改造条款
本任务**必须**包含以下 3 个高危 AI 味家族各 1 个方案（因为用户点名要求给出反套路改造），且每个都必须在正文里写出 **"反套路改造三指标"**（3 条可检验的硬改造，而不是形容词）：
- **Aurora Mesh**（本就容易 AI 味）
- **Glassmorphism**
- **Neumorphism**

改造方向必须**改变其物理隐喻**，不允许只是"降低饱和度"这种敷衍。参考方向（不强制，可用更好方案）：
- Aurora → 把极光当作**真实胶片长曝光**：颗粒、色偏、光晕不匀、暗部噪点，用抖动/半调位图而非 CSS 径向渐变；或把极光转译为**纸张上的墨水渗染（ink bleed）**。
- Glassmorphism → 把玻璃当作**实物亚克力 / 琥珀色厚玻璃 / 凸版透明油墨叠印**：有厚度倒角、边缘折射高光、指纹与灰尘、印刷套印错位；**禁止**吸顶模糊导航。
- Neumorphism → 把软挤出改为**凸版压印（letterpress）/ 盲压（blind emboss）/ 烫金击凸**：单向硬光源、纸纤维起伏、无圆角胶囊按钮，交互靠"光照方向反转"而非"内外阴影切换"。

### C-4 若使用"极简 / 现代 / 高级感"等词
仅允许作为**结论的注脚**出现，且同一段内必须立刻给出 ≥2 条可执行的具体设计决策（色值、网格单位、字号阶梯等）。凭形容词单独成立的描述一律不合格。

## D. 每方案强制字段模板（12 项，编号与标题必须逐字一致，缺一即不合格）

```
### 方案 N｜中文名（English Reference）
**结构类型**：F（骨架名）/ R（结构名） ｜ **认知门槛**：低 / 中 / 高 ｜ **调性**：<取自 7 种调性>
1. 一句话视觉定义
2. 美学家族与参考
3. 配色系统
4. 字体策略
5. 布局与网格
6. 关键视觉元素（≥3 个）
7. 动效与交互
8. 去 AI 味审查点（≥3 条）
9. 反 AI 味风险与规避
10. 适用场景（≥2 类，并附"不适合"）
11. 可落地要点
12. 设计师签名式怪癖
```

各字段最低要求（**逐条写死，便于审查**）：
1. **一句话视觉定义**：必须"能在脑中成像"，含具体材质/色彩/结构词。禁止出现"极简/现代/高级感/科技感"。反例："一个现代极简的高级感网站" → 直接打回。
2. **美学家族与参考**：写清家族名 + **≥3 个真实参考对象**（设计运动 / 杂志 / 品牌 / 网站 / 艺术家 / 印刷工艺），并说明"我们偷的是什么"（偷的是机制，不是外壳）。
3. **配色系统**：**恰好 3–4 个精确 HEX**，逐个写明角色（主色 / 辅助色 / 背景色 / 强调色）、面积比例（如 62 / 24 / 9 / 5）、情绪、以及**"为什么这套配色不像 AI 默认配色"**（必须点名它反的是哪种 AI 默认色，例如"反紫蓝渐变""反 #6366F1 靛蓝主色""反纯白底"）。
4. **字体策略**：给出**具体字体名**（优先 Google Fonts / 开源 OFL / 系统级真实存在字体），分工写明标题 / 正文 / 辅助数字三类，说明**搭配逻辑**与**"为什么不像 AI 选的"**（AI 默认 = Inter + 一款几何无衬线 + 一款圆润无衬线）。必须给出可用性说明：授权（OFL/Apache/商用免费）、是否有中文子集可用或需搭配哪款中文开源字体（如思源黑体/思源宋体/霞鹜文楷/朱雀仿宋/未来荧黑/文津宋体等）。
5. **布局与网格**：写明列数 / 基线 / 不对称方式 / 留白节奏 / 滚动行为 / 断点变化。禁止写"响应式适配"这种空话，要写具体行为（如"≥1280px 三栏对撞，768–1279px 折为双栏并保留报头，<768px 转为单栏纵向报摘"）。
6. **关键视觉元素**：**≥3 个**可被记住的细节：材质、纹理、图形语言、装饰、图标逻辑（明确"图标如何绘制，绝不用 Emoji"）、摄影/图像处理方式。
7. **动效与交互**：分滚动 / 悬停 / 加载 / 转场 / 光标 / 微交互。禁止写代码。要写触发条件、时长区间、缓动性格、降级策略（`prefers-reduced-motion`）。
8. **去 AI 味审查点**：**≥3 条**，每条必须写成"它故意反的是第 C-1/C-2 的第 X 条 → 具体怎么做 → 跳脱在哪里"。
9. **反 AI 味风险与规避**：指明本方案最容易滑向哪种 AI 味（要具体，例如"容易滑成 Dribbble 式深色仪表盘"），并给出 2–3 条规避动作。
10. **适用场景**：**≥2 类**具体品牌/产品/项目类型 + **明确写出不适合什么**。
11. **可落地要点**：给前端与设计师的实现提示：CSS 思路（写思路不写完整代码）、栅格单位、字体加载策略（`font-display`、子集化、可变字体轴）、图片处理（格式、抖动、颗粒叠加方式）、性能预算。
12. **设计师签名式怪癖**：一个"不为了效率"的细节，并说明它为什么值得存在。

## E. 篇幅与格式硬指标

- **每个方案正文（字段 1–12 全部内容）中文字符数 ≥ 600**，目标区间 **700–950**。低于 600 视为不合格，审查官必须打回。
- 30 个方案合计 ≥ 18000 中文字。
- **禁止**用表格压缩方案正文。表格**只允许**用于唯一性矩阵与审查打分摘要。
- **禁止**使用"由于篇幅限制""以下省略""简要描述""不再展开""同上""类似""略""参考上面"等任何省略性表述。机械校验：出现即不合格。
- 写作语言：简体中文。专有名词、字体名、HEX、CSS 属性保留英文。
- 禁止合并方案；每个方案独立编号、独立完整。

## F. 唯一性判定规则（Differentiation Auditor 按此机械判罚）

**五元组**：`美学家族 × 布局范式 × 字体气质 × 配色情绪 × 材质动效`

1. **家族互斥**：30 个方案必须属于 30 个**不同**美学家族。任意两方案家族相同 → 立即判重。
2. **五元组互斥**：任意两方案的 5 元组不得完全相同；且任意两个方案**不得有 4 个及以上分量相同**。
3. **近似度栅栏（防"同骨架换色"）**，满足任一即判近似，必须打回：
   - 两个方案的主色色相差 < 25° 且结构类型相同；
   - 两个方案的标题字体为同一款或同属同一超家族（如两款几何无衬线）且布局范式同类；
   - 两个方案的关键视觉元素有 ≥2 个语义重复（如都靠"粗黑描边"和"噪点颗粒"当记忆点）；
   - 两个方案的动效主机制相同（如都靠"滚动触发横向平移"）。
4. **家族槽位硬约束**（Matrix Architect 必须满足）：
   - 至少覆盖 **6 个不同时代**（如 1920s / 1950s–60s / 1970s / 1980s / 1990s–Y2K / 当代）；
   - 至少覆盖 **8 个不同地域或流派**（北欧、日本、瑞士、孟菲斯/意大利、东欧、包豪斯/德国、苏联构成主义、巴西热带主义、西非、韩/日亚文化等）；
   - 至少覆盖 **8 种媒介质感**（报纸、杂志、CRT 终端、胶片、手绘、拼贴、蓝图、票据、档案、丝网印、蚀刻、编织等）；
   - **7 种调性每种至少 3 个方案**；
   - 至少覆盖 **6 种技术语境**（终端、数据看板、游戏界面、编辑出版物、生物形态、工业控制台、地图/GIS、音频设备等）；
   - 至少 **10 个家族不在用户给出的风格池列表内**（即必须自行发明/扩展，证明不是照抄清单）。
