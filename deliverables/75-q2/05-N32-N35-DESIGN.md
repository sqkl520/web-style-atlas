# N32–N35 选题设计

> 2026-11-10　四个案子的选题依据与缺口覆盖

## 一、缺口与余量的现状（实测）

| 缺口 | 现况 | 地板 | 还差 |
|---|---|---|---|
| 中间明度带（HSL） | 1（S09，而 S09 在 Lab 下是浅色） | 2 | **1** |
| 亮底紫（hue 260–320 且明度 ≥60） | 0 | 1 | **1** |
| 很安静（chroma ≤ 25） | 3（S15/S22/S31） | 5 | **2** |
| 少货少图（minPics ≤ 2） | 1（S31） | 2 | **1** |

结构标签余量：14 个标签只用过 1 次（还能加 2），9 个用过 2 次（还能加 1）。
调性：`奢华暗黑 / 高定` 正好 3 案，**压线**——四个新案里至少要有一个落在这个调性上才稳。

## 二、四个案子的设计原则

**每个案子同时补 2–3 个缺口**，因为缺口是叠加的：一个"很安静 + 少图 + 中间明度"的屋子
天然同时补三条。逐案各补一条会浪费四个名额。

**结构标签各取未撞车的**，四种完全不同：一个 F 型（FLOORPLAN / CARD-CATALOG 类）、
两个 R 型（MIRROR / MASK / ZERO-G 类）、一个 GENERATIVE。

**调性分布**：一个落「奢华暗黑 / 高定」（压线那条），其余分散到温暖手作、荒诞幽默、学术档案。

## 三、四个案子的画像

### N32 · 亮底紫的那一页

| 项 | 值 |
|---|---|
| 目标缺口 | **亮底紫 0→1**（唯一一个只靠一案就能补满的缺口） |
| 底色 | 找 hue 270–310、明度 ≥60、且与文字对比 ≥4.5:1 的紫 |
| 结构标签 | `CARD-CATALOG`（档案馆卡片目录，只用过 1 次） |
| 调性 | 奢华暗黑 / 高定（把压线那条抬到 4） |
| minPics | 1–2（顺带补少图） |
| 它解决什么处境 | 全库没有一页是"紫而不甜"的：S02 鎏金对称厅是暗紫黑，S12 青柠是冷绿。要紫色又不想甜腻的（花艺、香氛、买手店）今天没有正解 |

⚠️ 难点：亮底紫很容易撞上 `palette-purple` 规则（`vendor/rules.mjs` 里 AI 味紫的窗口）。
要先量清那个窗口在哪，再选一个**在窗口外**的紫。

### N33 · 中间明度的那一页

| 项 | 值 |
|---|---|
| 目标缺口 | **中间明度 1→2** |
| 底色 | 已算过：`#5F5B55` 类的中性中灰（S31 用的就是这个）——但 S31 的 HSL l=35 落在"中性中带"，没进"中间明度带"。要 HSL l 在 23–77 且 sat > 8 |
| 结构标签 | `MIRROR`（镜像折叠，用过 1 次） |
| 调性 | 温暖手作 / 人味 |
| minPics | 2（顺带） |
| 它解决什么处境 | 中间明度是**最难做的一档**：深字太浅、浅字太深。S31 撞过这个墙（实测 4.5:1 在数学上做不到，只能改浅字）。这一案把这个制约变成机制本身 |

### N34 · 很安静的第二页（无照片、纯排版）

| 项 | 值 |
|---|---|
| 目标缺口 | **很安静 3→4**，同时 **少图 1→2** |
| 结构标签 | `ZERO-G`（零重力，用过 1 次）——但"很安静"与"零重力漂移"要小心不矛盾 |
| 调性 | 学术档案 / 严肃出版 |
| minPics | 0–1（**零照片**，全库第一个） |
| 它解决什么处境 | S31 是"用尺规替代图"，这一案是"用**留白的密度**替代图"。两个都少图，但机制不同：S31 靠刻度，这一案靠文字块的疏密 |

### N35 · 很安静的第三页

| 项 | 值 |
|---|---|
| 目标缺口 | **很安静 4→5**（补满） |
| 结构标签 | `GENERATIVE`（参数化生成，用过 1 次） |
| 调性 | 荒诞幽默 / 玩心（这个调性要"安静"很难，正好是差异点） |
| minPics | 1 |
| 它解决什么处境 | "很安静"目前三案全是暖色纸（S15 冷白、S22 灰白、S31 中性灰）——缺一个**冷色但安静**的。且"荒诞幽默 + 很安静"这个组合全库没有 |

## 四、执行顺序

按「补满缺口所需的工作量」排：

1. **N32 亮底紫**先做——它是唯一"一案补满一个 0 缺口"的，价值最高；
2. **N34 少图/安静**再做——同时补两条；
3. **N33 中间明度**——需要小心处理对比度制约；
4. **N35** 最后，只补很安静的最后一条。

做完四条后 `--strict` 应当全绿，那是 Q2 的验收开关。

## 五、已知的风险

1. **`palette-purple` 可能拦住 N32**：AI 味紫的窗口在规则引擎里，要先读出来。
2. **中间明度与对比度的数学冲突**：N33 必须用浅色文字（S31 已踩过）。
3. **「很安静」与「荒诞幽默」可能对撞**：N35 的调性要真的做得出来，不能只是标签。
4. **四个案子都可能触发 `few-pictures` / `hairline`**：已豁免，条件 `minPics ≤ 2`。
