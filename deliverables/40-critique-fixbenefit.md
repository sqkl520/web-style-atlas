# 40 · 修复收益评估

## 0 判定口径

### 0.0 一句话
复现性、正确性、许可合规都是**手段**。我判的是**目的**：这条修改让谁受益、受益多少、代价是什么、有没有更便宜的等价做法。

### 0.1 收益：两种读者 + 四个档

**读者类型**（互不替代，一条修复可以同时服务多种）：

| 代号 | 读者 | 他拿到仓库后做的第一件事 | 谁在乎他 |
| --- | --- | --- | --- |
| **U** | **想用它的人** | 打开页面看版式，或把某个原型当模板改成自己的品牌 | 这是这批交付物的**唯一商业目的**（`_specs/Sxx.md` §10「适用场景」逐案写了目标行业） |
| **R** | **想复现的人** | `git clone` 后重跑 `_build/` 的工具链 | 决定"这套东西是不是可交接的工程" |
| **E** | **想核证据的人** | 按报告里的文件路径/行号去核数字 | 决定"报告里的话能不能信" |
| **L** | **法务/授权** | 照着 `LICENSE` 与 `CREDITS.md` 判断哪些文件能复用 | 决定"拿来用会不会踩版权" |

**收益档**（可核，不含"我觉得"）：

| 档 | 名字 | 判据 |
| --- | --- | --- |
| **G3** | 功能失效 | 点了没反应 / 正文读不出来 / 工具根本跑不起来 |
| **G2** | 硬指标不达标 | WCAG AA 未过、明文契约未闭合、产物与自己的自称相反 |
| **G1** | 数字或口径与实际不符 | 可复算但写错，后果是后来者重复劳动或误判 |
| **G0** | 观感/整洁 | 不影响上述任何一条 |

**收益记法**：`受益面 = Σ(读者类型 × 档)`。例：39 号首推第 1 条 = `U–G1 + R–G1`（两读者、各一档）；37 号 T0-3 若成立 = `L–G2 + U–G0`。

### 0.2 代价：三个分量 + 风险系数

| 分量 | 取值 | 本仓库的标定依据（实测，不拍脑袋） |
| --- | --- | --- |
| **人时 h** | 连续量 | 1 行 CSS + 重渲染 + 复核 = **0.25 h**（33 号 AH-22/AH-21 的实测口径）；一个原型重渲染 = **20 s 机时**；一份 agent 审查报告 = **20–60 min**；本仓库 `33`/`37` 两份报告的自估都落在 0.03–15 h 区间 |
| **回归风险 r** | 低 / 中 / 高 | **低**＝`@media` 内单条声明、或纯新增/复制文件；**中**＝改可见内容或版式（要重新核该案基线与色比）；**高**＝动生成器、动已交付素材、动 30 案共用的规则 |
| **改已验收像素 p** | 是 / 否 | "已验收"＝该案 `.inspect/report.json` 的 `at` 已被 `check-stale.mjs` 判为新鲜（本文实测：30 案全新鲜）。**凡 p=是，必须先重跑闸门 + `collect-schemes.mjs` + 复核**，代价按 +0.3 h 计 |
| **动仓库受跟踪文件 t** | 是 / 否 | 本文实测 `git ls-files` = **2020 个文件**。`.gitignore` **只对未跟踪文件生效** —— 这条是本文 §2 推翻一条"零风险"建议的判据 |

**值不值得**：先看**有没有更便宜的等价做法**（§3）；没有才比 `收益 ÷ (h × 风险系数)`。

### 0.3 我自己的三条纪律

3. **凡是"存在 scratch 里"的数字，一律内联进本文正文。**

## 3 更便宜的等价做法

对每一条被提议的修复，问同一句话：**"有没有用十分之一代价拿到八成收益的做法？"** 有 12 条有，其中 **4 条我把"更便宜做法"定为最终裁定**（B04、B15、N17、§2.2 的 S28），另 8 条我把"更便宜做法"作为**分阶段的第一刀**（先做便宜的，看够不够）。
