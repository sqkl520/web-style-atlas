# S14：唯一一个「AI 无法判断颜色用途」的案

2026-10-30 · 开工 HEAD `6e0ca82` · 收尾见下方

---

## 1. 缺陷

提示词第 1 条原文（S14）：

```
1. 配色只用这几个值：#C9C4B8、#D8D2C4、#12181D、#E4572E、#8A3320、#111111。不新增更多彩色。
```

对比 S01（正常案）：

```
1. 配色只用这几个值：#C1121F（red）、#EFE7D7（paper）、#1A1614（ink）、#6E6A5E（lead）。不新增更多彩色。
```

**S14 的 6 个条目一个角色名都没有。** 这是 30 案里唯一一个（实测，见 `LEAD-role-names.mjs`）。

## 2. 为什么这是缺陷而不是风格差异

色值本身不带语义。同一组 5 个色，标成「主色/背景色/辅助色」和完全不标，
AI 会做出两个不同的站——而这正是本轮在修的那类问题
（上一轮 `0f10d8e` 修的就是「面积锚点指错色，AI 会把 11% 的强调色铺满整页」）。

S14 的实际顺序暴露了后果：

| 位置 | 修复前 | 规格里的角色 | 占屏 |
|---|---|---|---|
| 1 | `#C9C4B8` | **规格里没有这个色**（CSS 的 HUD 文字色） | — |
| 2 | `#D8D2C4` | 辅助色 | 15% |
| 3 | `#12181D` | 背景色 | 62% |
| 4 | `#E4572E` | **主色** | 18% |
| 5 | `#8A3320` | 压痕暗侧 | 5% |
| 6 | `#111111` | 按钮字色 | — |

主色排第 4，首位是一个规格里不存在的文字色。提示词没有任何线索告诉 AI 这件事。

## 3. 根因

`clean-dna.mjs` 的 `pickPalette()` 靠两样东西给条目命名：

1. `:root` 的**变量名**（`--paper` → `paper`）
2. `:root` 声明行上的**注释**（`/* 主色 */`）

**S14 整个文件没有 `:root`。** 它把颜色直接写在规则里：

```css
body { background: #12181D; color: #D8D2C4; }
.hud { color: #C9C4B8; }
```

于是 `rowColors` 是空数组 → `pickPalette` 返回空 → 调用方落到兜底分支
（`clean-dna.mjs:1279` 原实现），那个分支只按**出现频次**排，不带任何语义。

> 同一根因在上一轮 `6e0ca82` 已经暴露过一次：它导致 `dna.primary` 为空。
> 当时只修了「主色识别」，没修「角色名」，所以提示词表面上有了主色，
> 顺序却仍然是错的、且条目无名。

## 4. 修法

两处改动，都在 `clean-dna.mjs`，判据都不靠猜：

### 4.1 `colorSource`：没有 `:root` 时也要有候选池

```js
const colorSource = rowColors.length ? rowColors : (全文件出现过的 hex，按频次);
```

之后 `push` / 规格补位 / 余位补位三处都改用 `colorSource`。
这样 S14 至少进入正常流程（主色优先、规格色优先），而不是走裸频次兜底。

### 4.2 角色名三级来源

```js
name: varName || specRoleOf.get(hex) || usageRoleOf(hex) || ""
```

| 来源 | 判据 | 可靠性 |
|---|---|---|
| `:root` 变量名 | 已有行为，29/30 案都靠它 | 保持不动 |
| `specRoleOf` | 规格字段 3 里 hex **之前**那段文字（去掉 markdown 记号，≤8 字） | 权威原文 |
| `usageRoleOf` | CSS 里 `color:/fill:` 与 `background:/background-color:` 的命中数比较，多者胜；并列则返回空 | 可证伪的事实 |

第三级刻意保守：**并列或都没命中就返回空，宁可不给也不给错。**

## 10. 没做的事（明确记录）

- **没有给其余 30 案换用规格角色名。** 它们靠 `:root` 变量名已能表达角色
  （`paper` / `ink` / `gold` …），换掉等于凭空重写 60 多条提示词措辞，
  风险面远大于收益。
- **S14 多出的 3 个文字色没有从调色板删除。** 它们承担 AA 对比度
  （`#C9C4B8` 用 16 次、`#111111` 对铝面 12.5:1、`#E4E0D6` 对压痕暗侧 5.41:1），
  是必需色，只是标注为「文字色」。
