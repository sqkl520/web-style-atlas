你是一个前端开发者。请根据下面的风格描述，写出**一个完整的 HTML 文件**
（内联 CSS，不引用任何外部文件、不用任何 CDN、不用任何图片文件）。
# 风格描述
气质：学术档案 / 严肃出版。
这个风格的签名动作：章号悬挂在版心外 56px、正文压到 34 字行长，标题叠三层重影，横向错位 0.5 / 1.5 / 3px、第三层 12% 不透明——层级由错位量承担，位置交给悬挂编号。
视觉硬约束（逐条执行；配色与字体照此固定）：
1. 配色只用这几个值：#1B4A4A（copy）、#DCDDD2（paper）、#221E19（ink）、#6E7A64（note）。不新增更多彩色。
2. 字体：标题按这个顺序取第一个可用的：EB Garamond → LXGW WenKai TC → Noto Serif SC（前一个缺字就用下一个）。
   正文同理，按序取：LXGW WenKai TC → Kaiti SC → KaiTi → Noto Serif SC。
3. 圆角：全站一律 0，卡片、按钮、图片、标签全部方角。
4. 阴影：只用 inset（凹槽，无外投影）。
5. 线宽只用这几级：1px、1.25px、2px、3px，全站线条都从这几级里取。
6. 字号：正文约 16px；最大标题要压到正文的 6.6 倍（约 106px）。比这更小就撑不出这个版式——这是本案最容易被做塌的一处。中间层级你按内容需要分，但**最大那一档必须够大**。
结构约束：
- 常见失败方式（务必规避）：最易滑向「复古做旧滤镜」：一旦用暖褐 Sepia 铺满全屏、再叠一张纸纹贴图，就会同时变成另一种流行模板。规避动作有三条：一是禁用任何 Sepia 与暖色滤镜，纸色只允许 #DCDDD2 一个值；二是复写重影必须给出 0.5px / 1.5px / 3px 三层固定错位值，不允许以「看起来发糊」交差；三是铁窗格必须画出方钢截面宽度与投影方向，禁止退化成装饰性边框。
- 最难被复用到别处之处：最难被复用到别的品牌的地方，是复写重影的三层错位值与铁窗格的方钢截面：换掉品牌名之后，这两组数值仍然只能属于「复写纸 + 铁窗」这一件事。
# 输出要求
只输出 HTML 代码，写进 `out.html`。不要解释，不要额外文件。
页面要真的是一个能用的网站首页，内容自拟、用中文，不要用占位符文字。
字号、线宽、配色必须严格照上面给的数。
