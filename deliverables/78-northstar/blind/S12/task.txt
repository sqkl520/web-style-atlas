# 风格描述
气质：荒诞幽默 / 玩心。
这个风格的签名动作：七个挖空块按 3/2/1/1 递减错位落位，斜边只走 45° 与 135°、切角 30px，间隙取 12/28/44px 三级，内侧压 0.5px 翻边——分区靠硬边挖空，不靠投影。
视觉硬约束（逐条执行；配色与字体照此固定）：
1. 配色只用这几个值：#B5D626（lime）、#1E2A2E（room）、#E23E57（magenta）、#F2E9D8（face）、#26353A（room-2）、#182226（room-3）、#111111（btn-ink）。不新增更多彩色。
2. 字体：标题按这个顺序取第一个可用的：Bricolage Grotesque → Glow Sans SC（前一个缺字就用下一个）。
   正文同理，按序取：Glow Sans SC → Noto Sans SC → Source Han Sans SC → PingFang SC。
3. 圆角：全站一律 0，卡片、按钮、图片、标签全部方角。
4. 阴影：无阴影。
5. 线宽只用这几级：1px、2px、8px，全站线条都从这几级里取。
6. 字号：正文约 17px；最大标题要压到正文的 5.6 倍（约 95px）。比这更小就撑不出这个版式——这是本案最容易被做塌的一处。中间层级你按内容需要分，但**最大那一档必须够大**。
结构约束：
- 常见失败方式（务必规避）：最易滑向「孟菲斯多色贴纸堆砌」：把青柠、洋红、黄、蓝一次摆满，就退回成样式堆砌。规避动作三条：一是只允许三个实色加一个米白，禁止引入第四个彩色；二是所有图形边界必须能追溯到 45° 或 135°，禁止曲线与自由形状；三是斜纹角度只允许 45° 与 135°，禁止 30°、60° 这类中间值。
- 最难被复用到别处之处：最难被复用到别的品牌的地方，是那组 45° / 135° 的洞口顶点坐标与三级跳变间隙：换了文案之后，这组坐标仍然只适用于「一块被冲切的塑料板」。
# 输出要求
只输出 HTML 代码，写进 `out.html`。不要解释，不要额外文件。
页面要真的是一个能用的网站首页，内容自拟、用中文，不要用占位符文字。
字号、线宽、配色必须严格照上面给的数。
