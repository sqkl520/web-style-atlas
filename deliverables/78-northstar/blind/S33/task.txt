# 风格描述
气质：温暖手作 / 人味。
这个风格的签名动作：左右镜像对账：左栏是用户原话、右栏是落进合同的数，中间一条 1px 竖线对穿；左栏宽度分三档 0.8fr/1fr/1.3fr 按原话长短走，右栏永远等宽——说话的每次不一样，记账的格式不变。窄档镜像改成上下对照，竖线转成横线。
视觉硬约束（逐条执行；配色与字体照此固定）：
1. 配色只用这几个值：#4A6763（paper）、#F2F6F5（ink）、#D8E4E2（ink-mid）、#A8C0BD（rule）、#2F4744（block）、#3F5855（paper-deep）、#BCCFCC（ink-soft）。不新增更多彩色。
2. 字体：标题按这个顺序取第一个可用的：Jost → Noto Sans SC（前一个缺字就用下一个）。
   正文同理，按序取：Noto Serif SC → Literata → Georgia。
3. 圆角：全站一律 0，卡片、按钮、图片、标签全部方角。
4. 阴影：无阴影。
5. 线宽只用这几级：1px、2px，全站线条都从这几级里取。
6. 字号：正文约 16px；最大标题要压到正文的 6.3 倍（约 100px）。比这更小就撑不出这个版式——这是本案最容易被做塌的一处。中间层级你按内容需要分，但**最大那一档必须够大**。
结构约束：
- 常见失败方式（务必规避）：最易滑向「工程感深绿仪表盘」：一旦加上网格背景、等宽大字、荧光强调色，就与大量 SaaS 后台模板撞车。规避动作三条：一是底色只允许 #4A6763 一个值，不允许加网格背景（那会把"纸"变成"屏"）；二是记忆点必须落在三档左栏比例与中缝竖线上；三是零图标零投影零渐变。另有一条反向风险：「温暖手作 / 人味」这个调性容易被做成暖色——本页偏偏是冷青。人味在这里体现在"把你说的原话留着"这个做法上，不体现在配色上。
- 最难被复用到别处之处：最难被复用到别的品牌之处："左栏宽度随原话长短变化、右栏等宽"这个不对称——换一个没有"用户声音"这一层的品牌，三档比例就成了没有理由的装饰。
# 输出要求
只输出 HTML 代码，写进 `out.html`。不要解释，不要额外文件。
页面要真的是一个能用的网站首页，内容自拟、用中文，不要用占位符文字。
字号、线宽、配色必须严格照上面给的数。
