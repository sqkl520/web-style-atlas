# 风格描述
气质：温暖手作 / 人味。
这个风格的签名动作：左 3 右 7 栏、中缝 72px，装订线落中缝右 12px，两版错开 0.8 至 1.6px、相压处相乘出深色，行首按 0/12/24px 缩进——层级由缩进量与版次差给出。
视觉硬约束（逐条执行；配色与字体照此固定）：
1. 配色只用这几个值：#914A27（spot-a）、#E8E4DE（paper）、#1E1A16（ink）、#2E6B5E（spot-b）、#DFDAD2（paper-deep）、#FFFFFF（paper-white）。不新增更多彩色。
2. 字体：标题按这个顺序取第一个可用的：Besley → Noto Serif SC → Georgia（前一个缺字就用下一个）。
   正文同理，按序取：Noto Serif SC → Songti SC → Georgia。
3. 圆角：全站一律 0，卡片、按钮、图片、标签全部方角。
4. 阴影：无阴影。
5. 线宽只用这几级：1px、1.2px、2px、3px，全站线条都从这几级里取。
6. 字号：正文约 16px；最大标题要压到正文的 4.3 倍（约 68px）。比这更小就撑不出这个版式——这是本案最容易被做塌的一处。中间层级你按内容需要分，但**最大那一档必须够大**。
结构约束：
- 常见失败方式（务必规避）：本方案最容易滑向"文艺杂志排版模板"（大字衬线标题加超大留白加一张摊开的杂志照片）。规避动作：（1）版心必须右重左轻（3:7）并把三级缩进写死，禁止左右对称的居中版心；（2）第三色必须是两版相乘的结果，禁止用 opacity 假装叠印；第三色由运行时的 mix-blend-mode: multiply 在两版相压处真算（构建期不固色），实测 #181C0D；（3）与 7 号（油墨透印加页边毛口）、6 号（珂罗版网点加杯渍）的分界写明：25 号的分区靠版次与缩进，既不靠透印，也不靠污渍。
- 最难被复用到别处之处：最难被复用到别的品牌的地方：右重左轻的版心与三级缩进必须绑定真实的篇章层级数据，换品牌等于重排整本目录。
# 输出要求
只输出 HTML 代码，写进 `out.html`。不要解释，不要额外文件。
页面要真的是一个能用的网站首页，内容自拟、用中文，不要用占位符文字。
字号、线宽、配色必须严格照上面给的数。
