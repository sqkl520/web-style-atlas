你是一个前端开发者。请根据下面的风格描述，写出**一个完整的 HTML 文件**
（内联 CSS，不引用任何外部文件、不用任何 CDN、不用任何图片文件）。
# 风格描述
气质：混乱活力 / 街头。
这个风格的签名动作：12 列隐网格上，纸块跨 3 至 5 栏、色版偏移取 3 至 7px 五档，页面上没有一条对称边——阅读入口由层叠高低与错位量给出。
视觉硬约束（逐条执行；配色与字体照此固定）：
1. 配色只用这几个值：#2F7D4F（green）、#96550F（orange）、#14100C（ink）、#F0E2C8（paper）。不新增更多彩色。
2. 字体：标题按这个顺序取第一个可用的：LXGW WenKai → KaiTi → STKaiti → Kaiti SC（前一个缺字就用下一个）。
   正文同理，按序取：Redaction 20 → Georgia → Nimbus Roman → LXGW WenKai。
3. 圆角：全站一律 0，卡片、按钮、图片、标签全部方角。
4. 阴影：无阴影。
5. 线宽只用这几级：1px、1.1px、3px，全站线条都从这几级里取。
6. 字号：正文约 17px；最大标题要压到正文的 4.2 倍（约 72px）。比这更小就撑不出这个版式——这是本案最容易被做塌的一处。中间层级你按内容需要分，但**最大那一档必须够大**。
结构约束：
- 常见失败方式（务必规避）：最容易滑向"随机贴纸拼贴"——元素乱放、颜色乱配、靠混沌冒充个性。规避动作：①随机只允许出现在跨栏数与留白上，偏移量与斜纹角度必须固定成表并公开；②橙色与绿色各自压到 34% 与 26%，深棕黑保证 26% 去压场，画面不许出现第五种实色；③每个纸块必须挂真实的展期、作者与作品编号，混沌里要有可核查的事实。
# 输出要求
只输出 HTML 代码，写进 `out.html`。不要解释，不要额外文件。
页面要真的是一个能用的网站首页，内容自拟、用中文，不要用占位符文字。
字号、线宽、配色必须严格照上面给的数。
