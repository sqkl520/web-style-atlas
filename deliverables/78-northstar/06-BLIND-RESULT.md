## 零、负对照的结果，以及它改变了什么

我造了一个不存在的风格 S99（用产品自己的 `buildStylePrompt('S99')` 产出任务书，
与 S31 逐行同构 30/40，不同的 10 行恰好都是承载风格的那 10 行），在专用沙箱里跑。

**产物 459 行 / 23,204 字节，比 S31 还大。机制句 9 个可测值全部命中。**

### 0.1 它推翻的：我上一版的核心论证有洞

我原先写：

> 十案十个互不相同的目标倍率，产物各自落在自己那一个上。
> 一个「通用好看页面」不可能同时命中十个不同目标。

**这条推理不成立。** S99 证明：给**任何**一组精确数值，同一个模型都会精确命中。
「精确命中数值」是**提示词格式的函数**，不是「这个风格被传达过去了」的函数。

S99 的 `132px / 1×9px / 12px / 18px / 93px / 6.2` 与 S31 的
`60/34/3px / 12/12/2px / 6.5 / 104px` 是同一级别的命中。我独立复跑过它的读数脚本。

### 0.2 它没有推翻的：数值通道确实可靠

- 换一套**全新配色、全新字体、全新几何**，模型依然 9/9 精确命中
- 模型执行的是机制句的**语义**，不只是字面：S99 的读数随块高变化，总和自洽
  （36 = 七块之和），一个通用页面不会自发长出这种结构

### 0.3 修正后的准确表述

```
原：提示词有效，十案证据支撑。
新：数值通道可靠（十案 + S99，共 11 次验证）；
    「精确命中」不能证明风格被传达；
    要证明那一层，需要「删掉全部数值、只留文字」的对照（尚未做）。
```

### 0.4 我在 Agent 的结论上又加了一条它自己漏掉的偏差

它报「132px 栏宽命中」。几何实测是：

```
尺寸线 left = 170px
首块   left = 212px
差           = 42px      ← 不是 132px
```

`.wrap{padding-left:132px}` 是页面级左边距，但**块内的尺寸链只占了 42px**。
它的判据是「CSS 变量写对了吗」，不是「几何上真的占了 132px 吗」——
又一处「数字对但对象错」。

## 二、隔离是怎么做的（这段决定上表可信不可信）

### 2.1 不是权限提示，是内核级拒绝

```powershell
icacls D:\Web\style /deny "ClaudeBlindBox:(OI)(CI)(RX)"
```

Deny ACE 优先于任何 Allow（包括 `BUILTIN\Users` 的继承权限），由文件系统层强制。
模型无论怎么要求 `bypassPermissions` 都改不了它。

**决定性证据必须两者同时出现**：

```
READ_REPO_DENIED              ← 以 claudeblindbox 身份读 D:\Web\style 被拒
READ_CONTROL_OK:CONTROL-OK    ← 同一进程读别处正常
WHOAMI:win10pc-sqkl520\claudeblindbox
```

只有 `READ_REPO_DENIED` 不能证明隔离 —— **环境故障也会那样**。
这正是我早先被判「隔离不可行」时的错：把 `pwsh timed out`（实际是 PATH 缺
`C:\Windows\System32`）当成了安全控制。

### 2.2 挡不住什么（必须如实说）

- **模型的先验知识**。S31 是「钟表修理铺 + 尺规刻度」，一个见过类似设计的模型
  可能凭先验做出四栏结构。这不是隔离能解决的，只能靠负对照测。
- **网络泄漏**。若 agent 能搜到本仓库的 GitHub Pages，隔离就失效。
  `WebFetch`/`WebSearch` 目前被**域名安全校验**挡住，但那是域名校验，不是网络隔离。

## 四、下一步该测什么（这是负对照给出的方向）

S99 证明的不是「S31 是假的」，而是：**上一轮的对照组选错了。**

要区分「数值可传递」与「风格被传达」，正确的问题不是
「拿到一个不存在的风格的数值，会不会做出来」（已答：会，很稳），
而是：

| 对照 | 做法 | 回答什么 | 状态 |
|---|---|---|---|
| **负对照 A** | 不存在的风格 + 精确数值 | 数值能不能被遵守 | ✅ 已做，答：能，9/9 |
| **负对照 B** | **删掉 S31 提示词里的全部数值**（`60/34/3`、`12/12/2`、`6.5`、`104px`），只留文字描述 | 文字描述本身承不承重 | ❌ **未做，最该做** |
| **正对照** | 换成一份「通用漂亮页面」的描述（无机制句、无数值） | 「通用页面」的基线高度 | ❌ 未做 |

**如果负对照 B 也做出 12 等分 + 刻度带**，说明文字描述确实承载了风格，S31 的结论可以维持。
**如果做不出来**，说明承重的是数值，那「提示词有效」要再下调一次 ——
变成「提示词能精确传递数值，但不能传递风格本身」。

这个结果我无法预判，所以不能替它下结论。
