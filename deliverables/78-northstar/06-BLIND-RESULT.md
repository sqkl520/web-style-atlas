### 1.1 唯一的线宽缺口：S31，原因是提示词自相矛盾

S31 的产品用了 3px，而档位表只有 1px。**这不是模型不听话**：

```
blind/S31/task.txt（2026-11-12 的快照，即那次盲测实际用的文本）
  第 6 行  机制句：主刻度 3px 宽、次刻度 2px 宽
  第 13 行 档位表：线宽只用这几级：1px
```

产物里 `--tick-major-w: 3px`（机制句的值）、`--hair: 1px`（档位表的值）——
它把两句话**都**照做了：通用边框守档位表，刻度守机制句。
完整证据见 `_probe/35-s31-contradiction-evidence.md`。

今天修好之后提示词不再矛盾（档位表 1px/1.5px，机制句 1.5px/1px），
但那次盲测用的是旧文本，所以这条缺口会永远留在历史记录里。

### 1.2 这张表以前错在哪

上一版写「线宽 8/10，S13 缺 9px/14.5px、S18 缺 4px」。两处都是假的，原因两个：

**① 判据方向用反。** 提示词写「全站线条都从这几级里取」是**包含性**约束
（不许用档位外的值），不是「每一档都必须出现」。「缺 9px」根本不是缺陷。

**② 就算按缺档算，S13 也不缺。** 它确实用了 5.5px，只是 Chrome 在
`getComputedStyle` 里把边框宽度**截断**到整数，5.5px 量出来是 5.00。
旧判据用四舍五入（`round(5.5)=6 ≠ 5`）把它判成「自创 5px」。
实测：`_probe/_roundtest.html` 声明 5.5/5.4/1.25/0.5 → 量到 `["1.00","5.00"]`。

**这一节能错两周的教训**：『缺档』和『用档位外的值』共用同一句依据
「提示词都明写了『线宽只用这几级』」——而那句话支持的是后者。
引用一句约束时，要读清它禁止的是哪一侧。

| S13 | 棉纸公函 | 蝉翼石室 | 0.004 |
| S29 | 液压缸大修规程册 HY-114 | 漏点对章节 | **0.000** |

这对产品的含义很具体：同一个提示词交给两个店主，会得到两份结构相同、
**文案完全无关**的页面。如果他们期待「按我的店做出我的站」，这没问题；
如果他们期待「两次结果一致」，那做不到。

## 二、隔离是怎么做的（这段决定上表可信不可信）

### 2.1 不是权限提示，是内核级拒绝

```powershell
icacls D:\Web\style /deny "ClaudeBlindBox:(OI)(CI)(RX)"
icacls D:\Web\style /deny "ClaudeBlindBox:(OI)(CI)(W)"
```

Deny ACE 优先于任何 Allow（包括 `BUILTIN\Users` 的继承权限），由文件系统层强制。
模型无论怎么要求 `bypassPermissions` 都改不了它。

> ⚠️ **2026-11-14 补：只下 `(RX)` 是半个隔离。**
> 实测沙箱账户在只有 `(RX)` 时 `WRITE_REPO_OK` —— 读不到仓库，但**能往里写文件**，
> 而「往仓库里写」正是案与案之间泄漏答案的通道。
> 两条都要下。回归脚本 `_probe/_deny-verify.ps1` 必须打印 `WRITE_REPO_DENIED`。

**决定性证据必须三者同时出现**：

```
READ_REPO_DENIED              ← 以 claudeblindbox 身份读 D:\Web\style 被拒
WRITE_REPO_DENIED             ← 往里写也被拒（2026-11-14 补）
READ_CONTROL_OK:CONTROL-OK    ← 同一进程读别处正常
WHOAMI:win10pc-sqkl520\claudeblindbox
```

只有 `READ_REPO_DENIED` 不能证明隔离 —— **环境故障也会那样**。
这正是我早先被判「隔离不可行」时的错：把 `pwsh timed out`（实际是 PATH 缺
`C:\Windows\System32`）当成了安全控制。

### 2.2 挡不住什么（必须如实说）

- **模型的先验知识**。S31 是「钟表修理铺 + 尺规刻度」，一个见过类似设计的模型
  可能凭先验做出四栏结构。这不是隔离能解决的，只能靠负对照测。
- **网络泄漏**。若 agent 能搜到本仓库的 GitHub Pages，隔离就失效。
  `WebFetch`/`WebSearch` 目前被**域名安全校验**挡住，但那是域名校验，不是网络隔离。
