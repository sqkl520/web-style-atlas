## 二、为什么这组数字算证据

### 2.1 十个目标倍率互不相同，产物各自落在自己那一个

```
S31 6.5→6.50   S04 4.2→4.24   S08 4.9→4.88   S13 3.7→3.73   S22 4.7→4.76
S32 6.3→6.31   S15 5.8→5.75   S18 4.8→4.75   S29 4.7→4.69   S35 6.0→6.00
```

**这是最硬的一条。** 目标值从 3.7 到 6.5 跨越 10 个不同水平，产物全部落在自己那一个上，
最大偏差 1.1%。

一个「通用好看页面」不可能同时命中十个互不相同的目标倍率。
如果是碰巧，得碰巧十次，且每次误差都在 1.1% 以内。

### 2.2 配色 52 个值全中，而历史上这里是真失败点

`prompt-copy.js:600-616` 记录过一次真实事故：

> 2026-11-04 的盲测发现：让模型只按提示词复刻 S17，它做出的页面缺了原型里的
> `#D6C9AC`（`--tone-hold`，悬停态）。根因是 `pickPalette()` 的上限是 7 色，
> 而该案 `:root` 有 8 色。逐案统计有 6/30 案存在这个截断。

当时第一版修法是错的：加一句「需要状态色时从上述值调明暗」，模型完全照做，
仍然只用了列出的 7 个色 —— 因为**「调暗一点」可执行，「调成 #D6C9AC 这个值」不可推断**。

这轮 52 个色值全中，说明上游修法（`clean-dna.mjs` 的 MAX 从 7 提到 9）是对的。

### 2.3 两个线宽缺口是真偏差，不是判据问题

```
S13  提示词 7 档 → 产物 5 档，缺 9px、14.5px
S18  提示词 5 档 → 产物 4 档，缺 4px
```

提示词都明写了「线宽只用这几级」。**这是真偏差。**
但语义上「少用一档/两档」不等于「做错了」——可能那个设计里没有需要该档位的地方。
建议记 **WARN 不记 FAIL**，处置留给产品判断。

## 三、隔离是怎么做的（这段决定上表可信不可信）

### 3.1 不是权限提示，是内核级拒绝

```powershell
icacls D:\Web\style /deny "ClaudeBlindBox:(OI)(CI)(RX)"
```

Deny ACE 优先于任何 Allow（包括 `BUILTIN\Users` 的继承权限），由文件系统层强制。
模型无论怎么要求 `bypassPermissions` 都改不了它。

**决定性证据必须两者同时出现**：

```
READ_REPO_DENIED              ← 以 claudeblindbox 身份读 D:\Web\style 被拒
READ_CONTROL_OK:CONTROL-OK    ← 同一进程读别处正常
WHOAMI:win10pc-sqkl520\claudeblindbox
```

只有 `READ_REPO_DENIED` 不能证明隔离 —— **环境故障也会那样**。
这正是我早先被判「隔离不可行」时的错：把 `pwsh timed out`（实际是 PATH 缺
`C:\Windows\System32`）当成了安全控制。

### 3.2 挡不住什么（必须如实说）

- **模型的先验知识**。S31 是「钟表修理铺 + 尺规刻度」，一个见过类似设计的模型
  可能凭先验做出四栏结构。这不是隔离能解决的，只能靠负对照测。
- **网络泄漏**。若 agent 能搜到本仓库的 GitHub Pages，隔离就失效。
  `WebFetch`/`WebSearch` 目前被**域名安全校验**挡住，但那是域名校验，不是网络隔离。

## 四、这批产物的特殊来历（不隐瞒）

十案里有六份是**在超时边缘救回来的**：

- S08 / S13 / S22 / S15：我中止批量时它们已写好完整 HTML，但 `result` 事件没来得及落盘
- S29：批量脚本判定 `TIMEOUT` 之后才写完 59861 字节，重查时发现 `result=success`

我原来的收集逻辑把「没有 result 事件」判成失败，**差点扔掉四份好产物**。
已修：产物存在就算成功，`result` 只用来区分「跑完写的」与「中途写的」（后者标 `OK(early)`）。

这是本轮同一类错误的第三次：**判据看到的东西 ≠ 实际发生的事**。

### 4.1 耗时分布（对下一步有用）

```
S18   331s      S15  1027s      S35  2036s      S13  2579s
S22  2579s      S29  5582s      S08  ~2900s     S04  ~2564s
```

从 5.5 分钟到 93 分钟，**跨度 17 倍**。这说明：
- 不能用一个固定超时「够用」
- 批量必须允许长尾，且超时后仍要收已有产物
