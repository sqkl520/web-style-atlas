### 2.3 但复现性测试失败了，这条很重要

同提示词、同配置跑第二次：**>28 分钟仍无产出，被我人工终止。**

第一轮 704s，第二轮 28 分钟不成。这不是「偶然慢」——
生成任务是开放式的（模型自己决定页面做多长），耗时方差按倍计。

**所以正确的表述是：**

> 提示词**可复刻**，但**成功率未知**，需要 N 次采样才能估。

这比「盲测通过」诚实，也比「盲测不可行」有用。批量方案已按此调整：
超时设 3600s，且**超时不算失败**（超时后照样收 `out.html`），按「有无产出」判成败。

## 三、沿途抓到的真缺陷（都已修，不是只报告）

### 3.1 `measure.mjs` 三个静默失败（commit 7d87923）

| 缺陷 | 后果 |
|---|---|
| 静态服务站点根 = HTML 目录 | `../_fonts/` 全 404，**字体静默回退成系统字体**，字号字距量出来全错 |
| CLI 入口 `argv[1].endsWith('measure.mjs')` | 任何以 measure.mjs 结尾的脚本 import 时也触发 CLI 分支，多跑一次测量 |
| favicon 404 | `Page.navigate` 被任一失败子资源触发 → `goto()` 抛 → 整页测量异常 |

第二条最阴：症状是「同一个函数打印两次 `[nav]`，一次路径对一次路径错」。
只看最终数字的话，它表现为「有时测的是别的案子」，而且不报错。

修后实测：S01 4 栏 `div.columns`（比例 5/16,4/16,4/16,3/16，与 CSS 吻合）、
S28 16 轨 `div.press__grid`（与 `repeat(16,minmax(0,1fr))` 吻合）。

### 3.2 S31–S35 的提示词是坏的（commit 8e99eeb）

**Q2 建这 5 个新案时，没同步加进 `build-prompts.mjs` 的 HUMAN 手写表。**

```
grep -c '^\s+S[0-9]{2}: \{ plain' build-prompts.mjs  → 30
```

取值落到兜底 `HUMAN[d.id] || { plain: "", … }`，**缺失被静默成空字符串**。后果三处，
全部用户可见：

1. 提示词里出现 `请把整页做成这个风格：。` —— 没有宾语的病句
2. 选型台卡片上的「人话版」是空白
3. `sceneIndex` 里这 5 案的场景全丢

而当时 **15 步季度体检全过** —— 因为没有一条断言问过「plain 是不是非空」。

**两件事都做了：**

- 补数据：HUMAN 表加 5 项，plain 按该文件自己写的判据（≤20 字、不含 px/HEX/角度）
- 加闸门：`check-prompts.mjs` 的 D1 断言 + `--selftest`
  - 两个变异（plain 置空 / plain 含 px）**实测都触发 FAIL 1**
  - 已接进 `quarter.mjs`，季度体检 15 步 → 16 步

修后：`请把整页做成这个风格：只给读数不表态，刻度当骨架。`

**为什么加闸门比补数据重要**：补数据只修这 5 案，闸门防住第 6 案。

### 4.2 「哪些量能当验货判据」—— 从争论变成可算的事实

我扫了全 35 份提示词，逐量查「有没有一条能让模型执行的明确指令」：

| 可度量 | 有指令的案数 | 结论 |
|---|---|---|
| 字号比 | **35 / 35** | ✅ 可以判 |
| 线宽 | **35 / 35** | ✅ 可以判 |
| 配色 | **35 / 35** | ✅ 可以判 |
| 栏数 | **12 / 35** | ⚠️ 只能在这 12 案判 |
| 图片数 | **0 / 35** | ❌ **这条判据不该存在** |

最尖锐的是图片数：提示词**从来不给图片数量**。它给的是「这个版式的设计规模是 N 个服务格」，
那是条目数，不是图片数。所以 `compare.mjs:126` 那条 `imgVisible > 0`，
其 PASS/FAIL **都不能归因** —— 没有对应的提示词指令。

而栏数 12/35 解释了我在 S31 上看到的「栏数 3 vs 原型 4」：
S31 的提示词里「栏」字出现 **0 次**，差这一栏不是模型的问题。
