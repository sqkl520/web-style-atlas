# S31 的那个「线宽违规」是提示词自相矛盾造成的，不是模型不听话

> 2026-11-14　主线程　**端到端实证**

## 一、结论

`_batch-compare.mjs` 一直报 S31「用了档位表外的线宽 3px」。查到底之后，
这不是模型的错，是**当时那份提示词给了它两个不可能同时满足的约束**：

```
blind/S31/task.txt（2026-11-12 的快照，即那次盲测实际用的文本）

  第 6 行  机制句：主刻度每 60px、长 34px、3px 宽，次刻度每 12px、长 12px、2px 宽
  第 13 行 档位表：5. 线宽只用这几级：1px，全站线条都从这几级里取。
```

**机制句要求 3px 和 2px，档位表只允许 1px。** 模型选了机制句那一套。

## 二、产物里的直接证据

产物 `_staged/S31-sandbox.html` 里：

```css
--tick-major-w: 3px      ← 机制句的值
--tick-minor-w: 2px      ← 机制句的值
--hair: 1px              ← 档位表的值
```

而全站边框几乎都写成 `border: var(--hair) solid ...`，只有刻度那一处是：

```css
border-left: var(--tick-major-w) solid var(--ink-soft)
```

也就是说：**模型把两个来源都照做了 —— 通用边框用 1px（守了档位表），
刻度用 3px（守了机制句）。** 它是在尽力同时满足两句矛盾的话，
而环境变量实测出来的 `borderWidths = ["1.00","3.00"]` 就是这两套并存的结果。

## 三、这不是抽样误差，是确定的因果

```
$ node -e "…measure('_staged/S31-sandbox.html')…"
borderWidths: ["1.00","3.00"]

$ grep -oE '\-\-tick-major-w:[^;]*' _staged/S31-sandbox.html
--tick-major-w:3px
```

而 3px 这个值**只可能来自那行机制句**：`--hair` 是 1px、没有别的 3px 声明。

## 四、今天修好之后，同一个案子不再矛盾

```
prompts.js（修后）
  dna.lineWidths : 1px、1.5px
  dna.mechanism  : 主刻度每 60px、长 34px、1.5px 宽，次刻度每 12px、长 12px、1px 宽
                   ↑ 与档位表完全一致，两个来源指向同一组数
```

修的是三处：
- `_specs/S31.md:32` 与 `:41` 的 3px/2px → 1.5px/1px（CSS 真相）
- `mechanisms.mjs:37` 的硬编码 3px/2px → 1.5px/1px
- `clean-dna.mjs` 补上 gradient 线宽抽取，档位表才从「1px」变成「1px、1.5px」

## 五、为什么这件事值得单独记一份

因为它是**本仓库那个病的完整闭环样本**：

| 阶段 | 现象 | 当时会被怎么误读 |
|---|---|---|
| 提示词有矛盾 | 机制句 3px vs 档位表 1px | 看不出来，两句话隔了 7 行 |
| 模型两条都照做 | 页面用 1px 也用了 3px | 「模型不听话，自创档位」 |
| 对账判违规 | 报「用了档位表外的 3px」 | 「模型的问题」 |
| 查产物变量名 | `--tick-major-w:3px` | 才知道那个 3px 有出处 |
| 查提示词 | 第 6 行就写着 3px 宽 | **是提示词的问题** |

**规则**：对账报「产物用了档位表外的值」时，第一步不是判模型，是回去看
**提示词里有没有第二处提到这个值**。有的话，那是提示词自相矛盾，
产物只是忠实地执行了其中一句。

D4 闸门（`check-prompts.mjs` 的 `mech-width-vs-scale`）现在会在发布前抓这一类，
但它是 2026-11-14 才加的 —— 2026-11-12 那次盲测时还没有，所以带着矛盾的
提示词跑出去了。这条案子的产物因此永远不会「合规」，直到重跑。

## 六、要不要重跑 S31

**不用。** 理由：

1. S31 的判别值 3/3 全中，产物证明「模型读懂了提示词并照做」。
2. 它唯一被判违规的那一项（3px），**恰恰证明了它照做得很准确** ——
   它连机制句里那个错的值都精确复刻了。
3. 重跑会得到一份用 1px/1.5px 的产物，那只能证明「修好的提示词更自洽」，
   而这一点由 D4 闸门保证，不需要花 3.4 小时和 $4.25 去验。

**如果将来要验证「修好之后模型是否不再用 3px」**，那是另一个问题
（检验修复效果），与「S31 的产物是否有效」（检验复刻保真度）是两件事。
