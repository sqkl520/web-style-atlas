
########## S01 红黑斜排报

-- copy (155): 主张句"那场听证会的记录，我们按发言人姓氏重排了一次，你可以从左栏倒数第二段开始读"；按钮"翻到折角里那 4 条短讯"；空状态"本期没有读者来信。投稿寄到编辑部二楼那个木信箱，我们会手工编号"；错误状态"这一期还没上版：排版机卡在 3 号铅条上，错误码 P-03。重试一次，或者先读上一期那篇没登完的听证会"。

-- quirk (105): 右侧纹样永久保留一处"漏金"缺口，位置由当天日期对 7 取模决定——同一件藏品在不同日期打开，缺口落在不同的花纹上。它不传递任何信息，也不改善可用性，存在的理由是让耐心看第二遍的人发现"这块版今天没有被压实"。
-- copy (155): 主张句"这件 1926 年的银鎏金烟盒，盒盖内侧还留着第一位主人的缩写"；按钮"预约 40 分钟到店量体"；空状态"本周的到店时段已排满。留下电话，下周一上午十点前我们会打给你"；错误状态"这个时段刚被订走：14:20 与 14:40 两格冲突，错误码 BOOK-409。换一个时段，或者留电话让店员手工排"。

########## S12 青柠挖空墙
-- def (86): 一整面青柠色层压塑料墙被 45° 与 135° 硬边斜切出七个洞口，洞口内侧有 0.5px 米白翻边，透过洞口露出深墨绿的机房底色，墙面上浮动着一层 8px 宽的斜纹边框。
-- visuals (274): 一是挖空边缘全部为 45° 或 135° 硬切，任何位置不允许圆角，切边内侧压 0.5px #F2E9D8 硬高光，模拟层压板冲切后的翻边；二是 45° 斜纹，条纹宽 8px、间距 8px，只出现在洞口边框与按钮底，角度按层级在 45° 与 135° 之间翻转；三是图标逻辑，全部为自绘硬边几何符号，16 单位网格、2px 方头线宽、只用直线与 45° 折线，绝不用任何 Emoji 或曲线图标，颜色继承文字色；四是图像处理，所有照片先做 #1E2A2E 与 #B5D626 双色分色，再用同一套斜切遮罩冲切，边缘保留 1px 套色错位，禁止羽化。
-- audit (293): 第一，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全站圆角为 0，容器由 45° / 135° 斜切定义，页面不存在柔和投影；跳脱之处在于「可通行区域」是被硬边挖出来的，不靠卡片浮起暗示层级。第二，反 C-2.14「3 / 6 / 9 等量重复的图标网格」：七个洞口不等宽不等高，其中一个留空并在角上标「未开」；跳脱之处在于不平衡是孟菲斯式的版面态度，不是功能缺项。第三，反 C-1.6「白 / 灰交替分区」：全站只有 #1E2A2E 一种底，分区靠挖空层级与斜纹方向完成。第四，反 C-1.5「抽象 3D 球体代表科技」：主视觉是层压板冲切墙面，页面内无球体、无流体金属。
-- quirk (121): 页面右下的洞口编号 01–07 是手写数字压在 45° 斜纹上，其中 04 与 05 之间的间距比其它编号窄 3px，因为街机面板丝印常常为躲开螺丝孔而挤掉一点间距。它不影响点击热区，存在的理由是把「编号是印在实物面板上的」这件事留在成品里。
-- copy (118): 主张句「这面墙有七个洞，凿开三个就算通关」；按钮「切到第 3 关：青柠管道」；空状态「这一格还没开。凑齐三条斜线就凿得动」；错误状态「洞口 05 的斜纹贴图加载失败（错误码 MASK-05），已用 45° 单色斜纹兜底，热区仍可点击」。
-- risk (146): 最易滑向「孟菲斯多色贴纸堆砌」：把青柠、洋红、黄、蓝一次摆满，就退回成样式堆砌。规避动作三条：一是只允许三个实色加一个米白，禁止引入第四个彩色；二是所有图形边界必须能追溯到 45° 或 135°，禁止曲线与自由形状；三是斜纹角度只允许 45° 与 135°，禁止 30°、60° 这类中间值。
-- landing (411): CSS 思路：挖空用 clip-path: polygon() 的 45° / 135° 折线顶点定义，翻边高光用同顶点的内缩 0.5px 副本垫底，斜纹用 SVG <pattern> 绘制，全站不引入任何 CSS 色彩插值写法。栅格单位：8 栏、6px 基线、12 / 28 / 44px 三级间隙。字体加载：Unbounded 只取两档宽度轴并子集化，未来荧黑按 GB2312 一级字库子集，font-display: swap。图片处理：双色分色后导出 AVIF，色阶压到每通道 4 bit 配合硬边风格。性能预算：首屏 JS ≤ 60KB（gzip），字体 ≤ 380KB，clip-path 不做逐帧动画，位移一律走 transform，LCP ≤ 2.0s。本方案最难被复用到别的品牌的地方，是那组 45° / 135° 的洞口顶点坐标与三级跳变间隙：换了文案之后，这组坐标仍然只适用于「一块被冲切的塑料板」。

########## S19 铜版标本柜
