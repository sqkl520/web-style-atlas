### 方案 11｜铁窗打字本（Samizdat Typewriter）

**结构类型**：F（MANUAL） ｜ **认知门槛**：高 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
整页是一份用七层复写纸打出来的检修手册：绿黑油墨在米色书写纸上留下固定三层的错位重影，页缘外侧压着一层 8px 见方的方钢窗格投影，正文被章—节—条三级编号切成可逐条引用的条目。

**2. 美学家族与参考**
东欧地下出版物（samizdat）。参考对象有三个：一是 1970–80 年代苏联与东欧的复写纸自印本实物，我们偷的是「同一页被复写七次、一次比一次淡」的衰减层级机制，而不是做旧的颜色；二是被禁文本打字稿上的打字机跳字与字符重叠，偷的是机械失误本身作为纹理来源；三是车间挂墙的《设备检修手册》编号体系（章—节—条 + 规格表 + 警示框），偷的是「编号即导航」的检索机制。第四路参考是捷克 1970 年代技术图纸的手写尺寸标注。四条参考共同指向同一个机制：层级靠印次与编号产生，不靠颜色与阴影。

**3. 配色系统**
主色 `#1B4A4A`（色相 180°，复写纸第三联墨绿，情绪：压抑）44%；背景色 `#DCDDD2`（东欧未漂白书写纸含木素，泛灰绿，色相 65.5°、饱和 5%、明度 84.5%，情绪：陈旧）38%；正文色 `#221E19`（打字机色带油墨，L 11%，脏色）13%；批注色 `#6E7A64`（褪色复写批注灰绿，S 8.6%，脏色）5%。面积和为 100。这套配色反的是 `#6366F1` 靛蓝主色、纯白 `#FFFFFF` 底、紫蓝二元渐变这三个 AI 默认件：靛蓝在复写纸工艺里不存在，纯白在 1960 年代东欧纸张里也不存在，而紫蓝渐变与单色复写这件事物理上互斥。

**4. 字体策略**
标题用 `Redaction`（OFL 1.1，该字体自带 10/20/35/50/70 五档「反复复印劣化」变体，本章节号固定取 50 档）；正文用霞鹜文楷（OFL 1.1，楷体骨架，承担中文手写温度）；辅助数字用 `Martian Mono`（OFL 1.1，可调宽度等宽，窄档模拟打字机字距）。分工是：标题层级 = Redaction 50 档，正文与条款 = 霞鹜文楷，规格表数字与引用编号 = Martian Mono 窄档。为什么不像 AI 选的：AI 默认装配线是「中性无衬线 + 几何无衬线 + 圆润无衬线」三件套，三款的性格都被抹平成同一个友好度；这里展示字体是一款以印刷退化史为设计对象的版画衬线，正文字体是楷体手写，两者分属不同超家族，字腔开口方向与笔画末端方向正好相反。落地可用性：三款全部 OFL 1.1，霞鹜文楷按 GB2312 一级字库子集化，`font-display: swap` 并配 `size-adjust` 抵消跳版。授权复核：`Redaction` 的 OFL 1.1 原文须在落地前逐页复核发布页，若复核不通过则整案替换为 `EB Garamond`（OFL 1.1，同属版画衬线谱系），字号与字距不改。

**5. 布局与网格**
12 栏，基线 8px，栏间距 24px，正文行长压到 34 个汉字。不对称方式是「章节编号悬挂在栏外 56px」，正文只占 1–7 栏，8–12 栏留给规格表与警示框，且规格表整体比正文低 1.5 行。留白节奏：相邻章之间空 3 个基线单位（24px）并压一条 1px 断针虚线，节与节之间只空 1 个基线单位。滚动行为：整页纵向连续滚动，左侧 56px 悬挂栏随滚动移出画面，不做吸顶。断点：≥1440px 悬挂编号留在栏外，规格表保留 4 栏并向右出血 24px；1024–1439px 编号退回栏内缩进 24px，规格表压到 3 栏；<768px 转单栏，规格表改为「项目 / 参数」两列竖排明细，折角导读变成顶部可横滑的章节条，一次露出 1.2 个章节以便暗示可滑动。

**6. 关键视觉元素**
一是复写重影，固定三层错位 0.5px / 1.5px / 3px，第三层不透明度 12%，并显式保留打字机跳字造成的字符重叠，重叠处的墨色不加深；二是铁窗格，版心外侧铺 SVG 方钢网格，方钢截面 8px、投影单向且硬边无模糊，网格线禁止进入正文区；三是图标逻辑，全部为自绘机械制图符号，24 单位网格、1.25px 方头线宽、笔画交点填 1 单位方角，警示用「断针三角 + 三位编号」，工具用「卡口扳手轮廓」，绝不用任何 Emoji 或彩色字形，图标颜色继承文字色并降 30% 明度；四是图像处理，所有照片先转灰度再走 1-bit 阈值抖动（Bayer 4×4），只保留 `#221E19` 与纸色两阶，最后叠 6% 不透明度的 128×128 颗粒 tile；五是首屏工艺证据，首屏必须把同一段文字的第 3、5、7 次复写三层并置在同一视口内（层间距 12px、第三层仍为 12% 不透明度），让复写的衰减层级在缩略图尺度上能被数出来，读者不必靠滚动去推测这份稿子究竟复写过几次。

**7. 动效与交互**
滚动：规格表进入视口 15% 时逐行「落下」，每行 60ms，缓动性格为阶跃式（`steps(4)`），不使用淡入；悬停：明细行反白为底色 `#221E19` 配纸色文字，不产生任何位移；加载：先出纸纹底，再从左向右扫出三层重影，总时长 700ms；转场：章节切换使用 120ms 硬切，不做交叉淡化；光标：正文区光标为 1px 竖条，闪动周期 1100ms；微交互：点击警示框会压出 1px 内凹槽，120ms 后回弹。降级：`prefers-reduced-motion: reduce` 时取消逐行落下与重影扫出，仅保留 100ms 不透明度切换，光标改为常亮。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.6「每个 section 白 / 灰交替铺底」：全站只用 `#DCDDD2` 一种底，分区靠栏外章节编号与断针虚线完成；跳脱之处在于分区物是印刷物件，底色全程不参与分区。第二，反 C-2.11「24px 圆角 + 柔和投影的卡片浮起」：全部容器直角，规格表用 1px 实线框，页面唯一的阴影来自铁窗格方钢的单向硬边投影；跳脱之处在于页面的深度是窗外的方向光给的，没有任何卡片浮在纸上。第三，反 C-1.5 与 C-2.13「抽象 3D 球体代表科技」：主视觉是一张真实复写稿的抖动扫描件，页面内不存在球体、机器人、流体金属。第四，反 `01-research-brief.md` F 节 P10「全局 ease-in-out 加滚动淡入」：本方案唯一的缓动性格是 `steps(4)` 阶跃，物理来源是打字机走纸的机械分步，全站没有一处淡入位移。

**9. 反 AI 味风险与规避**
最易滑向「复古做旧滤镜」：一旦用暖褐 Sepia 铺满全屏、再叠一张纸纹贴图，就会同时变成另一种流行模板。规避动作有三条：一是禁用任何 Sepia 与暖色滤镜，纸色只允许 `#DCDDD2` 一个值；二是复写重影必须给出 0.5px / 1.5px / 3px 三层固定错位值，不允许以「看起来发糊」交差；三是铁窗格必须画出方钢截面宽度与投影方向，禁止退化成装饰性边框。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是学术机构与档案项目站，例如禁书目录、口述史数据库、手稿影印库，编号体系天然承担检索；二是条目量大的 B 端文档类工具，例如设备检修手册、合规条文库、审计留痕系统，用户需要逐条引用而不是浏览。不适合：需要情绪价值与转化率的消费品牌首页；也不适合以视频或大图为主视觉的展览宣传页，本方案没有动态主视觉。

**可直接上线的文案**：主张句「这本检修手册只印了 300 份，编号打在封底」；按钮「翻到 4.2 节：色带更换」；空状态「这一章的复写原件已散失，只留下第 3 联的照片」；错误状态「第 4 联扫描件损坏（错误码 CARBON-04），已自动退回第 3 联，条目仍可引用」。

**11. 可落地要点**
CSS 思路：三层重影不能用 `text-shadow` 实现（它给不出 3px 层的独立不透明度），改用同一段文本的三个绝对定位副本配 `mix-blend-mode: multiply`；铁窗格用 SVG `<pattern>` 绘制方钢网格，全站不引入任何 CSS 色彩插值写法。栅格单位：8px 基线、56px 悬挂栏、24px 栏间距，长行限制 34 个汉字。字体加载：霞鹜文楷按 GB2312 一级字库子集，因楷体笔画密度高，单文件预算放到 420KB；Redaction 只加载 50 档单文件；`font-display: swap` 配 `size-adjust` 抑制布局位移。图片处理：源图先转灰度、再 Bayer 4×4 阈值抖动，输出 AVIF 与 WebP 两版，颗粒层用 6% 不透明度的 128×128 tile PNG 平铺。性能预算：首屏 JS ≤ 45KB（gzip），字体总量 ≤ 520KB，LCP ≤ 2.2s，动效只碰 `transform` 与 `opacity`。本方案最难被复用到别的品牌的地方，是复写重影的三层错位值与铁窗格的方钢截面：换掉品牌名之后，这两组数值仍然只能属于「复写纸 + 铁窗」这一件事。

**12. 设计师签名式怪癖**
每一章第一行正文的第一个汉字右下方，有一枚 0.8px 的点状墨渍，位置随章节序号逐章向左下偏移 0.4px，共 12 章，第 12 章累计偏移 4.8px。它不参与导航，也不改善阅读效率，存在的理由是把「打字机色带在同一处被反复击打」这件事留在成品里，让翻到后面的章节时能看见同一个人越打越偏的手。

**自评：8.6/10**
依据一：字段 3 的四个色值全部有实体出处（复写墨、未漂白书写纸、色带油墨、褪色批注），且同时点名反 `#6366F1`、纯白底与紫蓝渐变，可被 D-11 与 D-02 机械复核。依据二：字段 8 的四条审查点每条都落到具体禁令编号与可测数值（1px 框、8px 方钢、`steps(4)`），无形容词独立成立。

### 方案 12｜青柠挖空墙（Lime Knockout Wall）

**结构类型**：R（MASK） ｜ **认知门槛**：低 ｜ **调性**：荒诞幽默 / 玩心

**1. 一句话视觉定义**
一整面青柠色层压塑料墙被 45° 与 135° 硬边斜切出七个洞口，洞口内侧有 0.5px 米白翻边，透过洞口露出深墨绿的机房底色，墙面上浮动着一层 8px 宽的斜纹边框。

**2. 美学家族与参考**
孟菲斯集团（Memphis，1980 年代米兰）。参考三个真实对象：Ettore Sottsass 1981 年首展的层压塑料家具（Carlton 书架）、Nathalie Du Pasquier 的斜纹图案布样、1980 年代街机框体的丝印面板。偷的机制是「层压板把图案压进塑料里，所以边缘必然被压出一条白线」，以及「斜纹是印刷方向而不是装饰花纹」。我们拿的是压印翻边与斜纹方向这两件事，不是拿一组孟菲斯色卡。

**3. 配色系统**
主色 `#B5D626` 青柠（色相 72°，情绪：顽皮）34%；背景色 `#1E2A2E` 深墨绿（L 15%，脏色，情绪：机房底）48%；强调色 `#E23E57` 洋红（情绪：塑料贴纸）12%；贴面色 `#F2E9D8` 米白（层压板芯纸，情绪：切口）6%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「深底加霓虹紫青」的仪表盘套路：青柠是被压进塑料的实色，不带光晕也没有发光边；底色是带绿的墨色，既不是纯黑也不是 `#0F172A` 那种蓝黑。按钮与色块约束：主色 `#B5D626` 作填充时白字只有 1.67:1，一律改用深色文字 `#111111`（实测 11.34:1），或把主色退到只有 45° 斜切的描边与图标位、不承担文字底。

**4. 字体策略**
标题用 `Bricolage Grotesque`（OFL 1.1，宽度轴 75–100 与字重 200–800 双向极端，「圆钝粗笨」由宽度轴的后段给出）；关卡号与洞口编号用 `JetBrains Mono`（OFL 1.1，等宽，只用于 14px 以下的编号与分数，不承担标题）；正文用未来荧黑 Glow Sans（OFL 1.1，硬骨架几何黑体）。分工：标题层级 = Bricolage Grotesque 极宽档；正文与规则说明 = 未来荧黑；关卡号 / 分数 / 计时 = JetBrains Mono。为什么不像 AI 选的：不用被组件库写死的默认无衬线栈；Bricolage 的宽度轴能让同一个字既是方块又是长条，这正是孟菲斯层压板的冲切逻辑，AI 默认的单一字重无衬线做不出这种尺度差。落地：三款均 OFL 1.1，未来荧黑按 GB2312 一级字库子集，`font-display: swap` 配 `size-adjust` 抑制跳版；授权复核：`Bricolage Grotesque` 的 OFL 1.1 原文须在落地前逐页复核发布页。

**5. 布局与网格**
8 栏，基线 6px（对齐街机像素栅格），栏间距 0。不对称方式：七个洞口按 3 / 2 / 1 / 1 的行数递减错位堆叠，最大洞口跨 4 栏，最小洞口只占 1 栏并故意留空，整体重心压在版面左侧 38% 处。留白节奏：洞口之间不留均匀间隙，间隙按 12px / 28px / 44px 三级跳变，形成冲切落料的不规则边角。滚动行为：主体是一屏高的墙面，滚动到 60% 时墙面向右平移 40px 露出第二层，第二层仍是挖空墙但斜纹方向翻转。断点：≥1440px 保持 8 栏与满屏墙面；900–1439px 折为 6 栏，最大洞口降到 3 栏，平移量减到 24px；<900px 挖空机制完整保留并换一种不对称方式，墙面变为「双列错位咬合」，两列斜边洞口以 16px 互相压叠交替排列（左列洞口上沿为 45° 斜切、右列下沿为 135° 斜切），两列宽分别为 42% 与 50%，斜纹边框收窄到 4px 但角度仍只允许 45° 与 135°，翻边高光保持 0.5px，Tab 顺序仍按洞口编号 01–07 硬性排列，触屏点击热区不小于 44×44px；<768px 两列咬合改为上下咬合，列宽改为 50% 与 46%，互压量由 16px 增到 20px，斜纹角度与 0.5px 翻边高光参数不变。

**6. 关键视觉元素（≥3 个）**
一是挖空边缘全部为 45° 或 135° 硬切，任何位置不允许圆角，切边内侧压 0.5px `#F2E9D8` 硬高光，模拟层压板冲切后的翻边；二是 45° 斜纹，条纹宽 8px、间距 8px，只出现在洞口边框与按钮底，角度按层级在 45° 与 135° 之间翻转；三是图标逻辑，全部为自绘硬边几何符号，16 单位网格、2px 方头线宽、只用直线与 45° 折线，绝不用任何 Emoji 或曲线图标，颜色继承文字色；四是图像处理，所有照片先做 `#1E2A2E` 与 `#B5D626` 双色分色，再用同一套斜切遮罩冲切，边缘保留 1px 套色错位，禁止羽化。

**7. 动效与交互**
滚动：墙面平移触发阈值为滚动 60%，位移 40px，时长 480ms，缓动性格为一次性过冲（`cubic-bezier(0.2,1.5,0.4,1)`），落位时回弹 6px；悬停：洞口斜纹相位错开 8px（即条纹接缝跳一格），时长 120ms，不位移不缩放；加载：七个洞口按 01–07 顺序做冲切落下，每洞 90ms，缓动为 `steps(3)`；转场：关卡切换用 200ms 硬切配 1px 轮廓闪一次；光标：20px 方形空心框、2px 边框，进入洞口后框内转为斜纹；微交互：按钮沿 135° 下沉 2px 并露出 2px 底层洋红。降级：`prefers-reduced-motion: reduce` 时取消墙面平移与回弹，洞口直接切换，闪烁改为 100ms 不透明度变化。

**8. 去 AI 味审查点（≥3 条）**

### 方案 13｜盲压公函（Blind-Emboss Dispatch）[高危改造]

**结构类型**：F（DOSSIER） ｜ **认知门槛**：中 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一份用棉纸印的公函：全文没有一处墨色差，条款标题是靠 0.4mm 深的盲压凹槽被读出来的，唯一有颜色的是编号处一小块烫金击凸，光从左上角来，凹槽就成槽，光从右上角来，同一条槽看起来变成凸线。

**2. 美学家族与参考**
Neumorphism 的实物化改造：把它从屏幕上的软挤出拉回日本凸版印刷的盲压（blind emboss）与烫金击凸工艺。参考三个真实对象：日本活版印刷所的盲压名片与请柬（无墨压印 + 棉纸纤维）、中国传统公文的「函 / 徵 / 字第 N 号」抬头与签发栏格式、以及 2020 年代日本文具品牌的压印信纸。偷的机制是「凸版印刷机的压力会把纸纤维压塌，凹陷是纸的形变，不是颜色的深浅」，以及「烫金只用来点一个位置，用多了就变成贴纸，盖住击凸的效果」。

**3. 配色系统**
背景色 `#F4E3BE`（盲压棉纸老龄泛黄，色相 41.1°、饱和 22.1%、明度 85.1%，情绪：无墨）56%；正文色 `#241F17`（印刷墨，L 12%，脏色，情绪：端肃）27%；主色 `#7B612C`（烫金击凸，色相 40.2°、明度 32.7%，脏色，情绪：矜持）9%；压印暗侧 `#D6CDB9`（凹槽受光弱的一侧，情绪：形变）8%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「纯白底 + 纯黑字 + 单一强调色」的偷懒三色：底色是偏黄 4 级的棉纸色而非纯白，文字是暖黑而非纯黑，且全文八成的立体感来自亮度差不超过 6% 的形变而不是彩色。2 号方案用的是烫金镜像，本方案用的是无墨盲压，两者的金色面积占比相差一个量级。对比度实测（脚本计算）：主色 `#7B612C` 对背景 `#F4E3BE` 为 4.62:1，达到 AA 正文线，修正前 `#A8843C` 对旧底色只有 2.70:1，属硬失败，已换掉；烫金块上的文字一律用纸色 `#F4E3BE`（4.62:1），`#111111` 压在烫金上只有 3.23:1，不采用。

**4. 字体策略**
标题用 `EB Garamond`（OFL 1.1，威尼斯拉丁老式衬线，小写带手写倾斜）；正文用文津宋体（免费商用，发布页须复核授权文本）；辅助数字与函号用 `DM Mono`（OFL 1.1，低对比等宽，字腔偏机械，与公文正文拉开字宽）。分工：抬头与条款标题 = EB Garamond 加文津宋体宽排（字距 0.06em）；条款正文 = 文津宋体 15px / 行高 1.75；函号、日期、编号 = DM Mono。为什么不像 AI 选的：AI 默认三件套全部是无衬线，且把「干净」等同于一家的新怪诞；这里让带手写倾斜的老式衬线、刻版宋、工程等宽三者并存，靠字腔开合与笔画末端方向做对比。落地：三款授权分别为 OFL 1.1、免费商用、OFL 1.1，文津宋体按 GB2312 一级字库子集，`font-display: swap`。

**5. 布局与网格**
16 栏细分栅格（公文格式的栏线细分），基线 8px，正文 15px / 26px 行高，行长限制 32 个汉字。不对称方式：正文条款只占 1–11 栏，签发栏贴在 13–16 栏并整体下移 2 行，抬头满幅出血且左侧内距比正文小 16px。留白节奏：条款之间空 2 个基线单位，函件与附件之间空 6 个基线单位并压一条 1px 的压痕线（不是画出来的线，是压出来的槽）。滚动行为：单列纵向滚动，签发栏在滚过 80% 后固定在视口底部而非顶部，因为签发是最后的动作。断点：≥1440px 保留 16 栏与右挂签发栏；1024–1439px 折为 12 栏，签发栏并入正文下方但保留 2 行下沉；<1024px 单栏，函号与日期由横排改为左对齐两行，压痕线宽度收到 1px 并取消接触阴影，键盘焦点环改为 2px 方形压痕而非彩色描边。

**6. 关键视觉元素（≥3 个）**
一是盲压凹槽，凹槽与周围纸面的亮度差固定为 3%（该数值为凹槽可见带的实测平均亮度差：该带由纸色 `#F4E3BE` 与背光侧 `#D6CDB9` 按 55:45 的面积加权得出，两色本身的明度差为 6.9%），靠 135° 单向硬光源与 0.4mm 压深被感知，边缘对比度控制在 14%，只有一侧投影且带接触阴影；二是纸纤维起伏，由程序化噪声生成，亮度幅度 ±2 级、纤维方向偏 12°，在凹陷区加密；三是图标逻辑，自绘凸版压印符号，20 单位网格、1.5px 方头线宽、笔画交点填 1 单位方角，签发用「骑缝章方框 + 函号」，驳回用「缺口圆环」，绝不用任何 Emoji，图标只有凹凸没有颜色；四是图像处理，文件翻拍一律用 45° 侧光拍摄以留下真实阴影，输出灰度后只保留纸色与墨色两个色阶，颗粒不叠加而改用纤维噪声；五是首屏工艺证据，首屏把函号旁的骑缝章方框与烫金块放大到可辨尺寸（方框 ≥ 64px、烫金块按正文 200% 排布），让 3% 亮度差的凹槽在缩略图尺度上有一个高对比的参照物，读者一眼能看出「这里有凸版工艺」而不是一张米色长文页。

**7. 动效与交互**
滚动：条款进入视口 20% 时逐条「压出」，每条 120ms，缓动为 `steps(2)`（模拟压印机一次压下）；悬停：凹槽的接触阴影加深一级（亮度差从 3% 升到 5%），无位移；加载：先出纸纤维底，再让抬头与函号依次压出，总时长 520ms；转场：函件之间用 160ms 硬切并伴随一次全屏亮度降 2 级再回；光标：跟随一个 6×6px 的方形压痕，按下时压痕加深；微交互：任何按钮按下时光源方位角由 135° 反转为 315°，切换 120ms，同时下沉 0.8px。降级：`prefers-reduced-motion: reduce` 时取消压出与光源反转的过渡，按钮按下改为 0.8px 瞬时位移配 100ms 亮度变化，光标压痕改为静态方框。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全站圆角为 0，所有容器都是直角铅字块，页面没有任何柔和投影，唯一阴影来自单向硬光源；跳脱之处在于层级是纸被压塌形成的凹槽，不是元素被抬起。第二，反 C-1.4 与 C-2.14「Emoji 图标与三等量图标网格」：图标全部是凹凸符号，只有形变没有颜色，且条款条目数量为 7 条与 4 条两段而非 3 / 6 / 9。第三，反 C-1.6「白 / 灰交替分区」：全站只用 `#F4E3BE` 一种底，分区靠函号与压痕线。第四，反 C-4 与 R-28：本方案不写「极简」这类形容，立体感一律给成 0.4mm 压深、3% 亮度差、14% 边缘对比度三个数。

**反套路改造三指标（对齐 02 号文件 8.3 节，供 V-11 / R-40 逐条打勾）**
- **必须存在 X**：单向硬光源方位角常驻 135°（误差 ±10°）；压印深度 0.4mm 等效；纸纤维起伏由程序化噪声生成、亮度幅度 ±2 级、纤维方向偏 12°；阴影只出现在凹槽一侧并带接触阴影。四条缺一即不成立。

最易滑向「苹果式同色系软挤出」：只要把背景与控件保持同色、再挂两枚对称阴影，立刻退回 Neumorphism 的默认套餐。规避动作三条：一是任何控件都不得使用同色系双阴影，全部改为单向硬光源加接触阴影；二是全文不允许出现圆角胶囊形状，按钮一律直角铅字块；三是立体感必须能用「亮度差 3% + 压深 0.4mm」两个数解释，凡解释不了的凹凸全部删掉。

适合两类项目：一是文档协作后台与合同、审批、签署类 B 端系统，用户需要一眼看清「谁签发、什么状态」；二是严肃出版机构、档案馆、研究机构的形象站与公文发布页。不适合：需要强对比与高识别度的营销落地页，本方案的整体对比度被刻意压在低位；也不适合移动端为主要入口的消费产品，盲压凹槽在低亮度屏幕与强光环境下几乎不可辨。

CSS 思路：凹槽用单向内阴影加单向外接触阴影两条实现，方向由 CSS 变量 `--light-azimuth` 统一控制，按下时把变量从 135deg 改为 315deg；禁止使用 `backdrop-filter` 与任何 CSS 色彩插值写法；纸纤维用一层程序化噪声 SVG `feTurbulence` 生成后转成静态 PNG 平铺，避免每帧重算。栅格单位：16 栏、8px 基线、26px 正文行高。字体加载：文津宋体按 GB2312 一级字库子集，EB Garamond 只取 Roman 与 Italic 两档，`font-display: swap` 并配 `size-adjust`。图片处理：翻拍图 45° 侧光拍摄，灰度化后压到双色阶，输出 AVIF。性能预算：首屏 JS ≤ 40KB（gzip），字体 ≤ 460KB，噪声纹理 ≤ 12KB，光源反转只改两个阴影色值不做逐帧动画，LCP ≤ 2.1s。本方案最难被复用到别的品牌的地方，是盲压深度与亮度差这一对数值：任何有彩色强调色的品牌套上去，凹槽就会被颜色抢走，方案立刻失效。

### 方案 14｜零重力发射序（Zero-G Launch Sequence）

**1. 一句话视觉定义**
一块贴在舱壁上的铝箔标贴组：十一枚 0.15mm 厚的橙色铝箔标签共享一个缓慢漂移的虚拟质心，在墨蓝黑的舱内底色上一起飘，谁都不绕自己的轴转，右下角一行遥测读数始终报出质心当前坐标。

**2. 美学家族与参考**
太空时代（Space Age，1960 年代美国航天视觉）。参考三个真实对象：NASA 阿波罗计划舱内标贴与检查单（铝箔背胶、热压编号）、1960 年代美国空军遥测面板的图例编号体系、以及瑞士飞行员腕表表盘的刻度布局。偷的机制是「舱内所有标签都挂在一个共同参考系上，所以它们的相对位置本身就是信息」，以及「铝箔标贴的反光带只在特定视角出现，贴纸是会随观察者改变的东西」。我们拿的是共享质心与视角反光，不是星空背景与火箭剪影。

**3. 配色系统**
背景色 `#12181D` 舱内暗蓝黑（L 9%，脏色，情绪：疏冷）62%；主色 `#E4572E` 铝箔标贴橙（色相 13.5°，情绪：工业标记）18%；辅助色 `#D8D2C4` 铝箔银白（未涂布铝面，情绪：金属）15%；压痕暗侧 `#8A3320`（热压击凸的背光侧，L 33%，脏色）5%，面积和 100。这套配色反的是「深色底 + 霓虹紫青 + 发光边框」的仪表盘套路，也反 `#6366F1` 靛蓝与纯白底：橙色来自真实铝箔涂布色而非霓虹，银色是金属反射而非 `#F5F5F5` 灰，暗部是带蓝的舱内黑而不是纯黑。按钮与色块约束：主色 `#E4572E` 作填充时白字只有 3.68:1，不达标，一律改用深色文字 `#111111`（实测 5.13:1）。

**4. 字体策略**
标贴标题用 `Oswald`（OFL 1.1，超窄展示体，字重 200–700，招牌与工程模板血统）；中文用朱雀仿宋（OFL 1.1，仿宋骨架窄排，公文与器械标签的典型面貌）；遥测读数用 `Space Mono`（OFL 1.1，等宽且字腔方正，读数对齐时不出现斜体错觉）。分工：标贴标题 = Oswald 加朱雀仿宋（字距 0.08em，压缩排）；说明与检查项 = 朱雀仿宋 14px / 行高 1.8；遥测数字与编号 = Space Mono。为什么不像 AI 选的：AI 默认三件套是无衬线加几何无衬线加圆润无衬线，且默认字体在窄体与仿宋这两个方向上一片空白；这里用窄体拉丁标题配仿宋正文，中拉混排时横向压缩率一致，读起来像贴在金属上的标签。

**5. 布局与网格**
基线 8px，不使用固定栏数，改用「质心极坐标」：每枚标贴的位置由到质心的距离 r 与方位角 θ 定义，r 按内容质量分 24 / 40 / 72 / 120px 四档，θ 间隔按 11 枚标贴非均匀分布（最小间隔 26°，最大间隔 61°）。不对称方式：质心本身偏离视口几何中心 6% 且持续漂移，所以任何时刻画面都不对称。滚动行为：滚动量映射为质心位移，滚动 1000px 质心位移 160px，标贴作为整体平移，不做各自视差。

**放弃常规导航后的可发现性机制（四条通路，缺一即退回不可用）**
第一条是编号即顺序：十一枚标贴各有唯一四位航电编号（如 A-1107），编号顺序就是阅读与 Tab 顺序，键盘可达且焦点环为 2px 直角方框。第二条是常驻最近邻列表：视口右下角固定显示「距质心最近的三个标贴编号与标题」，不随漂移移动。第三条是质心读数：视口左上角常驻坐标与进度（如 `X-004 / Y-112`、`3 / 7`），让用户知道自己处在任务流的哪一步。第四条是引力牵引反馈：指针进入标贴 64px 范围内，该标贴向指针牵引 8px 并在 180ms 内显出编号，离开后回弹，用户不需要猜测哪里可点。

**断点具体行为**
≥1440px 保持极坐标布局、质心漂移半径 48px、周期 24s；1024–1439px 漂移半径降到 24px，标贴 r 值整体压缩 20%，最近邻列表移到右下角并与边缘保持 24px 内距；<1024px 极坐标与质心漂移完整保留，换成「纵向极坐标」：质心移到视口上三分之一处并沿纵轴缓漂，漂移半径保持 12px、周期 32s，标贴按方位角由 −80° 到 +80° 排成一列，但每枚标贴仍按自身 r 值做 8–20px 的横向偏移，四位编号与常驻最近邻列表（3 条）继续固定显示，牵引反馈改为指针进入 48px 范围时横向牵引 6px，触屏点击热区不小于 44×44px；<768px 纵向极坐标的质心移到视口上四分之一处，漂移半径减到 8px、周期保持 32s，四位编号与最近邻列表（3 条）位置不变。

**6. 关键视觉元素（≥3 个）**
一是铝箔标贴本体，0.15mm 厚，边缘 1px `#D8D2C4` 高光，热压编号凹进 0.3mm，反光带只在 12° 视角区间内出现，出区间即消失；二是低重力气泡纹理，直径 3–9px 的硬边圆环散布在底色上，边缘 1px 硬线、不发光、无填充，模拟微重力下悬浮的液滴；三是图标逻辑，自绘航电标贴符号，24 单位网格、1.25px 单线、方头端点，符号取自阿波罗检查单图例（阀门用「蝶形缺口」、压力用「半圆加指针」、电路用「断口折线」），绝不用任何 Emoji；四是图像处理，所有照片走双色调加 12° 高光带处理，铝箔反光处叠加 8% 不透明度的 128×128 颗粒，禁止柔光与镜头光晕。

**7. 动效与交互**
滚动：质心位移由滚动量线性映射，但位移本身走 2400ms 长尾阻尼（`cubic-bezier(0.25,0.1,0.25,1)`），停手后仍余 40px 缓漂；悬停：标贴受引力牵引 8px，180ms，缓动为轻过冲，抬起后 260ms 回位；加载：各标贴按 r 值从大到小依次从失重状态落位，总 900ms，缓动为阻尼；转场：切换任务段时视角沿质心轴转向 6°，400ms；光标：24px 十字准星，旁挂 4 位坐标读数；微交互：点击标贴后其自转 2° 再回正（模拟无阻尼翻滚），耗时 320ms。降级：`prefers-reduced-motion: reduce` 时质心停止漂移、取消牵引与落位，改为静态极坐标定格，编号、最近邻列表与质心读数全部保留，仅去掉位移与翻滚。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.3 与 R-12「居中大标题加三张等宽卡片加底部 CTA」：本方案没有 hero，也没有栏式主体，十一枚标贴的位置由极坐标与质量分级决定；跳脱之处在于版面重心持续小幅漂移，任何时刻截图都不居中。第二，反 C-2.10 与 C-1.5「渐变与抽象球体代表科技」：主视觉是铝箔标贴与其 12° 视角反光带，页面内没有色彩插值写法、没有发光球体、没有流体金属。第三，反 C-2.14「3 / 6 / 9 等量图标网格」：标贴共 11 枚且尺寸按 24 / 40 / 72 / 120px 分四档，不存在等量重复。第四，反 `01-research-brief.md` F 节 P13「所有元素完美居中」：质心偏置 6% 且漂移，漂移量在字段 5 与字段 7 都写成了具体数值。

**9. 反 AI 味风险与规避**
最易滑向「深色太空壁纸加星点」：一旦铺一张星空底图并让元素各自浮动，立刻变成常见的深色科技页。规避动作三条：一是底色只允许 `#12181D` 一种，禁止星空、星云、渐晕；二是所有位移必须是共享质心的整体位移，禁止每个元素独立视差；三是可发现性四条通路必须在静态截图里也成立，如果去掉动效就找不到内容，方案判不合格。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是开发者工具与基础设施产品的站点，尤其是需要表达「多个模块共享一个状态」的调度、遥测、部署类产品；二是工业设备与航天、能源、检测行业的 B 端界面与形象站。不适合：需要线性阅读的长文内容站与出版物，极坐标布局无法承载连续段落；也不适合以转化率为唯一目标的营销页，用户第一眼找不到「购买」这类单一动作。

**可直接上线的文案**：主张句「十一枚标贴共享一个质心，读数就是位置」；按钮「跳到标贴 A-1107：推进剂加注」；空状态「遥测链路上还没有第 4 个数据包。下一次下行窗口是 02:14 UTC」；错误状态「质心同步超时（错误码 ZEROG-07）：标贴停在上一帧位置，编号与最近邻列表仍可读，02:14 UTC 下行窗口后自动重同步」。

**11. 可落地要点**
CSS 思路：极坐标用 `transform: translate(r·cosθ, r·sinθ)` 计算后写入自定义属性，滚动只改质心这一个变量，避免为每枚标贴各算一条时间线；反光带不使用任何 CSS 色彩插值写法，改用一张随 `--view-angle` 位移的位图遮罩。栅格单位：8px 基线、四档 r 值、26° 最小角度间隔。字体加载：Archivo Narrow 只取 Regular 与 SemiBold 两档宽度轴，朱雀仿宋按 GB2312 一级字库子集，Martian Mono 只取窄档，`font-display: swap`。图片处理：照片双色调化后输出 AVIF，反光带遮罩单独打包，颗粒层 8% 不透明度平铺。性能预算：首屏 JS ≤ 70KB（gzip），字体 ≤ 500KB，漂移只跑 `transform` 与 `opacity` 两个属性并做 `will-change` 收敛，LCP ≤ 2.3s。本方案最难被复用到别的品牌的地方，是十一枚标贴的极坐标角度表与质心漂移半径：换成另一个品牌后，这组角度仍然只对应这一套任务流。

**12. 设计师签名式怪癖**
每枚标贴的右上角压着一枚 0.6mm 高的手写缩写「地勤」，共 11 处，且每一处的字迹抖动都不一样，因为它是设计师用同一支笔在十一张真实铝箔上写完后逐张扫描进去的。它不提供任何信息，存在的理由是把「这批标签真的是被人一张张贴上去的」这件事留在界面里。

### 方案 15｜渔场平面簿（Fishery Floor Ledger）

**结构类型**：F（FLOORPLAN） ｜ **认知门槛**：高 ｜ **调性**：温暖手作 / 人味

**1. 一句话视觉定义**
一本 1930 年代挪威渔场的硫酸纸平面簿：三层半透明描图纸叠在同一张网具舱平面图上，最上层是 0.8px 的铅笔硬线标注与橡皮擦过留下的白痕，页脚钉着一根 1:200 的手绘比例尺，图例挂在平面图右侧只占六成高度。

**2. 美学家族与参考**
北欧渔业档案（1930 年代挪威）。参考三个真实对象：挪威渔业博物馆保存的鳕鱼场与网具舱平面测绘图、1930 年代工程师用的硫酸纸（tracing paper）三层透叠制图法、以及同期手绘比例尺与图例的排布习惯。偷的机制是「透叠是把不同年代的信息压在同一张图上，所以三层必须错开才能读出各自属于哪一年」，以及「铅笔标注是会被擦掉的，擦痕本身是修订史」。我们拿的是透叠层数与擦痕，不是泛黄纸感。

**3. 配色系统**
主色 `#3A3F45` 石墨（色相 213°，饱和 15.9%，明度 24.9%，同时构成脏色，情绪：朴拙）46%；背景色 `#E7EBE9` 硫酸纸透光色（冷白半透明描图纸，色相 150°、饱和 1.7%、明度 91.4%，情绪：透叠）34%；深色 `#22282B` 铅笔重压处与图例底（L 15%，脏色）15%；铅笔灰 `#7A7466`（普通标注线，饱和 8%，脏色）5%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色与「深蓝底加白色线稿」的蓝图套路，也反纯白底：石墨是铅笔与晒图两者的交集色，饱和只有 15.9%，而多数 AI 生成的「档案风」是给泛黄纸加一个暖滤镜，本方案整体偏中性，暖只出现在纸色一个值上。

**4. 字体策略**
标题用 `Newsreader`（OFL 1.1，为屏幕重绘的报纸衬线，带光学尺寸轴）；中文用思源宋体（OFL 1.1，横细竖粗，长文宽排）；读数与坐标用 `Reddit Mono`（OFL 1.1，窄等宽，纵向字面紧凑）。分工：平面图标题与档案标题 = Newsreader 加思源宋体宽排（字距 0.04em）；说明文与档案条目 = 思源宋体 15px / 行高 1.9（长宋宽排的行长放到 38 个汉字）；深度读数、坐标、登记号 = Reddit MonoMono。为什么不像 AI 选的：AI 默认装配线里没有一款报纸衬线，也没有把中文宋体的行高放到 1.9 的做法；这里展示与正文的对比靠字面宽度与行距节奏，而不是靠换一款几何无衬线。

**5. 布局与网格**
12 栏，基线 8px，栏间距 20px。不对称方式：平面图占 1–8 栏并向左侧满幅出血 40px，图例悬挂在 9–12 栏，高度只到平面图的 62% 且顶部对齐平面图的 1/3 处；比例尺贴在版心右下角，宽度固定 240px。留白节奏：平面图外围留 4 个基线单位的空白（这是测绘纸的图廓留边），档案条目之间只留 1 个基线单位，形成「图幅大留白、条目小间距」的两级节奏。滚动行为：平面图随滚动整体缩小到 68% 并向上让位，图例保持原位不缩放，比例尺始终贴住视口下沿内 24px。

**三层硫酸纸的透叠规则**
固定三层，层间错位量分别为 0 / 3 / 7px，透明度 100% / 78% / 56%；第一层是 1934 年原始平面，第二层是 1936 年的网具区修订，第三层是 1938 年的水深补测。切换年份时只有对应层的不透明度升到 100%，其余两层降到 30%，避免三层同时全亮导致读不清。图例中每一层用不同线型区分（实线 / 长虚线 / 点划线），不靠颜色区分，因为真实硫酸纸上三层都是同一支铅笔。

**断点具体行为**
≥1440px 保留 12 栏、平面图满幅左出血 40px、比例尺 240px；1024–1439px 折为 9 栏，图例移到平面图下方并横向排成 2 列，比例尺缩到 180px；<1024px 单栏，三层硫酸纸改为按层折叠成三个可展开的板块（点击层标题展开该层标注），比例尺固定在页脚不随滚动，热区点击面积一律不小于 44×44px 以保证触屏可用。

**6. 关键视觉元素（≥3 个）**
一是硫酸纸透叠，三层错位 0 / 3 / 7px，边缘有 1px 的纸张毛口，层与层交叠处亮度自动降低 6%（用混合模式实现而非降低不透明度）；二是铅笔标注，线宽固定 0.8px 硬线，端点方头，末端带 2–6px 的橡皮擦除残迹（表现为线条中断后留下 12% 不透明度的浅灰底），修订编号写在擦痕旁；三是图标逻辑，自绘测绘符号，32 单位网格、1px 单线，三角点用「等边三角加中心点」、等深线用「三级粗细递变曲线」、锚位用「带横杆的十字」，绝不用任何 Emoji，符号线宽只有 0.8px 与 1.2px 两级；四是图像处理，所有照片先扫描成灰度，再压到石墨与纸色两个色阶，保留原始铅笔压痕的侧向阴影，禁止暖色滤镜与纸张纹理贴图。

**7. 动效与交互**
滚动：平面图缩放触发阈值为滚动 200px，缩到 68%，时长 600ms，缓动性格为阻尼无过冲；悬停：热区边界由 0.8px 变 1.2px 并显示该区登记号，140ms，无位移；加载：三层硫酸纸按 1934 / 1936 / 1938 顺序依次叠上，每层 220ms，缓动为线性（模拟手动落纸）；转场：年份切换用 260ms 交叉叠化，且只有两层参与，第三层保持不动；光标：24px 十字加 0.5px 细圈，进入热区后细圈变为虚线；微交互：点击热区时该区在图例中的对应线型同步加粗一次（160ms）。降级：`prefers-reduced-motion: reduce` 时取消平面图缩放与逐层叠上，三层改为静态全部可见，年份切换用 100ms 不透明度瞬切，比例尺不再贴视口下沿而固定在图幅内。

**8. 去 AI 味审查点（≥3 条）**

### 方案 16｜速度斜排宣言（Velocity Slant Manifesto）

**结构类型**：R（SCROLLY） ｜ **认知门槛**：低 ｜ **调性**：混乱活力 / 街头

**1. 一句话视觉定义**
一叠 1910 年代活字宣言单页：九个超粗词的词块沿一条 12° 的斜线堆叠，铅字把纸压出 0.3mm 的凹痕，每块底下拖着三条 1px 速度线，越往下滚动词块沿斜线跑得越快。

**2. 美学家族与参考**
意大利未来主义（Futurismo，1910 年代）。参考三个真实对象：Filippo Marinetti 1909 年《宣言》在《费加罗报》上的排版实验、1910 年代意大利未来派海报上的斜排词块与自由排字（parole in libertà）、以及铅字活版印刷中「压力在纸上留下的凹痕与油墨堆积边」。偷的机制是「让所有词块共用一条斜向基线，仅把单块文字倾斜一个角度算不上斜排」，以及「速度感来自位移的加速度而不是线条的数量」。我们拿的是共用斜基线加加速轨道，不是拿爆炸形状与感叹号。

**3. 配色系统**
主色 `#C52C0F` 未来派朱红（色相 9.6°、明度 41.6%，情绪：躁进）26%；背景色 `#F7EBCF` 未漂白宣言纸（色相 42°、饱和 16.2%、明度 89%，情绪：脆薄）56%；正文色 `#1A1A1A` 铅字黑（L 10%，脏色，情绪：重压）14%；压痕暗侧 `#8E2A18`（铅字凹痕的背光边，L 30%，脏色）4%，面积和 100。这套配色反的是 `#6366F1` 靛蓝与紫蓝渐变，也反「纯白底加纯黑字加单一强调色」的三色偷懒：纸是偏黄的未漂白纸，黑是铅字黑而非纯黑，朱红只占 26% 且有一个同色相的压痕暗侧作为第四个色，第四色不另加彩色，取同一支油墨的凹陷侧。对比度实测（脚本计算）：主色 `#C52C0F` 对背景 `#F7EBCF` 为 4.74:1，达 AA 正文线（修正前 `#E63312` 只有 3.52:1，属硬失败，已换掉）；主色作实色块填充时按钮文字恢复白字（`#FFFFFF` 对 `#C52C0F` 为 5.61:1），正文色 `#1A1A1A` 对背景 14.70:1。

**4. 字体策略**
中文标题用霞鹜漫黑 LXGW Marker Gothic（OFL 1.1，马克笔头粗窄黑体，自带轻微后仰角，作本方案中文主字体）；拉丁标题用 `Archivo Black`（OFL 1.1，超粗 grot，宽度轴可压到极窄）；正文用思源宋体（OFL 1.1，同时承担中拉正文，其自带的拉丁字形作本方案唯一拉丁正文字面，因此不再单独引入拉丁衬线）；数字与块号用 `Fragment Mono`（OFL 1.1，等宽，字面偏窄）。分工：词块标题 = 霞鹜漫黑加 Archivo Black；说明与注文 = 思源宋体 15px / 行高 1.8（中拉同族，不再混排）；块号与日期 = Fragment Mono。为什么不像 AI 选的：AI 默认三件套是无衬线加几何无衬线加圆润无衬线，展示与正文同属无衬线超家族；这里展示字形是马克笔头的粗窄黑体，正文改用低对比刻版宋，倾斜与垂直、粗与细之间形成结构级对比，而不是靠换一款更圆的无衬线。落地：四款全部 OFL 1.1，思源宋体按 GB2312 一级字库子集，`font-display: swap`；授权复核：霞鹜漫黑的 OFL 1.1 原文须在落地前逐页复核发布页。

**5. 布局与网格**
基线 8px，不使用正交栏，改用「12° 斜向基线系统」：所有词块的左端对齐在同一条相对水平线 12° 的斜线上，块宽在 12 栏投影上取 4 / 6 / 7 / 9 栏四个值，块高按内容行数 2 至 6 行。不对称方式：每个词块的左端沿斜线向下递增偏移 24px，且块内的文字左对齐、右端允许长短不齐（悬挂标点出血 0.5em）。留白节奏：块与块之间的斜向间隙固定 3 个基线单位，块内的行距压到 0.95 倍行高，让词块看起来像被铅字压紧的铅块。滚动行为：滚动量映射到斜向轨道位移，位移量与滚动量成平方关系（每滚 100px，位移从 20px 增到 90px），所以越往下越快；右侧常驻一条 12° 的斜向进度尺显示当前块号，键盘 PageDown 逐块跳转。

**断点具体行为**
≥1440px 保持 12° 斜角与四个块宽档位；1024–1439px 斜角降到 8°，块宽档位减到 5 / 7 / 9 栏三档，进度尺移到视口右缘内 16px；<1024px 斜角降到 4° 但必须保留，词块改为「交错双列」：两列宽度取 54% 与 42%，左右两列共用同一条斜向基线并错开 28px，滚动位移仍随滚动深度递增（每滚 100px 的位移由 12px 升到 44px，分段加速而不是匀速），速度线只保留 1 条，块号固定在各块左上角，触屏点击热区不小于 44×44px；<768px 交错双列收为「窄列加留白栏」，左列 62%、右侧留白 38%，斜向基线与分段加速（每滚 100px 位移由 12px 升到 44px）全部不变。

**6. 关键视觉元素（≥3 个）**
一是斜排词块，左端严格对齐同一条 12° 斜线，块内字距 0.02em、行高 0.95 倍，词块背景为纸色、不加深；二是铅字重压，每块标题字下方压出 0.3mm 深的凹痕，凹痕背光侧 1px `#8E2A18`，字缘油墨堆积边宽度 3px 且不透明度 22%；三是速度线拖影，只在滚动中出现，每个词块最多三条 1px 竖线，长度 24 / 40 / 56px 三级，滚动停止后 260ms 内消失；四是图标逻辑，自绘未来派符号，取自 1910 年代意大利海报的几何语汇（放射短斜线、三角箭头、编号外圈），20 单位网格、2px 方头线宽，绝不用任何 Emoji；五是图像处理，所有照片先做 1-bit 高对比阈值化，再沿 12° 斜线撕边，边缘保留 2px 的纸纤维毛刺。

**7. 动效与交互**
滚动：斜向轨道位移按平方关系加速，缓动性格为纯加速（`cubic-bezier(0.5,0,1,1)`），无回弹；悬停：词块的油墨堆积边从 22% 加深到 30%，同时速度线从 0 条长到 3 条，180ms，无位移；加载：九个词块按块号从 01 到 09 沿斜线依次「压上」，每块 110ms，缓动为阶跃式；转场：块与块之间用 140ms 硬切并把斜向进度尺的指针推一格；光标：一个 12° 倾斜的 2px 十字，倾斜角与基线一致；微交互：点击块号会把该块沿斜线回推 12px 再弹回，240ms。降级：`prefers-reduced-motion: reduce` 时取消平方加速与拖影，滚动改为线性位移且位移量减半，速度线不再出现，进度尺保留。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.3 与 R-12「居中大标题加三张等宽卡片加底部 CTA」：本方案没有居中 hero，也没有等宽卡片，九个词块宽度取四个不同值并沿斜线错位；跳脱之处在于版面主轴是斜的，任何正交网格截图都对不上。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部容器直角，页面的立体感来自铅字压痕与油墨堆积边，没有任何投影。第三，反 C-1.6「白 / 灰交替分区」：全站只用 `#F7EBCF` 一种底，分区靠斜向基线与块号。第四，反 `01-research-brief.md` F 节 P10「全局 ease-in-out 加滚动淡入」：本方案唯一的滚动缓动是平方加速曲线，物理来源是铅字从斜坡滑下的加速，且不使用淡入。

**9. 反 AI 味风险与规避**
最易滑向「斜切贴纸式的活力模板」：一旦给每个词块加旋转、阴影、彩色描边，就退化成常见的活力营销页。规避动作三条：一是所有词块共用一个 12° 斜角，禁止每个块各转一个角度；二是禁止描边与投影，立体感只能由 0.3mm 压痕与 22% 油墨堆积分担；三是速度线只在滚动中出现且总数不超过三条，禁止把它做成常驻装饰。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是创意机构、字体厂商、设计工具的品牌页与作品集，用户对排版实验有耐心；二是演出、展览、文化节的宣传页，斜排词汇适合承载短句与场次。不适合：需要线性阅读的长文内容站与帮助中心，斜向基线会破坏连续阅读；也不适合金融与政务类站点，斜排与高对比朱红会削弱可信感。

**可直接上线的文案**：主张句「九个词块共用一条 12° 斜线，滚得越深跑得越快」；按钮「下一块：第 04 号宣言」；空状态「这条轨道暂时没有新词块。上一次投递是 1912 年 2 月」；错误状态「斜向轨道位移溢出（错误码 SLANT-16）：本次滚动已钳制在第 09 块的 56px 位移上限，进度尺停在 09，松手后恢复正常」。

**11. 可落地要点**
CSS 思路：斜向基线用 `transform: rotate(12deg)` 包一层容器并把内部文字转回 −12°，避免逐块单独旋转造成字形锯齿；滚动位移用 `scroll-driven` 思路换算成自定义属性，位移与滚动量的平方关系在 JS 里算一次写入变量，CSS 只读变量；压痕用单向内阴影加同色暗侧，不使用任何 CSS 色彩插值写法；速度线用三个绝对定位的 1px 元素控制长度档位。栅格单位：8px 基线、12 栏投影、斜向间隙 24px。字体加载：得意黑体积小可直接加载，Archivo Black 只取一个字重，思源宋体按 GB2312 一级字库子集，`font-display: swap`。图片处理：源图 1-bit 阈值化后导出 AVIF，撕边用同一套 12° 遮罩。性能预算：首屏 JS ≤ 50KB（gzip），字体 ≤ 520KB，滚动物理只用 `transform` 且做被动监听，LCP ≤ 2.1s。本方案最难被复用到别的品牌的地方，是那一条 12° 斜线与四个块宽的配比：任何长文案品牌套上去，斜线都会把段落切断。

**12. 设计师签名式怪癖**
每个词块的基线下方，第 3 个字的正下方压着一枚 2×2px 的墨点，且墨点随块号从 01 到 09 每块向右偏移 1px，到第 9 块累计偏移 8px。它不参与阅读，也不表示任何层级，存在的理由是把铅字排版时「填空铅的工人手会抖」这件事留在纸面上。

### 方案 17｜税票存根联（Revenue Stamp Stub）

**结构类型**：F（RECEIPT） ｜ **认知门槛**：中 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一张 1900 年代奥斯曼印花税票式的对账联：右侧是右对齐小数点的等宽明细行，左侧三成宽是带 1.2px 齿孔的存根联，一枚暗红骑缝章横跨两联并固定偏移 2mm，撕开就知道账目归属。

**2. 美学家族与参考**
奥斯曼印花税票（1900 年代）。参考三个真实对象：奥斯曼帝国时期的印花税票与骑缝章制度、凹版印刷（intaglio）在纸面上压出的 0.2mm 墨线凹槽、以及同时期欧洲票据的「主联加存根联」二联式单据。偷的机制是「存根联不是为了留档而存在，它是被撕下来才生效的」，以及「凹版印的线是压进纸里的，摸得到」。我们拿的是撕口与压线，不是拿异域花纹与货币符号。

**3. 配色系统**
背景色 `#E1D6BD` 税票纸（未涂布证券纸，色相 41.7°、饱和 16%、明度 81.2%，情绪：矜持）52%；主色 `#5A2A50` 凹版紫墨（色相 312.5°、明度 25.9%，脏色，情绪：沉静）30%；强调色 `#7A2E2E` 印花红（色相 0°、明度 32.9%，脏色，情绪：印信）10%；次级纸色 `#C9BFA6`（存根联专用压纸色，本方案唯一的背景色是 `#E1D6BD`，此色不作背景，情绪：留档）8%，面积和 100。这套配色反的是 `#6366F1` 靛蓝主色、`#3B82F6` 那一类默认蓝与纯白底：证券纸的纸色比纯白低 9 级亮度，主墨改成含铁紫墨（色相 312.5°），距 `#3B82F6` 的 217° 有 95°、距 `#8B5CF6` 的 258° 有 54°，印花红只用在印章与合计两处，不做按钮底色。对比度实测（脚本计算）：主色 `#5A2A50` 对背景 `#E1D6BD` 为 7.73:1，强调色 `#7A2E2E` 对背景 6.45:1，两者都在 AA 正文线以上；主色块上的文字用纸色 `#E1D6BD`（7.73:1），`#111111` 压在紫墨上只有 1.69:1，不采用。

**4. 字体策略**
中文主字体用文津宋体（免费商用，发布页须复核，老宋窄排刻版，字距压到 0.02em）；拉丁标题用 `Literata`（OFL 1.1，电子书原生衬线，字腔开阔、小字号稳定）；数字与金额用 `Sometype Mono`（OFL 1.1，等宽，字面比同类等宽更窄更硬，小数点可对齐）。分工：单据抬头与条款标题 = Literata 加文津宋体窄排；明细行文字 = 文津宋体 14px / 行高 1.6（票据行距比正文紧）；金额、税率、编号 = Sometype Mono 并启用表格数字特性以保证小数点垂直对齐。为什么不像 AI 选的：AI 默认字体栈里没有窄排刻版宋，也没有一款等宽体被指定承担「小数点对齐」这种具体任务；这里展示与正文都属于有刻版来源的衬线体系，靠窄排与行距把票据的紧凑感做出来，而不是靠一款几何无衬线。

**5. 布局与网格**
12 栏，基线 8px，明细行的行高固定 24px（3 个基线单位），金额列宽固定 96px 且右对齐。不对称方式：主联占 4–12 栏，存根联占 1–3 栏，两联之间是齿孔线而不是边框；骑缝章横跨两联，盖章中心固定偏离齿孔线 2mm，且只盖在合计行所在的水平位置。留白节奏：明细行之间不留额外间隙（靠 1px 浅色行线分隔），小计与合计之间空 2 个基线单位并加一条 2px 的凹版压线。滚动行为：明细行随滚动增量加载，每批 20 行，新行从下方 12px 处落位；齿孔线与合计行固定在视口底部上方 64px，始终可见。

**断点具体行为**
≥1440px 主联与存根联左右并排（存根 25%，主联 75%），金额列固定 96px；1024–1439px 存根联折到主联下方并保留齿孔线，金额列压到 80px；<1024px 转为单联竖排，齿孔线改为顶部的横向撕口，明细行改为两行一组（上行项目、下行金额），金额不再右对齐而改为行末紧跟，合计固定在页脚。所有触屏断点下，撕存根的点击热区不小于 44px 高。

**6. 关键视觉元素（≥3 个）**
一是齿孔撕边，孔径 1.2px、孔距 6px，只出现在存根联一侧，孔的边缘有 0.5px 的纸纤维毛口，撕开后毛口加宽到 1px；二是骑缝章，暗红实印，跨越两联且固定偏移 2mm，章面有明显的双色套印错位（错位 0.8px），边缘保留印泥外溢的 4% 不透明度晕边；三是凹版印花税票，票面细线固定 0.4px 与 0.8px 两级线宽，花瓣与数字处用平行影线表现深浅，线是压进纸里的因而在 45° 侧光下可见凹槽；四是图标逻辑，自绘税票几何符号，24 单位网格、0.8px 方头单线，税票用「齿孔外框加中心星」、骑缝用「跨栏方框加斜线」、已销账用「双横杠缺口圈」，绝不用任何 Emoji；五是图像处理，所有扫描图先灰度化再压到主墨与纸色两个色阶，保留印泥的边缘晕散，禁止套用纸张纹理贴图。

**7. 动效与交互**
滚动：明细行每批 20 行从下方 12px 落位，单批 200ms，缓动性格为阻尼无过冲；悬停：明细行底色转为 `#DFD6BF` 并显示该行税票编号，120ms，无位移；加载：先出纸色与齿孔线，再逐行压出明细，合计最后落位，总时长 900ms，缓动为阶跃式；转场：账期切换用 180ms 硬切并伴随骑缝章盖章一次（缩放从 1.08 到 1.0）；光标：14px 十字加 1px 方框，进入金额列时方框变为票据外框形；微交互：点击「撕下存根」时存根联沿齿孔线向右位移 6px 并露出纸纤维毛口，之后回位，320ms。降级：`prefers-reduced-motion: reduce` 时取消逐行落位与盖章，行直接出现，撕存根改为 100ms 不透明度变化，齿孔线与合计仍保持固定可见。

**8. 去 AI 味审查点（≥3 条）**
第一，反 C-1.6「白 / 灰交替分区」：全站只用 `#E1D6BD` 一种底，分区靠齿孔线、压线与行线完成；跳脱之处在于分区物是可以被撕开的物理结构。第二，反 C-2.11「24px 圆角加柔和投影的卡片浮起」：全部容器直角，页面唯一的高度差来自凹版压进的 0.2mm 墨线凹槽与骑缝章的印泥厚度，没有投影。第三，反 C-2.14「3 / 6 / 9 等量图标网格」：明细行数量随账期变化（示例为 27 行），金额不等量、行高统一但内容长短不一。第四，反 R-28 与 C-4：本方案不写「严谨」「专业」这类形容，票据的可信度由 0.4px 与 0.8px 两级线宽、2mm 盖章偏移与小数点对齐三个数承担。

**9. 反 AI 味风险与规避**
最易滑向「复古票据风贴图」：一旦把整页调成褐黄并叠一张做旧纸张贴图，就与大量复古模板撞车。规避动作三条：一是纸色只允许 `#E1D6BD` 一个值，整体偏中性而非褐黄，主墨占 30% 且已换成含铁紫墨（色相 312.5°），与褐黄不落在同一个色相里；二是记忆点必须落在齿孔 1.2px 孔径、6px 孔距与 2mm 盖章偏移这三个可测值上；三是禁止纸张纹理贴图与暗角，任何做旧只能来自线宽与压线。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是财务对账、税务与票据类 B 端系统，用户需要逐行核对并留档；二是档案馆与出版机构的票据专题数据库、钱币与印花收藏展示页。不适合：需要情绪化叙事的品牌首页，本方案的视觉主角是行与线而不是画面；也不适合面向大众泛用户的移动端消费产品，密集明细行在小屏上阅读成本偏高。

**可直接上线的文案**：主张句「本期应缴 12,480.00 元，其中 3 笔跨月未销账」；按钮「撕下存根联，导出 CSV」；空状态「这个账期还没有税票登记。导入 3 月的对账文件即可开始」；错误状态「存根联与主联编号不一致（错误码 STUB-17，两联相差 1 号）：合计行已锁定，导出前须先完成骑缝章校验」。

**11. 可落地要点**
CSS 思路：齿孔用 SVG `<pattern>` 画圆孔并配合纸纤维毛口位图，不使用任何 CSS 色彩插值写法；小数点对齐用等宽字体加 `font-variant-numeric: tabular-nums` 并把金额列设为 `text-align: end`；骑缝章用一张带透明通道的 PNG 覆盖两联，偏移量由 CSS 变量控制以复用同一张章面。栅格单位：12 栏、8px 基线、24px 行高、96px 金额列。字体加载：文津宋体按 GB2312 一级字库子集，Literata 只取 Regular 与 Italic，`font-display: swap`。图片处理：税票纹样做成单色 SVG，扫描件灰度加双色阶后输出 AVIF，印泥晕边用 4% 不透明度的独立图层。性能预算：首屏 JS ≤ 48KB（gzip），字体 ≤ 420KB，明细行虚拟滚动只渲染视口内 40 行，LCP ≤ 2.0s。本方案最难被复用到别的品牌的地方，是两联的宽度比与 2mm 盖章偏移：没有存根联需求的品牌套上去，齿孔线就成了多余装饰。

**12. 设计师签名式怪癖**
存根联顶部的单据编号旁，永远多出一枚倒置的 1.2px 齿孔，位置在第 3 孔与第 4 孔之间。它来自连张印刷被裁切机多打一孔的实况，不影响撕口对齐，存在的理由是把「这张票是从一整版上裁下来的」这件事留在单张上。

### 方案 18｜磷光检修台（Phosphor Service Deck）

**结构类型**：R（TERMINAL） ｜ **认知门槛**：高 ｜ **调性**：机能冷峻 / 工业

**1. 一句话视觉定义**
一台挂在机房墙上的检修终端：整页是一条从顶部连续下走的曳引打印纸，两侧各有一排 8px 宽的喂纸边孔，纸面上只有一列磷光绿的命令流，行尾锚着一个 8×14px 的实心光标，每条回执右侧挂着一枚写着三位回执号的纸牌。

**2. 美学家族与参考**
Terminal UI（1980 年代硅谷 BBS 与机房终端）。参考三个真实对象：1980 年代机房用的曳引式连续打印纸（tractor-feed paper，两侧边孔与折页线）、同时期终端上的磷光绿单色字符显示、以及设备检修制度里的纸质挂牌（hang-tag，检修时挂在阀门与开关上的编号纸牌）。偷的机制是「连续纸是一条不分页的长纸，所以阅读顺序由纸的走向决定」，以及「挂牌是设备被停机检修的唯一凭证，它挂在哪里比它写在什么更重要」。我们拿的是连续纸与挂牌，不是拿扫描线与星号边框。

**3. 配色系统**
背景色 `#0A0D0A` 机房暗底（L 2.5%，脏色，情绪：幽冷）70%；主色 `#2FA84F` 磷光绿（色相 135.9°，情绪：读数）18%；纸白 `#C8C4AE` 连续纸色（饱和 19.1%，脏色，情绪：耗材）9%；挂牌纸色 `#6E6350` 牛皮纸牌（饱和 11%，脏色）3%，面积和 100。这套配色反的是「深色底加霓虹紫青加发光边框」的仪表盘套路，也反 `#6366F1` 靛蓝与纯黑底：主色是带黄的磷光绿，避开霓虹青；暗底取偏绿 2 级的机房暗色，不用纯黑，纸白是耗材本色而不是 `#F5F5F5` 灰。按钮与色块约束：主色 `#2FA84F` 作填充时白字只有 3.07:1，不达标，一律改用深色文字 `#111111`（实测 6.15:1）。

**4. 字体策略**
命令流与回执号用 `VT323`（OFL 1.1，DEC VT320 终端像素字，落地前须复核发布页授权文本）；中文用未来荧黑 Glow Sans（OFL 1.1，硬骨架几何黑体，笔画端头平直，与点阵英文字面高度接近）；挂牌编号与状态码用 `Martian Mono` 极窄档（OFL 1.1，可调宽度等宽）。分工：命令与回执行 = VT323 加未来荧黑；维护说明段落 = 未来荧黑 15px / 行高 1.8；挂牌编号、出口码、时间戳 = Martian Mono 极窄档。为什么不像 AI 选的：AI 默认三件套清一色平滑无衬线，从不会选一款带点阵锯齿的终端字；这里把点阵英文与硬骨架中文并置，中文字面比英文高 1.5%，混排时保留了两套铅字不同的对齐习惯，读起来像打印纸而不是网页。

**5. 布局与网格**
基线 8px，行高 24px（3 个基线单位），单列，不用多栏。不对称方式：命令流左端起于版心左侧 12% 处，右侧留 34% 空幅专门悬挂回执牌，整列因此明显偏左。留白节奏：命令与回执之间不空行（连续纸不分段），每 20 行压一条折页线并空 1 行，形成 20 行一段的呼吸。滚动行为：滚动量与纸张位移 1:1，纸从视口底部连续走纸，两侧边孔保持对齐；提示符行固定在当前视口下沿内 48px，用户始终看到光标所在行。断点：≥1440px 保留边孔与 34% 悬挂区；1024–1439px 悬挂区收到 22%，命令流起点回到左侧 6%；<1024px 边孔、挂牌、光标锚定三件全部保留，边孔收窄到 5px 而孔距保持 12px，悬挂区换成「行内挂牌条」，即回执牌缩到 24×12px 的牛皮下标并挂在对应行尾下方 4px，命令流起点回到左侧 4%，折页线保持每 20 行一条，行尾光标仍为 8×14px 方块按 530ms 方波闪动，触屏点击热区不小于 44×44px；<768px 边孔孔径减到 4px 而孔距仍为 12px，挂牌条移到行尾右侧并改为竖排，530ms 方波光标与折页线不变。

**6. 关键视觉元素（≥3 个）**
一是连续打印纸，两侧各 8px 宽的喂纸边孔，孔距 12px、孔径 3px，孔内有 0.5px 单向下阴影以表现纸被齿轮拽过的痕迹；纸面每 20 行有一道 1px 折页压痕，压痕两侧墨色淡 6%；二是光标锚定，8×14px 实心块、530ms 方波闪动，位置永远在当前命令流末尾，滚动时随纸走而不脱离文字；三是回执挂牌，24×12px 的牛皮纸牌，左上角有 0.5px 打孔与一根 1px 挂绳，牌面印三位回执号，牌与回执行之间用一根 6px 的短线连接；四是图标逻辑，自绘终端符号，16 单位网格、1.25px 方头线宽，提交用「方框加下划线」、喂纸用「两级阶梯箭头」、挂牌用「矩形加穿孔」，绝不用任何 Emoji，符号只有磷光绿一色；五是图像处理，所有照片先转灰度再走 1-bit 点阵抖动，只保留磷光绿与纸白两个色阶，颗粒按行方向拉长 1.5 倍以贴合扫描线方向。

**7. 动效与交互**
滚动：纸张位移与滚动 1:1，缓动性格为阶跃式（`steps(6)`），模拟曳引齿轮一格一格拽纸；悬停：回执牌绕挂绳摆动 6° 并回位，240ms，阻尼无过冲；加载：先出两侧边孔，再从首行向下逐行落纸，每行 40ms，缓动为阶跃；转场：切换检修单时纸张向上抽出 200ms 并换上新纸；光标：8×14px 实心块常闪，周期 530ms；微交互：提交命令时该行左侧出现一条 1px 竖线并整行右推 3px，保持 300ms 后回位。降级：`prefers-reduced-motion: reduce` 时取消走纸与落纸动画、光标改为常亮不闪、挂牌不再摆动，折页线与边孔保留。

**8. 去 AI 味审查点（≥3 条）**

### 方案 19｜铜版标本柜（Copperplate Herbarium Cabinet）

**结构类型**：F（CARD-CATALOG） ｜ **认知门槛**：高 ｜ **调性**：学术档案 / 严肃出版

**1. 一句话视觉定义**
一只 1880 年代邱园的标本柜：柜面是 20 个宽度不等的抽屉，抽屉标签上的检索号由柜号、抽屉号、卡号三段组成，抽开抽屉露出铜版蚀刻的植物标本卡，细线只有 0.4px 与 0.8px 两级，褪色的墨绿压在米色卡纸上。

**2. 美学家族与参考**
植物学标本馆（1880 年代英国邱园）。参考三个真实对象：邱园标本馆的索引卡与抽屉标签体系、铜版蚀刻（copperplate engraving）用平行影线表现体积的制版方法、以及 19 世纪植物志里标本签上的手写采集地与时日。偷的机制是「抽屉标签、索引卡、检索号三者构成一条可检索的路径，缺一段就翻不到东西」，以及「蚀刻的深浅由线的疏密决定，不由颜色决定」。我们拿的是三级检索与平行影线，不是拿植物插画与藤蔓花纹。

**3. 配色系统**
背景色 `#E4DECD` 标本卡纸（棉麻浆手工纸，色相 44.3°、饱和 10.1%、明度 84.9%，情绪：陈雅）44%；主色 `#4A5C3A` 蚀刻墨绿（色相 91.8°，明度 29.4%，脏色，情绪：静肃）27%；抽屉与柜架 `#2A241C` 深木褐（明度 13%，脏色，情绪：旧木）24%；标签褪色墨 `#7C7460`（索引标签的褪色字迹，饱和 13%，脏色）5%，面积和 100。这套配色反的是 `#6366F1` 靛蓝与纯白底，也反「深绿加金色」的常见复古配方：绿色是带灰的墨绿而不是饱和绿，柜架色只有 24% 且不参与正文，页面没有金色，唯一的暖色来自卡纸本身。

**4. 字体策略**
中文主字体用京华老宋体（免费商用，发布页须复核：须保留原始授权声明、不得二次转售字体文件，老宋宽排刻版，横竖对比明确）；拉丁标题用 `Spectral`（OFL 1.1，低对比屏幕衬线，与 0.4px 蚀刻细线并置时不抢戏）；检索号与采集数据用 `IBM Plex Mono`（OFL 1.1，等宽，用于三段检索号与经纬度）。分工：柜门标题与卡面标题 = Spectral 加京华老宋体宽排（字距 0.05em，行长 40 个汉字）；采集说明与批注 = 京华老宋体 15px / 行高 1.9；检索号、采集年月、经纬度 = IBM Plex Mono。为什么不像 AI 选的：AI 默认字体栈不会选一款刻版老宋，也不会把行高放到 1.9 来承担宽排节奏；这里的中文是字面宽、行距松的刻版宋，拉丁是同为低对比的屏幕衬线，两者对比靠线宽而不是靠字族风格。

**5. 布局与网格**
12 栏，基线 8px，抽屉面板高 24px（3 个基线单位）。不对称方式：20 个抽屉分 5 行，每行 4 个，宽度分别取 4 / 3 / 3 / 2 栏，行与行之间不重复同一顺序，因此没有两个抽屉等宽；检索号悬挂在抽屉标签右侧 12px 处，比标签基线低 2px。留白节奏：抽屉内边距 8px，抽开后卡面留 16px 内边距，卡与卡之间空 1 个基线单位，行与行之间空 2 个基线单位。滚动行为：滚动经过某一抽屉行时，该行抽屉抽出 24px 并露出卡面首行，离开视口后自动推回；整柜不吸顶，滚动到第 3 行时柜体上沿才进入视口。断点：≥1440px 保留 20 个抽屉与不等宽分配；1024–1439px 合并为 12 个抽屉（每行 3 个），宽度取 4 / 4 / 4 栏但靠抽拉深度 24 / 32px 制造差异；<1024px 单列，抽屉改为可点击展开的索引卡列表，检索号提到行首用等宽字显示，键盘 Tab 顺序按检索号升序排列。

### 方案 20｜针笔声场图（Plotter Soundfield）

**结构类型**：R（GENERATIVE） ｜ **认知门槛**：高 ｜ **调性**：冷静克制 / 工程感

**1. 一句话视觉定义**
一张 1:1 的白色图纸贴在墙上，一支 0.35px 的针笔用单线把声音走成一层层不交叉的等高线，右侧挂着参数面板，滚动页面等于拧参数旋钮，图形随每一次滚动重绘。

**2. 美学家族与参考**
参数化生成印刷（2020 年代荷兰数据驱动设计）。参考三个真实对象：荷兰数据驱动设计工作室的绘图仪（pen plotter）作品、工程图纸上的声压级等高线与等值线标注法、以及早期示波器记录纸上的单线走位。偷的机制是「针笔是一次成线的，它不能回头也不能填色，所以图形的密度只能靠走线间距表达」，以及「参数变一次，图就整体重排一次，图与参数是同一个对象的两面」。我们拿的是单线走位与滚动即调参，不是拿波形的装饰曲线。

**3. 配色系统**

**7. 动效与交互**

**9. 反 AI 味风险与规避**
最易滑向「深色数据可视化大屏」：一旦把画布换成深底、加上发光描边与图例卡片，就退回成常见的数据看板。规避动作三条：一是底必须是图纸白且只允许一个值，禁止深色模式切换；二是图形只允许 0.35px 单线，禁止发光、禁止填充、禁止色彩插值；三是图例必须由真实走线段构成，不允许做成带圆角的图例卡片。

**10. 适用场景（≥2 类，并附「不适合」）**
适合两类项目：一是音频、声学、传感器与测量仪器类产品的官网与产品页，图与参数是同一个对象，能直接呈现设备在做什么；二是数据可视化工具与生成艺术工作室的作品集，参数驱动的重绘本身就是展品。不适合：需要情绪化叙事的品牌首页，本方案没有图像与色彩冲击；也不适合移动端为主要入口的消费产品，参数调参与密集细线在小屏上都难以成立。

**11. 可落地要点**
CSS 思路：走线全部用 SVG 路径，`stroke-width: 0.35`、`shape-rendering: geometricPrecision`、`vector-effect: non-scaling-stroke` 以保证缩放下线宽恒定；参数变化时用 `requestAnimationFrame` 每帧只更新路径的 `d` 属性，避免重建节点；不使用任何 CSS 色彩插值写法。栅格单位：12 栏、8px 基线、8px 坐标格、画布 1:1。字体加载：Space Grotesk 只取 Medium 与 Regular，思源黑体按 GB2312 一级字库子集，Martian Mono 只取窄档，`font-display: swap`。图片处理：本方案不引入位图，所有图形矢量输出，导出分享图时再栅格化到 2 倍图。性能预算：首屏 JS ≤ 75KB（gzip），字体 ≤ 450KB，单次重排路径总长设上限（4000 段以内），移动端降到 30fps 并限制每帧重算的路径数，LCP ≤ 2.2s。本方案最难被复用到别的品牌的地方，是参数与走线间距的三级图例映射：换掉音频来源之后，这套映射仍然只对应声压级的量级关系。

**12. 设计师签名式怪癖**
每张图的左下角有一枚 0.35px 的起笔点，它永远比理论原点向左下偏 0.6px，因为绘图仪的针架存在物理回差，设计师把这个误差保留下来而不是校正掉。它不影响读图，存在的理由是把「这条线是机械臂拖着笔走出来的」这件事留在图上。
