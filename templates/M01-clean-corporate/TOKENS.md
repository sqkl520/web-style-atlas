# TOKENS.md — 12 个 CSS 变量逐个说明

全部变量都在 `style.css` 的**最顶部**，一个 `:root{ }` 块里，共 12 个。
这一层故意把变量数量控制在 12 个以内：数量越少，不懂 CSS 的人越改得动。

```css
:root{
  /* 颜色 8 个 */
  --brand:      #1B3A5C;
  --brand-ink:  #12283F;
  --brand-soft: #EAF1F8;
  --ink:        #141B23;
  --ink-2:      #4C5966;
  --line:       #E0E6EC;
  --bg:         #FFFFFF;
  --bg-2:       #F4F7FA;
  /* 形状与尺度 3 个 */
  --radius:     10px;
  --maxw:       1140px;
  --space:      24px;
  /* 字体 1 个 */
  --font: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial,
          "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
}
```

改完怎么自检：改色后刷新页面，重点看四处 —— 顶部那个深色按钮上的白字、深色数据区里的白字和灰字、
页脚里的浅灰链接、以及正文段落。这四处是全页对比度最容易失手的地方。

---

## 一 颜色（8 个）

### 1. `--brand` 主色
* **作用**：全站唯一的品牌色。按钮底色、可点文字的链接色、三个服务图标、流程区的 2px 横规线、
  数字序号圆的文字色、问答区 `+` 号、数据区（成果）整段底色。logo 方形标志的底色也跟着它（用的是 `currentColor`）。
* **默认**：`#1B3A5C`（深石板靛蓝）。白字放在它上面是 **11.63:1**，它自己作为文字放在白底上也是 **11.63:1**。
* **改成什么会怎样**：
  * 换成**更深**的色（如 `#0F2438`）：更稳、更像金融与法律行业，页面整体对比度上升。
  * 换成**更浅**的色（如 `#4A7BB0`）：页面会立刻变"轻"，但按钮上的白字会掉到 3:1 以下开始看不清 ——
    这时你必须同时把 `style.css` 里 `.btn-primary{color:#fff}` 改成深色字。
  * **傻瓜判据**：HEX 每两位当成一个 0–255 的数（如 `#1B3A5C` = 27 / 58 / 92），三个数平均 ≤ 110 时白字安全；
    平均超过 130 必然不合格。
  * 换成**高饱和**的色（红、橙、亮蓝）：这套版式会从"专业服务"滑向"消费品促销"，慎用。
  * 换成灰（如 `#3A4149`）：变成黑白站，适合设计工作室和摄影，很好用。

### 2. `--brand-ink` 主色深一档
* **作用**：只用在两个地方 —— 按钮**悬停**时的底色、以及**页脚**整块底色。
* **默认**：`#12283F`。白字在它上面 **14.99:1**。
* **改成什么会怎样**：
  * 偷懒算法：把主色三个通道各乘 0.7（`#1B3A5C` → 19/41/64 ≈ `#132940`）。
  * 改成和 `--brand` **一模一样**：按钮悬停就没有反馈了（点上去颜色不动），页脚和成果区也会变成同一个底色，
    两段深色连在一起会显得是一段。**不要这么做。**
  * 改得比主色还浅：页面结构会读反（页脚看起来比正文更"亮"），不要这么做。

### 3. `--brand-soft` 主色浅档
* **作用**：三个服务图标的方形底、流程区数字圆底、结尾行动区（CTA）整块底色，
  以及描边款按钮（次按钮、电话按钮）悬停时的底色。
* **默认**：`#EAF1F8`。深灰正文 `#4C5966` 在它上面是 **6.30:1**（达标）。
* **改成什么会怎样**：
  * 偷懒算法：把主色调到约 92% 白。
  * 改成纯白 `#FFFFFF`：CTA 区会和上面的白底连成一片，看不出这里是一段独立区块（要靠 1px 边框撑着，变弱）。
  * 改成偏深（如 `#C9D8E8`）：图标和数字圆会变得很重，服务卡片看起来像被贴了色块。它是**底**不是**面**，保持很浅。

### 4. `--ink` 正文主色
* **作用**：所有标题（h1/h2/h3）、加粗断言、以及"最重要的一层文字"。
* **默认**：`#141B23`（偏中性的近黑，白底上 **17.34:1**）。
* **改成什么会怎样**：
  * 改成纯黑 `#000000`：对比度更高（21:1），但屏幕上会显得硬、有压迫感，且中文笔画密集的地方会糊在一起。
    这也是本模板**故意不用纯黑**的原因。
  * 改成深灰（`#333`、`#444`）：仍然达标（≥10:1），观感会软一些，适合杂志感的品牌。
  * 改成彩色：标题会抢掉主色的角色，不建议。

### 5. `--ink-2` 次级文字
* **作用**：所有段落正文、卡片说明、列表说明、图片说明、信任条文字、页脚的地址与备案行（在深色页脚上另有专用色）。
* **默认**：`#4C5966`。白底 **7.17:1**、交替底色 `#F4F7FA` 上 **6.67:1**、CTA 的 `#EAF1F8` 上 **6.30:1**（三处都达标）。
* **改成什么会怎样**：
  * 改浅到 `#767F8A` 左右：仍勉强达标（约 4.6:1），但已经在悬崖边上。
  * **再浅就违规**：`#8A939E` 约 3.3:1，正文会变成"看得见但费劲"。这是这一层最不能碰的一个变量。
  * 改深到接近 `--ink`：层级会消失，标题和正文长得一样，整页读起来变平。

### 6. `--line` 分隔线 / 描边
* **作用**：卡片描边、导航下边线、问答条目的分隔线、手机上导航菜单里每条菜单下的细线、
  结尾区上下边线、主视觉占位框的外框、汉堡按钮的边框。
  （三个客户 logo 占位框里那条**虚线**画在 SVG 内部，不受这个变量影响；换成真 logo 后就用不到了。）
* **默认**：`#E0E6EC`。
* **改成什么会怎样**：
  * 改得更浅（`#EFF2F5`）：卡片会"浮"不起来，服务区三张卡看着会散掉。
  * 改得更深（`#C6CFD8`）：整体会变得很"表格化"，适合数据密集的行业站（审计、检测机构）。
  * 改成主色：全页会被细线切碎，不要这么做。

### 7. `--bg` 页面底色
* **作用**：页面主底，也是服务卡片、按钮描边款的底色。
* **默认**：`#FFFFFF`。
* **改成什么会怎样**：
  * 改成暖白（`#FDFBF7`）或冷白（`#FAFBFD`）：整页立刻有"纸感/屏幕感"的差别，配合 `--bg-2` 一起改才自然。
  * 改成任何有明显色相的底：卡片就必须改成别的颜色，否则卡片和底分不开 —— 这时要连着改 `--bg-2`、`--line`、`.card` 的 `background`，**不建议新手动**。

### 8. `--bg-2` 交替分区底色
* **作用**：客户/资质条、常见问答区两段整块的底色（"白 / 浅灰交替"就是靠它）。
* **默认**：`#F4F7FA`（比白略深的冷灰蓝）。
* **改成什么会怎样**：
  * 和 `--bg` 只差 2–3% 亮度：交替会看不见，页面变成一整片白（这时只能靠 `--line` 画分隔线补救）。
  * 改成 `#EDF1F5` 或更深：分区感很强，但这两段里的段落文字对比度会下降 —— 改完请回头看一眼
    「常见问题」的回答和「客户条」的说明字是否还清楚（默认值下是 6.67:1，比 `--bg-2` 深一档就掉到 5.8:1 左右，仍达标）。

## 二 形状与尺度（3 个）

### 9. `--radius` 圆角
* **作用**：服务卡片、两个按钮、结尾区的按钮、手机上那个汉堡按钮、三个图标底、跳转链接的小圆角，
  都用它。**注意两处不受它影响**：logo 方形标志的圆角写在 SVG 里（`rx="7"`），键盘焦点描边自带 4px 圆角。
* **默认**：`10px`（本层规格要求 8–12px）。
* **改成什么会怎样**：
  * `0`：变成直角，观感立刻从"现在的软件"变成"严肃的机构/文件"，很适合律所与会计师事务所；
    但按钮会同时失去"可以点"的符号感，建议同时把按钮高度从 48px 提到 52px 补回点击感。
  * `16px` 以上：开始接近"通用 App"的圆润感，和这套严谨的版式开始打架。
  * `9999px`（胶囊）：按钮会变成药丸状，本模板的表格化数据区与它不搭，不要用。

### 10. `--maxw` 版心宽度
* **作用**：全站内容的最大宽度（`.wrap`），所有分区共用同一个版心。页脚、数据区、CTA 都一样宽。
* **默认**：`1140px`。
* **改成什么会怎样**：
  * `960px`：正文行长更短、更好读，适合文字为主的咨询/律所站；三张服务卡会变窄，标题会开始折两行。
  * `1320px` 或更大：数据区和柱状图会显得宽阔有气势，适合有大量数字的行业；
    但正文段落会变长（一行超过 75 个汉字就难读了）—— 这时建议只加宽数据区，做法见第三节。
  * 手机和平板上这个值不起作用（屏幕本来就比它窄），改它只会影响宽屏。

### 11. `--space` 基础间距单位
* **作用**：这一条是"全站节奏的总开关"，被用在四个地方 ——
  * 页面左右留白（`.wrap` 的 `padding-inline`）＝ `--space`；
  * 每个分区上下内距 ＝ `--space × 2.5`（手机上）/ `× 3.5`（768px 以上）；
  * 卡片内距 ＝ `--space × 1.25`；卡片之间、区块标题与内容之间的间距也是它的倍数。
* **默认**：`24px`。
* **改成什么会怎样**：
  * `20px`：更紧凑，一屏能多塞一点内容，适合信息量大的站。
  * `28–32px`：更松弛、更"有呼吸感"，但 390px 手机上左右留白会变成 32px，
    可用宽度只剩 326px，长一点的按钮文字会折行更多。改到 32px 以上请在手机上重新看一遍。
  * **不要**把它当成单一间距去改（它同时管留白、内距、间隔）。要单独调某处间距，请直接改那条规则，
    不要动这个变量。

## 三 字体（1 个）

### 12. `--font`
* **作用**：全站唯一的字体声明 —— 标题、正文、按钮、导航、页脚、连 SVG 占位框里的字和图表坐标轴的字都用它。
* **默认**：
  ```
  system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial,
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif
  ```
  这是**系统字体栈**：不下载任何字体文件，每个系统用它自己最好看的那套 ——
  Windows 得到 Segoe UI + 微软雅黑，macOS 得到 SF Pro + 苹方，Android 得到 Roboto + Noto Sans SC。
  效果是"在你的电脑上永远正常"，代价是"不同系统上不完全一样"。
* **改成什么会怎样**：
  * 想用设计字体（如思源黑体、霞鹜文楷）：**中文会从 8MB 起**，塞不进"两个文件"的模板。
    真要用，请自建 `fonts/` 目录并用 `@font-face` 引入，同时准备好回退栈 —— 这时断网就会掉回系统字体，
    所以建议把系统栈留在 `--font` 的最后几位。
  * 只把**第一个**名额换成某个拉丁字体（如 `"Helvetica Neue"`、`Georgia`）：标点、数字、英文会立刻换脸，
    中文仍然走系统字体 —— 这是最安全、最省事的"换气质"手法。
  * 删掉中文那几项（`PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`）：某些环境下浏览器会自己找字体替换，
    可能拿到一款衬线中文，中英混排会崩。**不要删。**
  * 加字重档位：本模板只用到 `font-weight` 的 400 / 600 / 700 三档，都是系统字体真实存在的档位。
    写 500 时浏览器会在 400 与 600 之间就近取整，不同系统上取到的结果不一样，所以别用 500。

## 四 不在 12 个变量里，但你可能想动的东西

这些值刻意没有做成变量（变量越少越好改），需要时直接在 `style.css` 里找到那一条改：

| 想改什么 | 在哪 | 现在是什么 |
| --- | --- | --- |
| 卡片投影（"浮起来"的那一层） | `.card` 的 `box-shadow` | `0 1px 2px rgba(20,27,35,.04), 0 16px 30px -24px rgba(20,27,35,.3)` |
| 键盘焦点描边颜色 | 搜索 `:focus-visible` | `#3C8CE0`（白底 3.49:1、深底 4.30:1，都过非文本 3:1） |
| 深色页脚上的文字色 | `.site-footer` / `.footer-about` / `.footer-col a` | `#E7EDF4` / `#AFC1D3` / `#CBD9E7` |
| 数据区里半透明白字的比例 | `.band .section-lead`（84%）、`.stat-note`（76%）、`.chart-y text`（80%） | 改小会让深色区里的说明字变暗，低于 70% 就不达标了 |
| 主视觉占位框里的灰阶 | `index.html` 里 `#EEF2F6` / `#C2CCD7` / `#2A3644` 等 | 换成真照片后这些全部消失，不用管 |
| 数据区里的横/竖分隔细线 | `.stats` / `.stat` 的 `border-*` | `rgba(255,255,255,.32)`（竖线只在 1000px 以上的四列排布出现） |
| 柱状图的柱子颜色 | `index.html` 里 `fill="rgba(255,255,255,.92)"` | 深色区里的白柱子 |
| 导航折叠的临界宽度 | 搜索 `@media (min-width:880px)` | 880px 以下变成汉堡菜单 |
| 顶栏高度 | `.header-inner` 的 `min-height` | 64px（手机）/ 74px（880px 以上） |
| 手机上那张图表的最小宽度 | 搜索 `.chart-scroll svg` 的 `min-width` | `620px`（小于它就在图表内部左右滑） |

**改完这 12 个（或上面这些）之后，最少要检查的四件事**：

1. 深色按钮上的白字、以及深色数据区里的白字，是否还清楚；
2. 正文段落在白底和浅灰底上是否都还能舒服地读（`--ink-2` 是最敏感的）；
3. 手机 390px 下有没有出现左右方向的整页滚动条（应该有，且只有图表内部那一条是允许的）；
4. 键盘按 Tab，焦点描边有没有被新配色吃掉。
