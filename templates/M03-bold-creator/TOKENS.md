# TOKENS.md · 12 个变量逐个说明

`style.css` 最上面 `:root{ … }` 里的 12 个变量，是**唯一需要改的地方**。
改完保存、浏览器刷新即可。本节按"改它的后果"逐个讲清，末尾附一整套「浅色版」可直接覆盖的值。

## 默认值一览（实测数据，非估算）

| # | 变量 | 默认值 | 管什么 |
| --- | --- | --- | --- |
| 1 | `--bg` | `#0e0e10` | 页面底色 |
| 2 | `--ink` | `#f2f2ef` | 正文与标题色 |
| 3 | `--muted` | `#a3a39c` | 次要文字色 |
| 4 | `--accent` | `#ff5c1a` | 唯一强调色 |
| 5 | `--on-accent` | `#14100d` | 强调色块上的文字色 |
| 6 | `--surface` | `#17171a` | 占位图 / 浅一层底色 |
| 7 | `--rule` | `#33333a` | 1px 细线 |
| 8 | `--focus` | `#ffd166` | 键盘焦点圈 |
| 9 | `--maxw` | `1280px` | 内容最大宽度 |
| 10 | `--space` | `clamp(1rem, 2.5vw, 2rem)` | 统一间距 |
| 11 | `--radius` | `2px` | 圆角 |
| 12 | `--font` | 系统字体栈（见下） | 字体 |

额外说明一处**不是变量**、但你可能想改的东西：等宽字体栈。全站的序号、分区标签、图片标注、页脚都用等宽字体，它只在 `style.css` 里声明了一次：

```css
code, kbd, samp, .mono,
.idx, .sec-num, .sec-label, .eyebrow, .work-tags, .contact-note, .foot-line, .ph-label, .nav-toggle{
  font-family: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
               "Liberation Mono", "Courier New", monospace;
}
```

---

## 1. `--bg` · 页面底色

- **默认**：`#0e0e10`（近黑，不是纯黑——纯黑在大多数屏幕上会让 1px 细线消失、边缘发死）
- **影响**：整个页面背景、页脚、页脚上方留白、以及吸顶导航条的底色（导航用它做不透明底，所以改 `--bg` 时导航自动跟着变，不用另改）
- **怎么选**：想要稍微暖一点的黑，试 `#0f0e0c`；想要冷一点，试 `#0d0e11`。**不要用 `#000000`**：细线和高光会失去层次
- **改完必须看一眼**：`--ink` 和 `--muted` 的对比度会跟着变。底色越亮，正文越可能掉到 4.5:1 以下

## 2. `--ink` · 正文与标题色

- **默认**：`#f2f2ef`（近白，略带一点灰，比 `#ffffff` 柔和）
- **影响**：首屏大字、分区标题、作品标题、表单/按钮悬停态、导航文字、页脚以外的所有正文
- **实测对比度**：`#f2f2ef` 对 `#0e0e10` = **17.2:1**（标准要求 4.5:1，余量很大）
- **想更"硬"**：`#ffffff`（更刺眼，长文阅读更累）；想更柔：`#ddddd8`

## 3. `--muted` · 次要文字色

- **默认**：`#a3a39c`
- **影响**：首屏身份行、作品说明、标签行、关于我正文、联系方式旁的备注、页脚
- **实测对比度**：对 `#0e0e10` = **7.6:1**（仍是"正文级"可读性，不是可有可无的装饰灰）
- **调色规律**：`--muted` 要和 `--bg` 拉开至少 4.5:1；深底上一般取 `--ink` 亮度的一半左右。**别用 `#666` 这类中灰**——它在近黑底上只有 3.x:1，正文看着会"发虚"

## 4. `--accent` · 唯一强调色

- **默认**：`#ff5c1a`（高饱和橙）
- **影响**：所有链接、作品序号（`01 02 03`）、分区序号、邮箱大字、按钮底色、选中文字（`::selection`）的反色
- **实测对比度**：对 `#0e0e10` = **6.25:1**（它经常当文字用，所以必须过 4.5:1）
- **换色建议**（深底上都能过 4.5:1 的高饱和候选）：
  | 色相 | 值 | 对 `#0e0e10` 对比度 |
  | --- | --- | --- |
  | 橙（默认） | `#ff5c1a` | 6.25:1 |
  | 柠檬黄 | `#f2d21d` | 更高（约 13:1） |
  | 青 | `#2fd6c3` | 更高（约 11:1） |
  | 品红 | `#ff5c9e` | 约 5.9:1 |
  | 草绿 | `#8ede3a` | 更高（约 12:1） |
- **只用一次原则**：这层只有一个强调色。别再加第二个——加了就不"大众模板"了
- **联动**：改了它，顺手检查 `--on-accent`（第 5 项）

## 5. `--on-accent` · 强调色块上的文字色

- **默认**：`#14100d`（近黑）
- **影响**：「复制邮箱」按钮上的字、`::selection` 选中文字的颜色、跳转链接获得焦点时的底色配字
- **实测对比度**：`#14100d` 对 `#ff5c1a` = **6.1:1**
- **怎么取值**：如果你的 `--accent` 是**亮**色（黄、青、亮橙）→ 用近黑 `#14100d`；如果 `--accent` 是**暗**色（深蓝、深红）→ 改成近白 `#f7f7f4`。这是唯一一个"必须和强调色一起改"的变量

## 6. `--surface` · 占位图 / 浅一层底色

- **默认**：`#17171a`（比 `--bg` 亮一档）
- **影响**：作品占位图的填充色、占位图上的网格线遮罩、以及你换成 `<img>` 后图片区域在加载前的底色
- **取色规律**：比 `--bg` 亮 8–12% 左右最舒服。深底上太亮会显得像"图挂了"的白块

## 7. `--rule` · 1px 细线

- **默认**：`#33333a`
- **影响**：顶部导航的下边线、每个分区（作品/关于/联系/页脚）的上边线、每条作品的上边线、桌面端左侧那条**贯穿全页的竖线**、占位图边框
- **性质**：纯装饰线，不承载信息，所以它**不需要**满足 4.5:1（实测对底色约 1.5:1，这是编辑类版面常见的"hairline"强度）
- **想要更明显**：`#45454e`；想要几乎看不见：`#26262b`
- **注意**：如果 `--bg` 改成很暗的纯黑，这条线也要跟着调亮一点，否则会整条消失

## 8. `--focus` · 键盘焦点圈

- **默认**：`#ffd166`（暖黄）
- **影响**：用 Tab 键在页面里移动时，当前元素外圈那 2px 的描边（`:focus-visible{outline:2px solid var(--focus); outline-offset:3px}`）
- **实测对比度**：对 `#0e0e10` = **13.4:1**（焦点指示要求 ≥3:1，这里余量很大）
- **为什么不用强调色**：焦点圈和链接/序号用同色时，键盘用户很难分辨"这是链接"还是"这是当前位置"。分开更清楚

## 9. `--maxw` · 内容最大宽度

- **默认**：`1280px`
- **影响**：导航、首屏、所有分区、页脚的内容装多宽；超过这个宽度就自动居中留白（所以屏幕越宽、两边留白越多）
- **怎么调**：`1440px`→更满、更有"大屏海报"感；`1040px`→更像杂志专栏、行长更短更好读；`760px`→基本变成单栏博客
- **注意**：改大以后，首屏大字的 `clamp()` 上限（`8.5rem`）可能就限制住了气势，此时同时把 `.hero-title` 里的 `8.5rem` 调大

## 10. `--space` · 统一间距

- **默认**：`clamp(1rem, 2.5vw, 2rem)` —— 即"最小 16px、随屏幕宽在 16–32px 之间浮动"
- **影响**：作品图文之间的间隔、关于我两栏之间的间隔、联系方式行的间隔
- **怎么调**：想更"紧、信息密度高"，改成 `clamp(0.75rem, 2vw, 1.5rem)`；想更"松、留白狠"，改成 `clamp(1.25rem, 3vw, 2.75rem)`
- **注意**：它是 `clamp()`，只在 16–32px 之间变化；如果你想要固定值，直接写成 `24px` 也完全没问题

## 11. `--radius` · 圆角

- **默认**：`2px`（几乎直角）
- **影响**：占位图/图片的圆角、按钮圆角、移动端「菜单」按钮圆角
- **怎么调**：`0` = 完全直角（更硬朗、更编辑感）；`6px` = 现代 App 感；`24px` = 常见的圆润卡片感（注意：和 1px 细线放在一起时，大圆角会显得两套语言打架）
- **注意**：这层**没有投影**。想加的话，在 `.work-media img` 和 `.ph` 上加 `box-shadow`，但深底 + 大圆角 + 投影三者同时出现容易发灰

## 12. `--font` · 字体

- **默认**（原文，就是 `style.css` 里那一行）：

```css
--font: ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto,
        "Helvetica Neue", Arial, "Noto Sans SC", "Microsoft YaHei",
        "PingFang SC", "Hiragino Sans GB", sans-serif;
```

- **为什么用系统字体栈**：这一层是"拿来就能用"的大众模板，必须**离线可用、零网络请求、零加载失败**。系统栈在每台设备上都立刻渲染；同时它按平台自动选字：Windows 走 Segoe UI / 微软雅黑，macOS 走 SF Pro / 苹方，Android 走 Roboto / 思源黑体，中文都能正确落到黑体上
- **想换字体**：把这一行整个换掉，例如 `--font: "HarmonyOS Sans SC", "Source Han Sans SC", sans-serif;`。但注意——换成本地没有的字体时，用户机器上会回退到 `sans-serif`；要真正保证效果就得引入字体文件（那就破坏"两个文件、离线"的前提了）
- **等宽字体**（序号、标签、图片标注、页脚用的那套）**不在 12 个变量里**，它单独声明一次，位置和原文见本页开头

## 附：一整套「浅色版」推荐值（可直接整段替换）

想让模板变成"纯白底 + 近黑字 + 一个强调色"，把 `:root` 里的颜色行换成下面这组即可，其余不用动：

```css
--bg:        #fbfbf9;   /* 近白，不用纯白，避免刺眼 */
--ink:       #121215;   /* 近黑 */
--muted:     #55555c;   /* 次要文字，对 #fbfbf9 约 7.4:1 */
--accent:    #c23a00;   /* 强调色要压暗：亮橙在白底上只有 2.x:1，不能当文字用 */
--on-accent: #f7f7f4;   /* 深橙底 → 用近白字，约 6.0:1 */
--surface:   #f1f1ee;   /* 占位图底色比底再深一档（浅色主题里反过来） */
--rule:      #d6d6d1;   /* 浅底上的细线要够浅 */
--focus:     #0b63d6;   /* 焦点圈换成蓝，在白底上约 5.9:1 */
```

浅色主题要额外检查两处（深色主题不会遇到的问题）：

1. `--accent` 在白底上当**文字**用时必须 ≥4.5:1，所以高饱和亮色（`#ff5c1a`、`#f2d21d`）都不合格，要压暗到 `#c23a00` 这一档；
2. `.ph-diag line` 和 `.ph-grid line` 的网格线颜色是写死在 `#24252a` / `#202126` 的深色线——浅色主题下会显得很脏，需要在 `.ph-grid line{stroke: …}` 和 `.ph-diag line{stroke: …}` 里各改一次（各一处，改完刷新即可）。
