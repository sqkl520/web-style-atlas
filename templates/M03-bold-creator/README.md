# M03 · 醒目作品集（Bold Creator）

一个给人看的个人作品集模板：**大留白、字很大、近黑底＋近白字＋一个橙色强调色**。
两个文件就能跑，不需要安装任何东西，不需要联网，不需要构建。

适合：个人作品集 / 自由职业者 / 小型创意工作室 / 摄影师 / 设计师 / 写作者。

---

## 一、怎么打开（30 秒）

1. 打开 `templates/M03-bold-creator/` 文件夹；
2. 双击 `index.html`，用它默认的浏览器打开就行；
3. 要改内容，用任何纯文本编辑器打开 `index.html`（Windows 上推荐 VS Code 或 Notepad++，**不要用 Word**）；
4. 改完保存，回到浏览器按 `F5` 刷新。

不需要本地服务器。文件里没有一行外部依赖：没有 CDN、没有字体文件、没有图片文件、没有 JS 库。

```
templates/M03-bold-creator/
├── index.html    ← 页面结构 + 全部文案 + 占位图（要改的就是它）
├── style.css     ← 所有样式；想换色换宽只改最上面 12 个变量
├── README.md     ← 你正在看的这份
└── TOKENS.md     ← 12 个变量逐个说明，含"浅色版"整套推荐值
```

## 二、先改这 7 处文案（找 `【换成你的：` 就能定位）

在 `index.html` 里用编辑器搜索 `换成你的`，一共 **32 处**（含浏览器标签页标题、SEO 描述、以及占位图里那行比例标注），按重要性排：

| 位置 | 现在的内容 | 换成什么 |
| --- | --- | --- |
| 首屏最大的那行 | `【换成你的：你的名字】` | 你的名字 / 工作室名（**2–6 个字最好看**） |
| 名字上面小字 | `【换成你的：身份 / 城市…】` | 一句话身份，例：`独立设计师 · 上海` |
| 名字下面那行 | `【换成你的：一句话说清你做什么】` | 你的定位，例：`帮小店做出看起来不便宜的样子` |
| 首屏最下面 | `【换成你的：接单状态…】` | 例：`2025 年 3 月起可接新项目` |
| 作品区 | `【换成你的：作品区标题…】` `【换成你的：作品区说明…】` | 小标题 + 一段介绍 |
| 每条作品 | `【换成你的：项目名称一】` `【换成你的：一两句说明…】` `【标签一】/【标签二】/【年份】` | 项目名、做了什么、标签和年份 |
| 关于我 | `【换成你的：关于我标题…】` 和两段正文 | 3–4 句自我介绍；越具体越可信 |
| 联系 | `【换成你的：联系区标题…】`、`【换成你的：你的邮箱@example.com】`、`【换成你的：回复时间说明…】` | 标题、**你的真实邮箱**、回复时效 |
| 页脚 | `【换成你的：你的名字】` | 署名 |

⚠️ **邮箱要改两处**：一处是页面上显示的链接文字，另一处是它上面 `href="mailto:…"` 里的地址，还有"复制邮箱"按钮上的 `data-copy="…"`。三处保持一致，否则点了发信或复制会对不上。

页脚年份会自动显示当前年份（一行原生 JS），不用管。

## 三、怎么换图片

**模板里没有一张图片文件**：所有作品图都是**内联 SVG 占位框**（灰阶、四角框线、网格、对角线、右下角标注 `1600 × 900 · 16:9`）。这是故意的——它看起来是"设计好的占位块"，而不是"图挂了"。

换真图：在 `index.html` 里找到要换的那一整段

```html
<svg class="ph" viewBox="0 0 1600 900" role="img" aria-label="作品配图占位框：1600×900，比例 16:9">
  …
</svg>
```

从 `<svg` 到 `</svg>` **整段删掉**，换成一行：

```html
<img src="images/我的作品.jpg" alt="秋季新品手册封面，橙黑对比">
```

CSS 已经写好了 `.work-media img` 规则，图片会自动按栏目宽度铺满、加同一个 1px 边框和圆角，你**不用改 CSS**。

三个小提醒：

- 图片和项目放在同一个文件夹里时，路径写文件名即可（`src="我的作品.jpg"`）；
- `alt` 是给看不到图的人（和搜索引擎）读的，写清"这张图是什么"；
- 想让版面保持现在的错落感，图片长宽比尽量接近原来的比例：
  | 第几条 | 占位框比例 | 建议图片比例 |
  | --- | --- | --- |
  | 01 | 16:9 | 横构图，1600×900 左右 |
  | 02 | 3:2 | 横构图，1200×800 左右 |
  | 03 | 4:5 | 竖构图，800×1000 左右 |
  | 04 | 1:1 | 方图，1000×1000 左右 |
  | 05 | 4:3 | 1200×900 左右 |

## 四、加一条 / 减一条作品

作品是一个列表，每条长这样（结构完全一样，改 `work--xxx` 这类修饰类名就会换排法）：

```html
<li class="work work--flip">
  <div class="work-media"> …图或占位 SVG… </div>
  <div class="work-body">
    <span class="idx">02</span>          <!-- 序号，手动写，纯数字两位 -->
    <h3 class="work-title">项目名称</h3>
    <p class="work-desc">一两句说明</p>
    <p class="work-tags">标签 / 标签 / 年份</p>
  </div>
</li>
```

- 复制整段 `<li>…</li>` 就是加一条；删掉就是减一条；
- **序号要手动改**：`01` `02` `03`… 序列号是等宽数字、右对齐，宽度固定，所以你写 `1` 和 `01` 都对得齐，但建议统一两位，列出来才像一条整齐的竖线；
- 排法有 5 种修饰类，随便组合：`work--lead`（图铺满整行）/ `work--flip`（左文右图）/ `work--tall`（竖图）/ `work--narrow`（整条右缩进）/ `work--sm`（小图在右）。

## 五、换颜色、换宽度：只改 `style.css` 最上面的 12 个变量

`style.css` 开头 `:root{ … }` 里有 12 个变量，改完刷新就生效，其它地方不用碰：

```css
--bg:#0e0e10;        /* 页面底色 */
--ink:#f2f2ef;       /* 文字色 */
--muted:#a3a39c;     /* 次要文字（说明、标签、页脚） */
--accent:#ff5c1a;    /* 唯一的强调色：链接、序号、按钮 */
--on-accent:#14100d; /* 强调色底上的文字色 */
--surface:#17171a;   /* 占位图/浅一层的底色 */
--rule:#33333a;      /* 1px 细线 */
--focus:#ffd166;     /* 键盘焦点圈 */
--maxw:1280px;       /* 内容最大宽度 */
--space:clamp(1rem,2.5vw,2rem);  /* 统一间距 */
--radius:2px;        /* 圆角，2px≈直角 */
--font:<系统字体栈>; /* 字体 */
```

每个变量管什么、改错了会怎样、以及一整套"浅色版"推荐值，见 **TOKENS.md**。

> 改强调的是 `--accent` 时，顺手看一眼 `--on-accent`：那是"橙底上的黑字"，两个一起改才能保证按钮上字看得清。

## 六、为什么这套样式和 30 个原型方案不一样（本层豁免了哪些条款）

仓库里有另一层：`prototypes/S01-…` ～ `S30-…` 共 30 个**高度个性化**的设计原型。它们受一份「反 AI 味」规格约束，被**明令禁止**下面这些做法：

1. 居中大标题 + 三张等宽卡片 + 底部 CTA
2. 白色／浅灰 section 交替铺底
3. 纯白底 + 纯黑字 + 单一强调色
4. 24px 圆角 + 柔和投影卡片
5. `Inter` / `Roboto` / `Arial` / `system-ui` 作主字体
6. 紫蓝渐变
7. 毛玻璃吸顶导航

**这一层（大众模板）明确豁免上述全部 7 条**，因为对这些禁令的"违犯"恰好就是"大众模板"能成立的原因。两层的目标不同：

| | 30 个原型（S01–S30） | 这一层（大众模板 M03） |
| --- | --- | --- |
| 目标 | **被记住**：让人一眼看出"这是有人认真做过的" | **不犯错**：任何人拿到就能套用、能上线 |
| 手段 | 反常规、冒险、一次性 | 排版纪律、熟悉的模式、可预期 |
| 失败代价 | 平庸、被划走 | 崩版、看不懂、用不起来 |
| 占位文案 | 禁止（必须写满真文案） | **故意保留**（`【换成你的：…】` 是给使用者的填空指令） |
| 字体 | 禁止系统默认字体 | 系统字体栈（零请求、离线可用） |
| 配色 | 禁止"白底黑字单强调色" | **就是**近黑底＋近白字＋一个强调色 |

逐条对照说明：

- **豁免 1（居中大标题 + 三卡 + 底部 CTA）**：本层没有照搬这套"AI 味"，但**允许**它出现——因为它是普通人最熟悉、最不会出错的作品集结构。实际实现里我选了更稳的变体：极简顶部导航 → 超大自我介绍 → 大小错落的作品列表（`--lead` 铺满、`--flip` 左文右图、`--tall` 竖图、`--narrow` 右缩进，**刻意不做等宽三卡**）→ 短"关于我" → 联系方式 → 页脚。
- **豁免 2、3（白/浅灰交替、白底黑字单强调色）**：这条禁令针对"看着像模板生成"的视觉；而在大众模板层，"低认知负担的配色"恰恰是优点。本层**只选了一侧**：近黑底 `#0e0e10` + 近白字 `#f2f2ef`，加**一个**高饱和橙 `#ff5c1a`。选深色侧的理由：(a) 大字号 + 1px 细线在深底上更"立得住"，白底细线容易显脏；(b) 摄影、视觉类作品在深底上更容易跳出来；(c) 深底不会在长时间浏览时刺眼。想反过来用浅色一侧，TOKENS.md 给了一整套可直接替换的值。
- **豁免 4（24px 圆角 + 柔和投影）**：本层用 `--radius:2px`（几乎直角）+ 1px 硬边线 + 零投影。不是为了反 AI 味，而是：硬边更容易和 1px 网格、等宽数字共存；柔和投影在任何背景色下都容易"发灰"，用户换了底色容易变脏。
- **豁免 5（Inter/Roboto/Arial/system-ui 作主字体）**：本层**就是要**系统字体栈。理由是可交付性：模板必须"两个文件、离线、零请求、零加载失败"。系统栈在每台设备上都立即渲染，不需要任何网络。换字体只需要改 `--font` 一个变量。
- **豁免 6（紫蓝渐变）**：本层不用渐变。单一平色 + 字号层级已经足够，渐变对不会调色的使用者来说是个陷阱。
- **豁免 7（毛玻璃吸顶导航）**：本层顶部导航是**不透明**的纯色吸顶条（`position:sticky` + `background:var(--bg)`）。毛玻璃需要半透明叠加，换底色时容易糊。这里只用一条 1px 底线分隔，风格统一。
- **占位文案（本层故意反掉 30 案"禁止占位文案"的规定）**：30 个原型是**成品**，成品里出现 `【…】` 说明作者没写完；而模板是**半成品**，使用者必须知道"哪里该换成自己的字"。所以本层把所有可变内容写成 `【换成你的：…】`，可搜索、可定位、不会漏改。真正的成品请把 27 处全部替换掉。

一句话口径：**30 案那层的目标是被记住；这一层的目标是不犯错、拿起来就能用。**

## 七、无障碍与响应式，做到了哪些

**无障碍（可访问性）底线**

- 正文最小 16px（`body{font-size:1rem}`），没有比 16px 更小的正文；
- 对比度（按 WCAG 相对亮度公式实算，不是估的）：
  - 正文 `#f2f2ef` / 底色 `#0e0e10` = **17.2:1**
  - 次要文字 `#a3a39c` / 底色 = **7.6:1**
  - 强调色 `#ff5c1a` / 底色 = **6.25:1**
  - 强调色底上的文字 `#14100d` / `#ff5c1a` = **6.1:1**
  - 键盘焦点圈 `#ffd166` / 底色 = **13.4:1**
  - （全部高于 WCAG AA 正文要求 4.5:1；`--rule` 细线是纯装饰，不承载信息）
- 键盘：所有链接/按钮有 `:focus-visible` 可见焦点圈（实测按 Tab 时计算样式为 `outline: solid 2px rgb(255,209,102)`、`outline-offset:3px`，即变量 `--focus`）；页面第一个可获得焦点的元素是「跳到主要内容」；
- 语义标签：`header / nav / main / section / footer`，每个 section 用 `aria-labelledby` 指向自己的标题；导航按钮带 `aria-expanded`；
- 图片：有真实 `alt`；占位 SVG 用 `role="img"` + `aria-label="作品配图占位框：1600×900，比例 16:9"`（内联 SVG 没有 `alt` 属性，`aria-label` 是它在无障碍树里的等价物）；
- 按钮点击区 ≥44×44px，导航链接也是；`prefers-reduced-motion: reduce` 时关闭全部过渡动画。

**响应式**

- 三个断点实测（Chrome 无头，`--force-device-scale-factor=1`）：1440×900 / 768×1024 / 390×844，**三档横向滚动宽度 = 视口宽度，零横向溢出**；
- 作品区在 ≥900px 转两栏（左右交替），900px 以下自动堆叠成"大图 + 说明"，手机上不会挤成两列；
- 首屏标题用 `clamp()` 流体字号：390px 上 48px，768px 上 80.6px，1440px 上 136px；
- 移动端导航：≥768px 显示「名字 + 三个横排链接」；小于 768px 收成一个「菜单」按钮，6 行原生 JS 控制展开收起。实测：按钮 84×44px（≥44px 点击区），展开后菜单 355px 宽、三个链接各 44px 高、**不引起横向滚动**，点任一链接后自动收起并跳到对应分区；JS 不跑也不影响键盘 Tab 走到全部链接。

## 八、已知的不足（用之前先知道）

1. **序号和条数要手动同步**：模板不自动生成序号，加/删作品后记得改 `01 02 03`；
2. **占位图替换是"整段替换"**：必须把 `<svg>…</svg>` 从开标签删到闭标签，只删一半会让后面的版面串位。如果你只想要一段能直接填路径的代码，可以先用 `index.html` 里的占位结构当参照，把它替换成第三节给的一行 `<img>`；
3. **"复制邮箱"按钮依赖浏览器的剪贴板接口**：用 `file://` 直接打开时个别浏览器会拦截，此时按钮仍会显示「已复制」但内容不一定进剪贴板——最稳的方式是直接选中页面上那行橙色邮箱手动复制；
4. **首屏大字是给短名字准备的**：名字换成 10 个字以上时，136px 的大字号会折成两行（不会溢出，但气势会降），这种情况建议把 `--maxw` 调大，或把 `.hero-title` 的 `clamp()` 上限从 `8.5rem` 调小。
