# TOKENS.md — M02 暖调门店站的 12 个变量

全部变量都在 `style.css` 的**第 1 节**（`:root { … }`）。改完保存、刷新浏览器就生效，没有构建步骤。

**一共 12 个（已清点）**：`--paper` `--paper-2` `--ink` `--ink-soft` `--brand` `--brand-deep` `--accent` `--rule` `--radius` `--page-max` `--font-serif` `--font-sans`。

> 另外文件里还有 **1 个内部变量 `--ring`**（焦点框颜色），它只在深色区域（`.hero-band`、`.site-foot`）里被局部改成奶油色，默认值是 `--accent`。**它不在调色清单里，平时不用动**——你只有在"把深色区域改成浅色区域"这种大改时才会碰到它。

**改色安全线（先记住这一条）**：任何当**文字**用的颜色，压在它实际出现的底色上必须 ≥ **4.5:1**（大标题 ≥3:1）。下表"实测"一列是默认值下的真实计算结果；你换色后请照着核一遍，搜索「对比度检查」随便开一个网页工具，把前景/背景两个色值填进去即可。

## A. 颜色（8 个）

### 1. `--paper  #FDF7EE` — 主底色（米白）

| | |
| --- | --- |
| 控制什么 | 全站主背景：页面底色、顶部导航底色、菜单标签小圆片底色 |
| 改它会动到 | 与 `--paper-2` 交替分段的分界（"哪一段是白的、哪一段是奶油的"）、所有深色文字的背景、页脚深底上的浅字（通过 `color-mix` 派生） |
| 实测 | `--ink` 压在上面 **16.01:1**；`--ink-soft` **8.84:1**；`--accent` **5.79:1**；`--rule` **1.84:1**（纯装饰线，允许低） |
| 安全范围 | 亮度上到这个量级就基本安全（接近白）。**别低于 `#F2EDE4`**，再深就要重新核 `--ink-soft` 与 `--accent` |
| 想换的样子 | 更白一点 → `#FFFDF9`；更黄一点 → `#FBF3E4`；带一点灰的纸感 → `#FAF6EF` |

### 2. `--paper-2  #F7EADA` — 分区底色（奶油）

| | |
| --- | --- |
| 控制什么 | 交替分段的那一层底：本模板用在「营业时间与地址」和「顾客评价」两段 |
| 改它会动到 | 这两段的背景；这两段里的文字对比度 |
| 实测 | `--ink` 压在上面 **14.40:1**；`--ink-soft` **7.95:1**；`--accent` **5.21:1**（这是全站当文字用的强调色**最紧**的一处，还有 0.7 的余量） |
| 安全范围 | 与 `--paper` 的差值别拉太大：两者亮度差在 1%–4% 之间最舒服（太近看不出分段，太远像两块不同品牌） |
| 想换的样子 | 更淡 → `#FBF2E6`；更暖（像淡蜂蜜）→ `#F6E6D2` |

### 3. `--ink  #241A12` — 正文与标题（深暖褐）

| | |
| --- | --- |
| 控制什么 | `body` 的文字色 → 全部正文、全部标题（`h1/h2/h3`）、菜单里的菜名、营业时间表 |
| 改它会动到 | 全站可读性的地基。这是最重要的一格 |
| 实测 | 压 `--paper` **16.01:1**，压 `--paper-2` **14.40:1** |
| 安全范围 | 只允许在很暗的范围内微调。**别往灰里调**（`#4A4A4A` 一类中性灰会让整个页面失去暖调）；**绝不要往浅里调**（浅褐当正文立刻掉到 4.5:1 以下） |
| 想换的样子 | 更黑 → `#1E140E`；带红调（像深可可）→ `#2A150F`；带橄榄调 → `#221F12` |

> 注意：`--ink` **不会**自动用在深底上。深底（页脚、主视觉信息带）里的文字是写死的奶油色，这是故意的——见 §B 的说明。

### 4. `--ink-soft  #55432F` — 次要文字

| | |
| --- | --- |
| 控制什么 | 导航链接、店名副标题、段落说明（`.lede`）、菜单分类标题、营业时间表的小注、表单标签 |
| 改它会动到 | "第二层信息"的整体灰（暖）度 |
| 实测 | 压 `--paper` **8.84:1**，压 `--paper-2` **7.95:1** |
| 安全范围 | 可以比 `--ink` 浅 2 档，但**不要浅过 `#6B5A45`**（约 6:1，是舒适下限）。它一旦浅到 4.5:1 附近，整页会显得"字都发虚" |
| 想换的样子 | 更淡 → `#6B5A45`；更暖（像肉桂）→ `#5C4028` |

### 5. `--brand  #7A3B12` — 主色（烤色深褐，物质来源：法棍烤边 / 旧皮革）

| | |
| --- | --- |
| 控制什么 | 主按钮（订位/留座、提交订位）的底色与描边、描边按钮的文字色、链接 hover 色 |
| 改它会动到 | 按钮；`.btn-line` 的文字；页脚深底不是它（那是 `--brand-deep`）；`--brand` 也是 `--brand-deep` 的同族搭档，两格建议一起换 |
| 实测 | **奶油字 `#FFF7EC` 压在它上面 8.03:1**（按钮文字必须走这条）；它自己压在 `--paper` 上当文字是 8.01:1 |
| 安全范围 | 必须够深。`--brand` 与 `--brand-deep` 的亮度差距要够，否则 hover 时按钮变色看不出来（默认两者的对比是"明显变深"） |
| 想换的样子 | 橄榄油 → `#4A4A1E`；皮革红棕 → `#7A2E1B`；深可可 → `#5A2E14`（**别用亮橙或亮红**，按钮上的奶油字会掉到 3:1 以下） |

### 6. `--brand-deep  #2B1A0F` — 最深底（主视觉信息带、页脚）

| | |
| --- | --- |
| 控制什么 | 主视觉压在图上的那块信息带（以 `rgba(43,26,15,0.92)` 用，即同一个色值 92% 不透明）、页脚背景 |
| 改它会动到 | 页面最深的两个块；这两块里的浅色文字；页脚次要字（`color-mix(in srgb, var(--paper) 74%, var(--brand-deep))` 由它派生） |
| 实测 | 奶油字 `#FFF7EC` 压在上面 **15.72:1**；**最坏情况**——信息带 92% 叠在**纯白**照片上合成 `#3C2C22`，仍有 **12.55:1**；叠中灰 `#322218` 是 14.35:1；页脚次要字 `#C6BEB4` 是 **9.09:1** |
| 安全范围 | 它必须"深到没有第二种可能"。**别浅过 `#4A3320`**：那会让"压在大图上"的可读性保证从"与照片无关"退化成"看照片运气" |
| 想换的样子 | 橄榄系深底 → `#22220E`；酒馆红棕深底 → `#2A1211` |

> **为什么信息带用 92% 而不是 100% 不透明？** 留 8% 是为了让照片的颜色隐约透上来（不那么像贴了一块色卡），代价是面板颜色会随照片略变——所以上表把"照片纯白"这个最坏情况单独算了出来（12.55:1，余量充足）。**如果你想要绝对保证**，把 `style.css` 里 `.hero-band` 的 `rgba(43, 26, 15, 0.92)` 改成 `0.98`（甚至直接写 `var(--brand-deep)`），对比度就恒定在 15.72:1。

### 7. `--accent  #9C4A16` — 强调色（陶土 / 烤橙褐）

| | |
| --- | --- |
| 控制什么 | **价格**、`h2` 上方的分类小标签（`.eyebrow`）、周一至周日表里的「最后点单」、手绘风格强调线、键盘焦点框、编辑提示条的边框与文字 |
| 改它会动到 | 全站"要点"的颜色；页面里唯一的高饱和锚点 |
| 实测 | 压 `--paper` **5.79:1**、压 `--paper-2` **5.21:1**（作文字用，均达标）；编辑提示条底是它 8% 叠米白 → 上面写 `--accent` 是 **5.16:1**（全站最紧的一对） |
| 安全范围 | **它同时是文字色**，所以不能往亮里调。上限大约到 `#B0561C`（约 4.6:1，再亮就不合格）。**也绝不能把它当深底上的文字色**：压在 `--brand-deep` 上只有 **2.71:1**（这是我在这个模板里实际踩到的坑，见 README §8.2） |
| 想换的样子 | 更红（番茄酱）→ `#9C3A16`；更黄（芥末）→ `#8A5A12`（黄更难做文字色，注意复核） |

### 8. `--rule  #CBB69C` — 点线、分隔线（纯装饰）

| | |
| --- | --- |
| 控制什么 | **价目表的点线引导**（这个模板的"手艺感"就靠它）、营业时间/怎么来的行分隔、"怎么来"与"先看这里"的点线、`h3` 下划线、输入框描边、顶部导航的下边线 |
| 改它会动到 | 页面的"手工排印"味道；不承载任何信息，改坏也不会读不出来 |
| 实测 | 压 `--paper` **1.84:1**、压 `--paper-2` **1.66:1**（都低于 3:1，**这是设计意图**：菜单点线本来就该若隐若现） |
| 安全范围 | 想更明显 → `#BBA484`；想更淡 → `#DCCBB4`。**唯一的禁令：不要拿它当文字色**（那样文字会隐形）。焦点框走 `--accent`，不走它 |
| 附注 | 输入框的描边也用它。若你觉得输入框太不显眼，把 `.field input, .field select, .field textarea` 的 `border` 改成 `1px solid var(--ink-soft)`（会变成 8.84:1 的描边，很明显） |

## B. 尺寸与字体（4 个）

### 9. `--radius  8px` — 圆角

| | |
| --- | --- |
| 控制什么 | 按钮、图片位、深褐面板、输入框、导航折叠按钮的圆角 |
| 改它会动到 | 全站的"软硬"手感 |
| 建议范围 | **`4px`–`10px`**。`4px` 更利落（像老店的名片），`10px` 更柔和。**不要调到 16px 以上**：那会立刻变成"通用 SaaS 卡片"的观感，和"暖调实体店"对不上（而且那是本层刻意避开的默认范式之一） |
| 附注 | 菜单里的小标签（招牌/素食）和顶部导航的折角箭头用的是固定值（`999px` / 方角），不随这个变量变 |

### 10. `--page-max  1120px` — 版心最大宽度

| | |
| --- | --- |
| 控制什么 | 内容区的最大宽度（`.wrap`），超过这个宽度就居中留白 |
| 改它会动到 | 每行文字的长度、价目表两列的宽度、环境图的尺寸、页脚四列的宽度 |
| 建议范围 | `960px`–`1320px`。**别超过 `1400px`**：中文行会变太长，读起来眼睛要来回扫；也别小于 `900px`，价目表两列会挤 |
| 实测 | 默认值下 1440 视口：版心 1120px、内容左右各留 160px；行宽（中文正文）约 40–45 字，落在易读区间 |

### 11. `--font-serif` — 标题字体栈（衬线）

```
Georgia, "Times New Roman", "Songti SC", "SimSun", "Noto Serif CJK SC", serif
```

| | |
| --- | --- |
| 用在哪 | `h1` `h2` `h3`、店名、页脚店名、顾客评价的引文、菜单分类标题 |
| 为什么这么排 | `Georgia`（Windows/macOS 都有）负责拉丁字母和数字 → `"Times New Roman"` 兜底 → macOS 的 `"Songti SC"`、Windows 的 `"SimSun"`（宋体）负责中文 → `"Noto Serif CJK SC"`（Linux / Android 上可能装）→ `serif` 自己兜底 |
| 想换的样子 | 只换成**你系统里装了的**字体名，例如 macOS 想用楷体：把 `"Songti SC"` 换成 `"Kaiti SC"`；Windows 想用楷体：加 `"KaiTi"` |
| 注意 | 本层不引外部字体文件（零依赖）。**不要**在这里写 `@import` 或 `<link>` 到字体网站的地址 |

### 12. `--font-sans` — 正文字体栈（无衬线）

```
system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
"Microsoft YaHei", "Noto Sans CJK SC", "Source Han Sans SC", Arial, sans-serif
```

| | |
| --- | --- |
| 用在哪 | 正文、导航、菜单菜名与价格、按钮、表单、页脚 |
| 为什么这么排 | `system-ui` / `-apple-system` / `"Segoe UI"` 依次命中 macOS 与 Windows 的系统界面字体（拉丁） → `"PingFang SC"`（macOS 中文）、`"Hiragino Sans GB"` → `"Microsoft YaHei"`（Windows 中文，微软雅黑）→ `"Noto Sans CJK SC"` / `"Source Han Sans SC"`（Linux / 思源黑体）→ `Arial` → `sans-serif` |
| 想换的样子 | 想固定成某种观感（比如一定要苹方风格）：把 `"Microsoft YaHei"` 提前；想让 Windows 一定用雅黑、macOS 也用雅黑（如果你装了）：把 `system-ui` 去掉 |
| 关于豁免 | 这个栈用了 `system-ui` 与 `Arial`，在 `prototypes/` 那一层是被**一票否决**的；在 `templates/M0x` 这一层是**明示豁免**的（理由与范围见 `README.md` §7） |
